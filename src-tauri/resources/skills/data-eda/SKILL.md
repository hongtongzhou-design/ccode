# 探索性分析与绘图

本技能规定数据处理课题「探索性分析（EDA）」阶段的操作规范与产出格式。分析全覆盖不挑选、图表可复现、发现可回溯，保证结论经得起复查。

## 何时使用

- 用户要求对清洗后的数据做探索性分析、找规律或出结论
- 用户要求绘制论文/报告级图表（分布、相关矩阵、异常点等）
- 数据处理流水线中「探索性分析」一步（简报会指向本技能）

## 操作规范

### 1. 分布/相关/异常全覆盖，不挑选

- **分布分析**：各字段全部给出分布（直方图/核密度 + 关键统计量），逐个解读，不跳过「看起来正常」的字段
- **相关分析**：全字段相关矩阵；强相关对（|r| ≥ 0.7）**全部列出并解读**，不挑符合预期的
- **异常分析**：按清洗规则口径复查残留异常；新发现的异常标 [待确认] 并给出样例行号

### 2. 图表规范

- 图表统一**英文标注**（标题、坐标轴、图例；数据标签含单位），正文解读用中文
- 全部图表由 `analysis/` 下的可复现脚本生成，**禁止手工改图**；脚本从 `main` 重跑应产出相同图片
- 图表写入 `figures/`，文件名与报告中引用一一对应（如 `fig1-age-histogram.png`）
- 绘图参数固定（dpi ≥ 150、字号、配色），同一报告内风格一致

### 3. 发现可回溯

`eda-report.md` 每条结论必须附证据：对应的 figures/ 文件名或具体统计量数值，不写「数据表明」「大致呈正相关」这类无出处的表述。

### 4. 涉及统计结论时先过 stats-check

`eda-report.md` 的结论若包含统计检验、显著性或效应量表述，先按 stats-check 技能的审查口径自查（检验方法与数据匹配、p 值给具体值、附效应量与置信区间），再落笔。

### 5. 代码风格（matplotlib/pandas）

- 每个分析脚本设 `main()` 与 `if __name__ == "__main__":` 入口，从 `main` 重跑全流程
- 路径集中为模块顶部常量，读产物目录数据、写 figures/
- 一图一函数，函数名说明图意；不依赖交互式状态，不手写中间结果进代码
- 依赖只用项目已有的 pandas/matplotlib/numpy，不新增未声明依赖

## 产出格式

- `analysis/<EDA 脚本>`：可复现，`main()` 入口，输出全部图表到 `figures/`
- `figures/`：全部图表，英文标注，文件名与报告引用一一对应
- `eda-report.md` 分析报告：
  1. 分布分析：逐字段解读，附图表与统计量
  2. 相关分析：相关矩阵图 + 全部强相关对（|r| ≥ 0.7）解读
  3. 异常分析：残留异常复查结果 + 新发现 [待确认] 异常样例
  4. 结论：3-5 条可用于后续决策的发现，每条附对应图表/数字

## 完成标准

`figures/` 与 `eda-report.md` 存在；每条发现可回溯到具体图表或数字；无主观臆断；脚本从 `main` 重跑产出与仓库中一致的图表。
- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
