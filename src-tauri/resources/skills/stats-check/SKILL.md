# 统计审查（stats-check）

本技能规定「统计用法审查 + 实验设计自查」的只读检查流程。**本技能只产出报告，不改数据、不改正文**——怎么修由人定夺。统计结论拿不准时写明「建议咨询统计专业人员」，不硬下判断。

## 何时使用

- 用户要求「检查一下统计对不对」「审一下 p 值/显著性用法」
- 论文投稿前自查统计报告规范
- 实验设计阶段做功效与样本量自查（科研论文/毕业论文流水线的「实验设计」「结果分析」步骤可引用本技能）

## 操作规范

### 1. 确定检查范围

- 正文：调用方指定的稿件或报告；未指定时按 `manuscript/` 最新稿（final 优先于 draft），报告开头写明检查对象；
- 数据与结果：`analysis/`、`results/summary.md` 中的数字与图表用于交叉核对，只做只读引用。

### 2. 检验方法与假设匹配

逐处统计检验核对：数据类型（连续/分类/有序）、分布假设（正态性是否检验或说明）、组数与配对关系，与所用检验是否匹配（如两组连续非正态却用 t 检验 → 记录）。不确定匹配性的标 [待确认]，给出可替代的稳健/非参数方法名称。

### 3. p 值与报告规范

- p 值是否给出具体数值（而非只写 p<0.05）；是否报告检验统计量与自由度；样本量是否随结果给出；
- 多重比较：同一数据集上做了多个检验时，是否说明校正方法（Bonferroni/FDR 等）；未校正的列出比较次数并标风险；
- 「显著/不显著」的二元表述是否伴随效应量与置信区间——只有 p 值的结论列入「证据不足表述」。

### 4. 图注与正文一致性

- 图注中的检验方法、样本量、显著性标记（* 的含义）与正文方法节是否一致；
- 图中误差棒的含义（SD/SEM/CI）是否标注；正文数字与图中数字是否一致。

### 5. 实验设计自查（设计阶段适用）

- 主要结局指标是否唯一明确；样本量是否有功效估算依据（效应量假设、α、power），没有依据的给出可执行的估算路径；
- 随机化/盲法/对照是否说明；剔除标准是否事先定义（防止事后挑数据）。

### 6. 产出报告

结果写入 `analysis/stats-check.md`（调用方另指定路径时从其约定）：

```
# 统计审查报告（<被检文件>，<日期>）
- 结论：通过 / N 个问题（CRITICAL n / MAJOR n / MINOR n）
## 检验方法匹配
## p 值与报告规范
## 图注与正文一致性
## 实验设计自查（仅设计阶段）
## 建议处理项（按优先级排序，只列建议不执行）
```

## 完成标准

报告各节齐全（无问题的节写「无」；非设计阶段「实验设计自查」节写「不适用」）；每条问题可定位（节+行号或图号）；正文与数据一个字未改。

- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
