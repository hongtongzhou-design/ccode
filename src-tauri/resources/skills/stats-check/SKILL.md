# 统计审查（stats-check）

本技能规定「统计用法审查 + 实验设计自查」的只读检查流程。**本技能只产出报告，不改数据、不改正文**——怎么修由人定夺。统计结论拿不准时写明「建议咨询统计专业人员」，不硬下判断。稿件没写的信息（n 定义、校正方法、软件版本、剔除规则）一律列入「待作者补充」，绝不编造。

## 何时使用

- 用户要求「检查一下统计对不对」「审一下 p 值/显著性用法」
- 论文投稿前自查统计报告规范
- 实验设计阶段做功效与样本量自查（科研论文/毕业论文流水线的「实验设计」「结果分析」步骤可引用本技能）

## 操作规范

### 1. 确定检查范围

- 正文：调用方指定的稿件或报告；未指定时按 `manuscript/` 最新稿（final 优先于 draft），报告开头写明检查对象；
- 数据与结果：`analysis/`、`results/summary.md` 中的数字与图表用于交叉核对，只做只读引用。

### 2. 分析单元与重复层级

最先核对「n 是什么」，再谈检验：

- n 的确切定义与处理施加的层级：n 报告为细胞/视野/读数/技术孔数，而处理施加在动物/患者/批次/实验轮次上 → 伪重复风险，记最高级；
- 配对、重复测量、嵌套（同一动物的多个部位、同批次的多个孔）是否被当成独立样本分析。

### 3. 检验方法与假设匹配

逐处统计检验核对：数据类型（连续/分类/有序）、分布假设（正态性是否检验或说明）、组数与配对关系，与所用检验是否匹配。不确定匹配性的标 [待确认]，给出可替代的稳健/非参数方法名称。常见信号：

- 两组连续非正态却用 t 检验；多组用连串 t 检验代替 ANOVA；
- 卡方用于期望频数 <5 的格子；Pearson 相关用于明显非线性关系；
- 「A 组显著、B 组不显著，所以 A 优于 B」——两组各自显著性差异不等于组间差异显著，须看交互作用。

### 4. p 值与统计解读

- p 值是否给出具体数值（而非只写 p<0.05）；是否报告检验统计量与自由度；样本量是否随结果给出；
- 多重比较：同一数据集上做了多个检验时，是否说明校正方法（Bonferroni/FDR 等）；未校正的列出比较次数并标风险；
- 「显著/不显著」的二元表述是否伴随效应量与置信区间——只有 p 值的结论列入「证据不足表述」；
- 常见信号：阈值两侧近似值区别对待（p=.049 显著、p=.051 不显著）；单尾检验无先验依据；「ns」作为唯一结果；「显著」当「重要」用而无效应量；非显著结果被写成「无效应」（小样本可能只是功效不足，建议敏感性分析或等效性检验）；相关/回归措辞升级为因果。

### 5. 图注与正文一致性

- 图注中的检验方法、样本量、显著性标记（* 的含义）与正文方法节是否一致；正文数字与图中数字是否一致；
- 每面板：n 定义、汇总惯例（误差棒是 SD/SEM/CI）、检验与校正状态是否标注；
- 柱状图未叠原始数据点时提示分布不可见；箱线图须说明 whisker 规则。

### 6. 实验设计自查（设计阶段适用）

- 主要结局指标是否唯一明确；随机化/盲法/对照是否说明；剔除标准是否事先定义（防止事后挑数据）；
- 功效估算依据分层：最小重要效应/文献效应量（可信）> 预实验估计（发表偏倚易致高估，须打折）> 惯例值（兜底且须明说）；成果应是敏感性区间而非单一 n；没有依据的给出可执行的估算路径；
- 已完成的实验被要求补功效 → 指出事后功效是循环论证，改报现有 n 下可检测的最小效应量；
- 缺失数据的量与处理策略是否说明（整行删除是否安全、是否查过缺失机制）。

### 7. 措辞红线

- 每条问题写「现象 + 风险 + 修法」，禁指责性结论（「分析错误」「显著性造假」）；材料不足统一写「现有材料无法评估」；
- 机械可核项（p 值格式、误差棒标注、文图数字一致）可下定论；判断依赖项（检验是否真正恰当、因果措辞是否过强）统一写「风险 + 需人工确认」。

### 8. 产出报告

结果写入 `analysis/stats-check.md`（调用方另指定路径时从其约定）：

```
# 统计审查报告（<被检文件>，<日期>）
- 结论：通过 / N 个问题（CRITICAL n / MAJOR n / MINOR n）
- 检查边界与无法评估项
## 分析单元与重复层级
## 检验方法匹配
## p 值与统计解读
## 图注与正文一致性
## 实验设计自查（仅设计阶段）
## 待作者补充（稿件缺的事实信息，短问句清单）
## 建议处理项（按优先级排序，只列建议不执行）
```

## 完成标准

报告各节齐全（无问题的节写「无」；非设计阶段「实验设计自查」节写「不适用」；「待作者补充」无内容时写「无」）；每条问题可定位（节+行号或图号）；每条判断依赖项结论含「需人工确认」；正文与数据一个字未改。

- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
