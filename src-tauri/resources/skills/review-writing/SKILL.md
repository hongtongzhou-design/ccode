# 英文综述写作

本技能规定综述写作「大纲 → 初稿 → 润色」三阶段的操作规范与红线约束。任何阶段都适用：**引用只来自引文库，严禁编造文献。**

## 何时使用

- 用户要求基于笔记与引文库（如 `notes/` 与 `references.bib`）写英文综述
- 综述流水线中「综述大纲 / 综述初稿 / 润色与定稿」各步（简报会指向本技能）

## 动笔前

- 确认综述类型：独立综述（默认本规范）/ 学位论文综述章 / 引言 mini 综述（1-3 页，CARS 三 Move：确立领域 → 指出 gap → 占据位置）；任务书未指明时按独立综述。
- 通读 `notes/` 全部笔记与 `references.bib`；笔记缺失时在报告中说明并停止，不自造内容。

## 三阶段要点

### 阶段一：大纲（outline.md）

1. 通读全部笔记，按概念/主题聚类归纳研究现状的主要线索（方法/问题/结论的异同）——**按概念组织，不按作者、不按时间**。
2. 产出 `outline.md`：章节结构（引言 / 背景 / 主题各节 / 讨论 / 结论）、每节要点（3-6 条）、每节拟引用的 bib 键、分类框架的一句话说明。
3. 有分歧时选覆盖文献最多的框架，并在末尾记录取舍理由。
4. 每个主题节预设一句「综合点」：这组文献一致在哪、分歧为何（方法？样本？时代？）。
5. 讨论节必须含 gap 段：gap 归类（证据/知识/实践/方法/经验/理论，六类之一）、承认相邻工作并说清「未整合之处」；禁「有待进一步研究」式空话。
6. **只引用 `references.bib` 中存在的键，不为大纲新造引用。**

### 阶段二：初稿（manuscript/draft.md）

行文规则：

1. **观点先行，引用为证**：论断在前、括号聚类引用在后（`[@a; @b]`）；禁「作者说」流水账（BAD：`Smith (2020) found X.` / GOOD：`X is well-established (Smith, 2020; Chen, 2021).`）；仅当概念不可通用归属时才点名学者。
2. 段落以概念开头；自检：随机抽 5 段，首句以作者名开头超 2 段即重写该节。
3. 每个主题组至少一处批判：方法学评价 / 结果冲突 / 适用边界；可用批判词：however / in contrast / remains unclear / overlooks / limited to。
4. 转场即论证：过渡句须承接上节论证（如 "This framework was powerful, but it carried an implicit assumption that…"），禁「接下来讨论…」式空转。

内容与篇幅：

5. 按 `outline.md` 用规范学术英文撰写，目标 6000-8000 词（用户另有约定时从其约定）。
6. 引用一律用 `[@bib键]` 形式，且键必须能在 `references.bib` 中解析——**严禁编造文献，严禁新造键**。
7. 图表以占位形式给出（「图 1：…（待绘制）」「表 1：…」），**不虚构数据**。
8. 没有文献支撑的论断不得下；必须保留的判断在句末标 `[待核实]`。

### 阶段三：润色与定稿（manuscript/review-final.md）

1. 语言润色：语法、用词、句式与段落衔接，保持学术语气；**只改表达，不改学术观点**。
2. 分级自检：
   - `[必须修复]`：引用断链（键不可解析）；堆砌超标（复跑阶段二第 2 条抽查）；随机抽 3-5 处引用回 `notes/` 对应笔记核对论断与文献内容相符（防张冠李戴），不符标 `[待核实]`。
   - `[建议修复]`：转场空转；批判词缺位；图表占位编号不连续；重复句式。
3. 引用闭环核对：每个论断都有引用、每个 bib 条目都被引用（未用的在报告中列出）。发现内容性错误标 `[待核实]`，**不得自行改写事实**。
4. 产出定稿 `manuscript/review-final.md`，并附 `manuscript/changelog.md` 逐条列出主要修改点。
5. 文末 References 节按 `references.bib` 生成完整文献列表。

## 完成标准

- 大纲：结构完整、每节要点与引用键齐全、综合点与 gap 段已预设、取舍理由已记录
- 初稿：覆盖大纲全部章节，引用键全部可在 `references.bib` 中解析，行文规则自检通过（段落抽查达标）
- 定稿：无语法硬伤、引用闭环（论断有引用、条目被引用）、张冠李戴抽查通过、`[必须修复]` 项清零、`changelog.md` 已提交
- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
