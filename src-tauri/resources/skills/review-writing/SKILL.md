# 英文综述写作

本技能规定综述写作「大纲 → 初稿 → 润色」三阶段的操作规范与红线约束。任何阶段都适用：**引用只来自引文库，严禁编造文献。**

## 何时使用

- 用户要求基于笔记与引文库（如 `notes/` 与 `references.bib`）写英文综述
- 综述流水线中「综述大纲 / 综述初稿 / 润色与定稿」各步（简报会指向本技能）

## 三阶段要点

### 阶段一：大纲（outline.md）

1. 通读全部笔记，按主题聚类归纳研究现状的主要线索（方法/问题/结论的异同）。
2. 产出 `outline.md`：章节结构（引言 / 背景 / 主题各节 / 讨论 / 结论）、每节要点（3-6 条）、每节拟引用的 bib 键、分类框架的一句话说明。
3. 分类框架优先按主题聚类；主题过于发散时改按时间线；有分歧时选覆盖文献最多的框架，并在末尾记录取舍理由。
4. **只引用 `references.bib` 中存在的键，不为大纲新造引用。**

### 阶段二：初稿（manuscript/draft.md）

1. 按 `outline.md` 用规范学术英文撰写，目标 6000-8000 词（用户另有约定时从其约定）。
2. 引用一律用 `[@bib键]` 形式，且键必须能在 `references.bib` 中解析——**严禁编造文献，严禁新造键**。
3. 图表以占位形式给出（「图 1：…（待绘制）」「表 1：…」），**不虚构数据**。
4. 没有文献支撑的论断不得下；必须保留的判断在句末标 `[待核实]`。

### 阶段三：润色与定稿（manuscript/review-final.md）

1. 语言润色：语法、用词、句式与段落衔接，保持学术语气；**只改表达，不改学术观点**。
2. 一致性核对：每个论断都有引用、每个 bib 条目都被引用（未用的在报告中列出）、图表占位编号连续。发现内容性错误标 `[待核实]`，**不得自行改写事实**。
3. 产出定稿 `manuscript/review-final.md`，并附 `manuscript/changelog.md` 逐条列出主要修改点。
4. 文末 References 节按 `references.bib` 生成完整文献列表。

## 完成标准

- 大纲：结构完整、每节要点与引用键齐全、取舍理由已记录
- 初稿：覆盖大纲全部章节，引用键全部可在 `references.bib` 中解析
- 定稿：无语法硬伤、引用闭环（论断有引用、条目被引用）、`changelog.md` 已提交
- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
