# 综述框架构造

本技能规定综述/论文框架的设计方法：**根据最新精读文献的前言内容提取研究空白 + 拆解权威综述的框架范式 → 融合构造出自己的综述框架**。框架不是凭空拟的目录，每一章都要能回答「它补了哪个空白、借用了哪个范式」。

## 何时使用

- 综述流水线中的「综述大纲」步骤（简报会指向本技能）
- 用户要求为综述或论文设计章节框架、讨论「这篇综述该怎么搭结构」时

前置条件：`notes/` 下已有精读笔记（含「局限」「可引用点」字段），`papers/included.md` 中已有纳入文献清单，`references.bib` 引文库可用。

## 规范

### 一、提炼研究空白清单

1. 通读 `notes/` 各笔记的「局限」与「可引用点」两节；对最新精读的一批文献，回到原文前言（Introduction 末段）核对作者自述的研究空白——前言中的 gap 陈述优先级最高。
2. 汇总为研究空白清单：**每条空白必须标注来源笔记**（笔记文件名或 bib 键），多条文献指向同一空白时合并为一条并列出全部来源。
3. 空白描述写「缺什么」，不写「我想做什么」；剔除仅凭单篇文献主观抱怨、无第二来源佐证的孤立空白（保留但在清单中标注「孤证」）。

### 二、拆解权威综述为范式卡片

1. 从 `papers/included.md` 中选取 **2-3 篇权威综述类文献**（权威综述/大刊综述/高被引综述优先）；纳入清单中没有综述类文献时，如实说明并跳过本步，不得虚构范式。
2. 对每篇拆解其章节框架，写成一张**范式卡片**，三项必填：
   - **结构逻辑**：章节按什么线索组织（主题聚类 / 时间线 / 方法分类 / 问题驱动……）
   - **详略配比**：哪些部分重笔（如方法对比占全文比例）、哪些一笔带过
   - **论证顺序**：背景→现状→对比→展望，还是问题→方案→评估→开放问题等实际推进次序
3. 范式卡片只记录结构事实，不摘抄内容；注明该范式适合回答哪类问题。

### 三、融合构造框架

1. **范式做骨架、空白做导向**：以覆盖空白最多的范式为主线骨架，把每条研究空白对应到框架中的具体章节位置——空白即章节存在的理由。
2. 一个空白可由多个章节共同回应（在对应关系中注明）；一个章节可回应多个空白。
3. **取舍规则**：
   - 范式冲突时（结构逻辑不兼容），选覆盖空白更多的范式做骨架，落选范式的局部优点（如某节的论证顺序）可作为节内参考吸收；
   - **不新造与空白无关的章节**——经典背景、方法总览这类「惯例章」也要能挂到至少一条空白或一条范式理由上，否则删除；
   - 空白无法落进任何范式时，允许新增章节，但必须在该节标注「空白驱动新增」。

### 四、产出 outline.md 必须附「框架推演」段

`outline.md` 末尾固定附「## 框架推演」段，包含三块内容，供评审核对：

1. **空白清单**：逐条列出，标注来源笔记；
2. **范式卡片**：每篇权威综述一张（结构逻辑 / 详略配比 / 论证顺序）；
3. **融合理由**：选了哪个范式做骨架及为什么（覆盖空白数）、每个空白落到哪节、哪些惯例章被删或新增及理由。

## 产出格式

`outline.md`（写入综述工作区根目录）：

```markdown
# 综述大纲

## 1. 引言
- 要点：……（3-6 条）
- 拟引用：[@bib键1] [@bib键2]
- 回应空白：G1、G3

## 2. ……
（章节结构按融合框架展开，每节给要点、引用键、回应空白）

## 框架推演
### 空白清单
- G1：……（来源：note-a.md、note-c.md）
### 范式卡片
- 综述X（@bib键）：结构逻辑……｜详略配比……｜论证顺序……
### 融合理由
- 以综述X范式为骨架（覆盖 G1-G4，综述Y仅覆盖 G2-G3）；G5 无范式可落，新增第 6 节「空白驱动新增」……
```

引用键只来自 `references.bib`，不为框架新造引用。
- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
