# 引用完整性校验（bib-check）

本技能规定「正文引用 ↔ references.bib ↔ 全文 PDF」三方核对的只读检查流程。**本技能只产出报告，不直接改正文和 bib**——修什么由人定夺。

## 何时使用

- 用户要求「检查引用」「核对参考文献」「bib 和正文对不对得上」
- 流水线润色/定稿/期刊格式适配步骤的一致性核对环节

## 操作规范

### 1. 确定检查范围

- 正文：优先检查报告调用方指定的稿件文件；未指定时按 `manuscript/` 下最新稿（final 优先于 draft），并在报告开头写明检查了哪个文件；
- bib：项目根 `references.bib`；缺失时在报告中说明并停止。

### 2. 引用键核对

- 从正文提取全部 `[@key]` 形式的引用键；LaTeX 稿件同时提取 `\\cite{key}`、`\\citep{key}`、`\\citet{key}`、`\\parencite{key}`、`\\textcite{key}`、`\\autocite{key}` 等命令中的键，逗号分隔的多键逐个展开。检查范围在报告开头注明（Markdown / LaTeX / 两者）；
- 每个键必须在 `references.bib` 中存在——缺失的列入报告「未解析引用」节（含出现位置：节+行号）；
- 占位引用扫描：正文中 `[CITATION NEEDED]`、`TODO: 补引用` 等占位标记列入「未解析引用」节（含位置）；
- bib 重复键：同一键出现多条会静默覆盖前一条，列为 Critical 列入「重复 bib 键」节；
- 反向核对：bib 中从未被正文引用的条目列入「未引用条目」节（不视为错误，供用户决定去留）。

### 3. bib 条目字段核对

逐条检查：作者、年份、标题、出处（期刊/会议）、DOI 或链接五字段；缺字段或标「待补」的列入「字段缺失」节，逐条列出缺哪几项。另做两项专项检查（肉眼最易漏的错）：

- 作者顺序专门核对第一作者——人名集合对得上不代表顺序对，第一作者错/顺序颠倒属 Critical；
- 卷年一致性：bib 年份与卷号对应的出版年份明显不符时标出（抄录错误的高发信号）。

### 4. 全文对应核对

- 若项目存在 `papers/included.md`：bib 条目应与清单中的文献对应，清单有而 bib 无、bib 有而清单无的分别列出；LaTeX 项目若存在 `\\bibliography{...}` 或 `\\addbibresource{...}`，记录实际使用的 bib 文件；
- 若项目存在 `papers/` 目录：抽查 bib 条目是否有对应 PDF（按「作者年份-短标题」命名口径匹配）；清单中标注「需自行获取」的跳过并在报告中计数说明。

### 5. 外部元数据核验（可选，联网工具可用时）

- 来源层级（按可信度从高到低取用）：DOI 解析/出版社页 > DBLP（CS 领域优先，`dblp.org/doi/<doi>.bib`）> CrossRef（`https://api.crossref.org/works/<doi>`）> arXiv API > 标题检索兜底；每条核验结论注明依据来源（如 dblp / crossref / 标题检索）；
- 判定口径二分，两类不得混报：
  - DOI/arXiv ID 精确查询证实不存在 → [疑似编造]，列入报告最前；
  - 仅标题检索无果（人文、中文刊、区域期刊常见未被索引）→ 「无法证实存在（可能未被索引）」单列，由人工定夺，不算编造；
- 字段冲突按严重度三级分级，逐条写明 bib 值与官方值：
  - Critical（必修）：作者/年份错、DOI 指向另一篇论文、标题核心词不符、页码差 ≥5；
  - Warning（待核）：卷年不一致、期号缺漏、页码差 1–4；
  - Info（仅记录）：标题大小写、刊名缩写 vs 全称、标点差异；
- 预印本专项：bib 为 arXiv 条目但该文已正式发表 → 「出处可升级」节（建议性质，非错误）；
- 联网工具不可用或条目无 DOI/标识时跳过本节，在报告中注明「未做外部核验」。

### 6. 产出报告

结果写入 `manuscript/citation-check.md`（调用方另指定路径时从其约定），结构：

```
# 引用完整性校验报告（<被检文件>，<日期>）
- 结论：通过 / N Critical / M Warning / N 疑似编造 / N 未解析引用
## 疑似编造（ID 可证伪，最优先处理）
## 无法证实存在（可能未被索引，人工定夺）
## 未解析引用（正文有键、bib 无条目；含占位引用标记）
## 重复 bib 键（静默覆盖，Critical）
## 字段缺失与元数据存疑（按 Critical / Warning / Info 分级，注明核验来源）
## 出处可升级（预印本已正式发表）
## 未引用条目（bib 有条目、正文未引用，不视为错误）
## 全文对应
## 建议处理项（按优先级排序，只列建议不执行）
## 验证范围声明
```

报告末尾固定附上验证范围声明：本报告核验的是 bib 良构与文献存在性/元数据匹配，**未核验「文献是否支持正文所引论断」**——该层需人工或评审环节完成。本地扫描干净不等于文献真实存在，未做外部核验时必须明说。

## 常见错误模式（检查时对照的提醒清单）

- 凭记忆写 bib 条目（作者名/会议名幻觉高发）；
- 正文留占位引用 key 忘了补；
- 预印本与正式发表版本混用；
- 引用本身真实但文献并不支持该处论断（超出本技能核验范围，提醒人工）；
- 重复键静默覆盖导致条目张冠李戴；
- 盲信 Google Scholar 导出的 venue/页码/年份元数据。

## 完成标准

报告各节齐全（无问题的节写「无」；无 Critical 时明确写明「无 Critical」；未做外部核验时相关两节写「未做外部核验」）；每条问题可定位（行号或 bib 键）并带来源标注（外部核验结论）；正文与 bib 一个字未改。
- 写作约定：不使用彩色 emoji；强调标记用「注意：」或单色 ⚠（U+26A0 U+FE0E）。
