## 1. Mesa 是什么

Mesa 是装在电脑上的 **AI 科研工作台**。它自己不是一个大模型，而是把你电脑上的终端 AI（Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Kimi Code、CodeBuddy Code、Cursor CLI、Grok Build，装一家就够）管起来，围绕一个课题文件夹干活。

可以把它想成三样东西叠在一起：

- **书桌**：课题文件夹、PDF、笔记、草稿都在一个地方。
- **管家**：记住用哪家 AI、哪把密钥、课题走到了哪一步。
- **验收门**：AI 做出来的正式成果先放在旁边的工作副本里，你看过、点过保存，才进课题文件夹。

### 三方分工

| 谁 | 负责 | 不负责 |
|---|---|---|
| 你 | 定课题、拍板纳入哪些文献、登录学校账号、决定哪一版算数 | 手填环境变量、盯着终端每一行日志 |
| Mesa | 准备环境、建隔离副本、记住步骤、把 PDF 收进 `papers/`、拦住没验收的写回 | 替你登录学校、存机构密码、把「文件写完」当成「研究成立」 |
| AI | 检索、写笔记、改文件、出草稿 | 自己点保存进项目、批量去出版商网站下 PDF |

### Mesa 不做的事

- 不是网页聊天框。真正干活的是你本机的 Agent 程序。
- 不会替你把大课题拆成子任务，也不会替你选用哪家 AI。
- 不保存学校图书馆账号密码，不批量下载付费全文（会连累全校 IP 被封）。
- 不把 AI 报告里的「已完成」「通过」当成你可以投稿。

### 几条贯穿全书的规矩

- **课题是家。** 对话、步骤、文件、定时任务都挂在课题文件夹上。
- **成稿走副本。** 要进课题的正式成果在工作副本里做，评审后才合并。随口问一句用「＋新对话」，它直接改课题文件夹。
- **PDF 是原始资料。** 下载或关联的文献直接进 `papers/`；AI 做的表、图、稿件要评审后才进主文件夹。
- **密钥不出门。** 界面只显示尾号；默认只注入到这一次运行，不改你电脑上 CLI 的全局配置。

界面叫 Mesa，但数据文件夹仍叫 `ccode`（课题里的 `.ccode/`，家目录下的 `~/ccode/`）。备份或换电脑时按这个名字找。

> **【配图】** 总览：书桌（项目）+ 管家（连接 / 步骤）+ 验收门（评审）。

## 2. 安装与第一次打开

### 2.1 下载哪个包

到 [Releases](https://github.com/hongtongzhou-design/ccode/releases/latest) 按电脑选：

| 电脑 | 安装包 |
|---|---|
| Mac（M1–M4 芯片） | `Mesa_x.x.x_aarch64.dmg` |
| Windows | `Mesa_x.x.x_x64-setup.exe`（批量部署静默安装：`setup.exe /S`；不再提供 `.msi`） |

本版本不发布 Linux 安装包。

带 `.sig`、`latest.json` 的是自动更新用的签名文件，不用下。

**【待补充：Intel 芯片 Mac 是否支持；Windows ARM 是否支持】**

### 2.2 Mac 提示「已损坏，无法打开」

文件没坏，是应用还没做苹果公证。打开「终端」执行：

```bash
xattr -cr /Applications/Mesa.app
```

每次重新下载安装都要做一次。

> **【配图】** 「已损坏」弹窗与终端命令。

### 2.3 打开之后

默认停在 **工作台**。左边一列九个图标，`⌘1`–`⌘9`（Windows / Linux 用 `Ctrl`）切换，`⌘K` 打开命令面板。

还没有课题时，工作台中间写着 **从一个项目开始**，有一个 **添加项目** 按钮。三条路都可以：

1. 只想试 AI 会不会说话：点右上角 **快速开聊**（不建课题）。
2. 有课题文件夹：点 **添加项目**。
3. 想先摸科研界面：到 **项目** 页点 **✦ 创建示例课题**。

窗口顶上的 **待处理** 带数字时，说明有事要你拍板；没数字就是没事。

**怎样算装好：** 能看到工作台，九个入口都能点进去。

### 2.4 快速开聊（不建课题）

1. 点 **快速开聊**，选 Agent 和连接，点开始。
2. 进入 **运行** 页，目录在 `~/ccode/scratch`。
3. 聊出有用的东西：标签上 **⋯ → 转为项目…**，选文件夹登记，对话会跟过去。

写综述、下文献、要留存的成稿不要在这里做，它们需要一个课题。

> **【配视频】** 快速开聊一句 → 转为项目。

## 3. 第一次用：五步到能聊

整段约 15–25 分钟。

### 第 1 步　补齐本机环境

**设置 → 诊断**。

| 项 | 用途 | 缺了怎么办 |
|---|---|---|
| Git | 科研、编程都要用（工作副本、历史） | 行内 **一键安装** |
| Node.js | 很多 Agent 靠它安装 | 行内 **一键安装** |
| Quarto | 把稿件渲染成 PDF / Word | 一键安装（Homebrew / winget） |
| TeX | 渲染 PDF | 一键装 tectonic；已有 xelatex 就是 ✓ |
| PyMuPDF、Pillow | 从论文 PDF 裁图、拼 panel | 一键用本机 Python 的 pip 装 |

写综述的话，这五行都要是 ✓。Mac 走 Homebrew，Windows 走 winget；Linux 页面会给出 apt / dnf 命令。装完点 **重新检测**。

Mac 没装 Homebrew 时：Git 这一行会弹出系统的 Xcode 命令行工具安装窗口，装完点 **重新检测**。Quarto 去 [quarto.org](https://quarto.org/docs/download/) 下安装包，TeX 装 tectonic 或 MacTeX。装好后再点 **重新检测**。没有 Homebrew 时，这两项没有一键安装。

### 第 2 步　让一家 AI 能用

**连接** → 在某家 Agent 卡片点 **安装**（没装过的话）→ **＋ 添加连接** → 选 **端点预设** → 贴 API Key → **验证并获取** → 保存。详见第 5 章。

**怎样算做成：** 卡片里出现这条连接，密钥只显示尾号，没有红字。

### 第 3 步　建一个课题

**项目 → 添加项目** → 选文件夹 → 填项目名 → 工作方式选 **科研** → **添加** → 选模板（写综述选 **英文综述**）。详见第 6、7 章。

### 第 4 步　指定课题默认的 AI

项目顶栏 **Agents** → 在配好的那家点 **设为默认**；点开连接名可选这个课题用哪个模型。只影响这个课题。

**怎样算做成：** 卡片上写着「项目默认」。

### 第 5 步　说上一句

- 问一句、改个错字：**＋新对话**（直接改课题文件夹）。
- 出一版要留存的成果：步骤上点 **开始**（AI 在工作副本里做，你验收）。

> **【配视频】** 诊断 → 添加连接 → 添加项目 → 设为默认 → 开聊。

## 4. 认路：左边九个入口

| 分组 | 入口 | 干什么 |
|---|---|---|
| 工作 | **工作台** | 进来第一眼。有 AI 在跑时显示「正在进行」+ **继续工作**；另有「待你处理」「待你验收」、最近项目与对话 |
| | **项目** | 课题的家。左边课题列表（按科研 / 编程 / 工作分组），右边当前课题。黄点 = 有事待处理，绿点 = 有 Agent 在跑 |
| | **运行** | 盯着 AI 干活。一个标签是一次运行，聊天和终端是同一次对话的两种看法 |
| | **对话** | 全部历史对话，按课题、按 Agent 回放 |
| 资源 | **连接** | 密钥、地址、模型 |
| | **技能** | 给 AI 的短说明书（如精读笔记写哪八节） |
| | **MCP** | 外部工具接口（Consensus、Undermind、Blender 等） |
| 管理 | **用量** | token 与花费、订阅余量、网关余额 |
| | **设置** | 外观、终端、网络（代理 / 学校图书馆）、更新、诊断 |

**待处理**（窗口顶上）只收「不拍板就卡住」的事：命令等确认、步骤可合并、有冲突、Mesa 有新版、Agent 写了求助条（例如某篇下不到）。AI 说完一轮等你下一句，不会进这里。

## 5. 连接 AI

没有连接，后面所有「开始」「问 AI」都跑不起来。目标只有一个：**至少一家 Agent 有一条能用的连接**。

### 5.1 安装 Agent 程序

**连接** 页每家一张卡，没装的颜色淡，点 **安装**。Mac 优先 Homebrew（国内镜像），Windows 部分走 winget，其余走 npm。安装过程是一个小终端，遇到 `[y/n]` 就在下面答。约 10 分钟完全没动静才算卡住。卡上出现 **新版** 就是可升级。

### 5.2 用 API 密钥 / 中转（最常见）

1. **＋ 添加连接**
2. **端点预设** 选供应商（DeepSeek、智谱、月之暗面、百炼、OpenRouter 等），地址和推荐模型会自动填。
3. 贴 API Key。保存后只显示尾号。
4. **验证并获取**：会真的发一次请求，成功后列出模型并勾上推荐项。失败按红字改，不要先保存。
5. 同一把密钥要给别的 Agent 用，勾 **同时绑到**。
6. 保存。

常见坑：

- Claude / CodeBuddy 的地址**不要**以 `/v1` 结尾；Codex / Kimi / Qwen 一般**要**带 `/v1`。
- 智谱给 Codex 用时，普通槽 `paas/v4`、Responses 槽 `api/v1`，勾「同时绑到 Codex」预设会自动补。
- Cursor 用自己的密钥和模型，第三方中转通常接不上。
- 写综述要检索、建文件，**模型必须支持工具调用**。

综述没有指定某一家。连接页能装上、**验证并获取** 通过、模型支持工具调用，就可以用来检索和写稿。上下文短的模型会在长稿上反复停。费用看用量页，不在这里估一个数字。

### 5.3 用官方订阅

Claude Code、Codex、Gemini、CodeBuddy、Cursor、Grok 支持。「账号类型」选 **官方账号**，组头点 **登录**，按终端提示完成（Codex 给设备码）。组头变成绿点「官方已连接」即可。

国内直连官方常失败：**设置 → 网络 → 出网代理** 填本机代理（如 `http://127.0.0.1:7890`），或点 **检测**。这份代理只给官方登录、官方启动、Agent 安装更新用，不影响走中转的连接。

### 5.4 连接行上的三个动作

- **编辑**：换密钥、加减模型。
- **停用此连接**（⋯）：不被自动选中，仍可手选。
- **解绑**（⋯）：删掉这家 Agent 对这条连接的使用，网关和密钥保留。注意：正在用它的定时任务**不会自动换别的 AI**，会在下次运行时失败并留记录。先去改定时任务再解绑。

### 5.5 只在 Mesa 里生效 vs 全局生效

默认只在 Mesa 启动时注入，不改你电脑上其他终端。想让系统终端也用这套：**⋯ → 设为全局默认**（会先备份，可撤销）。

### 5.6 模型能力查不到

新模型或改名模型被当成小窗口、贴图被拒时：**连接 → 网关库 → 编辑 → 模型策略 → 能力声明**，填上下文窗口、思考 / 视觉支持，**保存声明**。不确定的留「未声明」。

> **【配图】** 添加连接表单：预设、密钥、验证并获取、同时绑到。

## 6. 建课题：项目与工作方式

### 6.1 三种工作方式（添加时选一次，之后不能改）

| 方式 | 适合 | 主画面 |
|---|---|---|
| **科研** | 文献、实验、论文 | 研究流程步骤（或目标）+ 文献 + 文件 |
| **工作** | 工作文档、日常材料 | 目标 + 文件预览 |
| **编程** | 写代码、分支、PR | 工作树 |

再打开添加表单时，已选定的那一项后面写着「（已选定，不可更改）」。

真要换方式，另建一个项目。

### 6.2 项目的五个页签

三种工作方式都是这五个页签。中间那个的名字随方式变：**科研任务** / **工作任务** / **编程任务**。另外四个都叫 **对话 / 定时任务 / 文件 / Agents**。

| 页签 | 干什么 |
|---|---|
| **对话** | 这个课题里 AI 的记录，点一条回放 |
| **科研任务** | 有流程时看走到哪一步，点「开始」。点过「不使用研究流程」且没有步骤时，这里是目标列表 |
| **定时任务** | 文献雷达、定时巡检 |
| **文件** | 左目录右预览；PDF、笔记、表格 |
| **Agents** | 这个课题默认用哪家 AI、哪个模型 |

规则、课题主题、全局设定、验收记录在顶栏 **⋯ → 项目设置…**。

### 6.3 选模板

添加科研项目后弹出 **选择研究流程模板**：

- 可先填 **课题主题（可选）**，之后每次开工都会带给 AI。
- **英文综述**（5 步）→ 第 7 章
- 其他模板 → 第 8 章
- **不使用研究流程**：只读文献、写笔记
- **稍后再选**：只关弹层，项目页会继续提醒

> **【配图】** 添加项目表单；模板选择弹窗。

## 7. 科研项目：英文综述流程全程

这一章按真实顺序走完一篇英文综述。先看总览，再读「步骤卡通用操作」（7.2），之后每一步照着做。

### 7.0 总览

| # | 步骤 | 角色 | 你主要做 | AI 主要做 | 主要产出 |
|---|---|---|---|---|---|
| 1 | 文献检索与筛选 | 一起 | 定文献来源、拍板纳入 / 排除、补付费墙全文 | 检索、去重、按标准初筛、下开放获取 PDF | `papers/screening.md`、`included.md`、`included.json`、`to-fetch.md`、两份 RIS |
| 2 | 精读笔记 | 一起 | 确认精读篇目、边读边补想法 | 逐篇读 PDF 写八段笔记、补 `references.bib` | `notes/*.md`、`references.bib` |
| 3 | 大纲 | 你来 | 审大纲、决定章节框架 | 提炼研究空白、拆解范式综述、构造框架 | `manuscript/outline.md` |
| 4 | 初稿 | AI | 定正文字体、审稿、写意见 | 按大纲与笔记成稿、配图、渲染 | `manuscript/draft.md`、PDF、Word |
| 5 | 润色定稿 | 你来 | 定引用样式 / 目标期刊、逐条裁决审查报告 | 审查、润色、查引用、出最终稿 | `output/` 下 PDF、Word、EndNote 版、Zotero 版 |

「角色」对应步进器上的小点：实心强调色 = 你主要负责，灰点 = 你和 AI 一起定，没有点 = 主要是 AI。

一篇综述要多久、花多少 token，取决于纳入篇数和你用的模型，这里不给一个会过期的数字。用量页按这一次运行记账。示例课题可以先走通界面，再拿你自己的篇数估计。

> **【配图】** 五步大圆 + 角色小点图例。

### 7.1 应用模板：五项全局设定

选 **英文综述** 后进入「「英文综述」的项目全局设定」。五项都是自由填写，会贯穿全部五步：

| 设定 | 怎么填 | 输入框里的提示 |
|---|---|---|
| 综述角度 | 这篇综述要回答的核心问题 | 领域全景 / 聚焦某个子问题 |
| 目标篇幅 | 目标字数或页数 | 读者预期，如期刊常见 6000-8000 词；不是初稿必须凑到的词数 |
| 读者与文风 | 谁会读、什么口气 | 偏同行专家 / 偏入门科普 |
| 去向 | 投哪里 / 用在哪 | 投期刊 / 毕业论文一章 / 课程作业 |
| 综述深度 | **标准档** 或 **严格检索档** | 标准档 / 严格检索档 |

**综述深度怎么选**

- **标准档**（默认）：常规叙述性综述的检索与筛选。
- **严格检索档**：强制做引文扩展，题摘与全文分两轮筛，`screening.md` 末尾附检索披露。它**不是系统综述**，不产出 PRISMA 流程图级别的结论。

要做 PRISMA 流程图、全文双人筛选或 Meta 分析时，Mesa 这套流程不够。换专门的系统综述或统计工具，不要把严格检索档的产物当成系统综述。

拿不准的项点 **暂不填写，稍后补充**。空着的会以「综述角度：（…）」这样的括号形式留在 **⋯ → 项目设置** 的规则里，并出现在每一步任务书的「待确认的全局设定」中；AI 开工或跟你商量时会先逐项问你，你确定后它才改那一行。最后点 **保存设定并应用模板**。

稿件用 Word 还是 LaTeX、要不要进 Zotero，都不在这里问，到用得上的那一步再选。

**怎样算做成：** 科研任务页顶上出现五个大圆，第一个是当前步。

### 7.2 步骤卡通用操作（每一步都一样）

点任意一个大圆，下面出现**当前步骤卡**。没有内容的行不出现。有的话，从上到下是：

1. **确定文献来源**（这一步要问文献从哪来才有）
2. **稿件载体**（这一步会换正式稿才有）
3. **先定几件事**，还有没答的写成 **先定几件事（还有 N 件）**
4. 开工前的人工事项，标题就是事项名
5. **AI 干活：{这一步的名字}**
6. 进行中和收尾的人工事项，标题仍是事项名
7. **你核对后，保存进项目**（按钮是 **去评审**）
8. 分隔线左边写 **可选**。下面是保存进项目之后才做的事

#### 主按钮会变

这些字在对应那一行的右侧：

| 按钮 | 意思 |
|---|---|
| **开始** | 在 **AI 干活** 那一行。这一步还没开工。悬停写「直接开工也行，AI 会在对话里问你缺的信息」 |
| **去终端看看** | AI 正在做。会话判定已经跑完时，按钮左边有一行字 **Agent 已跑完** |
| **去评审** | 在 **你核对后，保存进项目** 那一行。有产出可以看了 |
| **去处理冲突** | 工作副本和主文件夹改了同一处，占掉「去评审」的位置 |
| **恢复工作区** | 这一步的工作副本已收起，占掉「开始」的位置 |

#### 开工前：先定几件事 / 跟 AI 商量

- 有开工前可定的问题时，卡片上是 **先定几件事（还有 N 件）**。展开 **直接选择（N 项待定）**，点选项；或点 **全部用推荐值**。都答完了这一行改成 **直接选择（已定）**。
- 想先聊：展开 **和 AI 商量（可选）**，点 **跟 AI 商量一下**。AI 通读任务书，逐个问你拿不准的地方，按你的回答改任务书。商量过后按钮变成 **继续讨论**，接回上次，不新开。
- 没有待定问题的步骤，**跟 AI 商量一下** 直接挂在 AI 那一栏，旁边是 **TASK.md**（打开这一步的任务书）。
- 只有卡片上标明必须批准的问题，不答才不能开始。其余问题 AI 会在跑起来、看到数据后再问你。

**想法卡片**：**聊想法** 回到这张卡上次的对话；**◈ 沉淀进任务书** 只在这一步还没开工时出现，AI 先写出要追加的结论，你改完再写入任务书。

#### 点「开始」之后：确认层

不会立刻跑，先弹确认层，标题是 **开始 {步骤名}**。里面列出：本步产物、已有材料（缺的必填写成「文件名 · 还没有」）、这次用哪家 AI（旁边 **更换**）、可展开修改的任务书。有连接时权限一行写死：「运行权限：写步骤工作区 + 主仓 papers/（原始文献）；派生产物经评审合并进主仓」。左下是 **取消**。

| 确认层按钮 | 意思 |
|---|---|
| **先加连接** | 这个课题还没有能用的 AI |
| **仅开始准备** / **先做无依赖工作** | 有决定没批准，只做不依赖答案的部分 |
| **仍要开工** | 上一步还有收尾事项没勾。先点「确认开始」，按钮变成它，再点一次才真开 |
| **记下并开始** | 你改过本步要读的文件（比如精读后又手改了笔记）。点了会先把这些文件存进历史再开工，新工作副本才看得到你的修改 |
| **确认开始** | 正常开工 |

#### AI 干活时

跳到 **运行** 页，可以用聊天或终端看它做事、插话。AI 按任务书里的 **决策暂停策略** 停下来问你（例如纳入标准没定、期刊没选）；写完一批、提交、报进度**不算**该停的点。

- 它在不该停的地方停了：**不要再点「开始」**。点当前步或工作台的 **继续工作** 回原终端，告诉它「不必拍板，做到完成标准」。
- 它需要你补信息时，会在收件箱写「人工请求」。点进去看完整问题，用 **去终端回答** 回到那次对话答复。不回复的话，它按每条后面写的兜底继续。

#### 评审与保存进项目

点 **去评审**。页签最多三个：

| 步骤 | 页签 |
|---|---|
| 检索 | **清单 / 过程 / 文件** |
| 精读 | **笔记 / 过程 / 文件** |
| 大纲、初稿、润色 | **稿件 / 过程 / 文件** |

- 顶上可能有黄字提醒：摘要含 [待核实]、正文含空白编号（G1…）、N 处「待绘制」。
- 保存进项目之后，精读步的可选区会出现 **继续精读笔记**，按钮是 **去笔记夹**。
- 意见框：写意见，或在稿件里划一段点 **加进意见**。
  - **退回修改**：接回原对话，按意见改现稿。
  - **按意见重写**：同一工作区新开会话，从大纲和笔记重写（会先确认）。
  - 这两个都**不会**保存进项目。
- 满意了点右上 **提交并保存进项目**（没有待提交改动时叫 **保存进项目**）。
- 保存后若出现 **沉淀到下一步**，点 **◈ AI 起草**：只写这一步已定死、下一步容易改回去的决定，以及还等你确认的事项。没有就留空。

**保存进项目只表示文件进了课题，不表示你接受了其中的科学结论。**

两边改了同一处时是 **去处理冲突**：按文件选「用任务这一版」或「用主文件夹这一版」；要逐行掺，去预览编辑器手改。

**沉淀到下一步** 在这一步已经保存进项目、而且模板里还有下一步时才出现。最后一步没有它。点开后可以 **◈ AI 起草**，也可以自己写；留空就不写。写进去的是下一步任务书，不是这一步的稿子。

> **【配视频】** 开始 → 确认层 → 运行页 → 去评审 → 保存进项目。

### 7.3 第 1 步：文献检索与筛选

**目标：** 得到一份你拍板过的纳入清单，能拿到的全文都进 `papers/`。

#### ① 开工前：三件人工事项

**确定文献来源**（整个课题只在这里问一次）：

| 选项 | 适合 | 之后去哪 |
|---|---|---|
| **让 agent 检索** | 从零开始 | 「去补几篇 →」可先手动放几篇种子文献 |
| **我有 Zotero 库** | 已在 Zotero 里攒了文献 | 「去导入 Zotero 库 →」 |
| **我有 EndNote 库** | 已在 EndNote 里攒了文献 | 「去放入 EndNote 题录 →」：导出 XML 或 RIS 放进 `papers/imports/` |
| **我已有 PDF / 题录** | 手里有一堆 PDF 或 .ris/.bib | 「去放入题录 / PDF →」 |

这些链接都跳到 **项目设置 → 文献与数据**。选了 Zotero，检索和精读步会自动挂上 zotero-sync 技能。

Zotero 用户的建议设置：关掉「自动重命名附件文件」，打开「自动检索 PDF 元数据」。要与项目共用同一份 PDF，用「链接到文件」，并把链接附件根目录指到项目的 `papers/`。
EndNote 用户注意：不要把 `papers/` 设为 EndNote 自动导入文件夹（它可能把 PDF 搬走）；Mesa 不读 `.enl`。

**配置学术检索 MCP**（推荐）：点 **Consensus** / **Undermind** 跳到 MCP 页预设。

- Consensus：填 API 密钥（填在密钥栏，不要写进命令）。
- Undermind：点 **去终端登录** 做一次浏览器授权。
- 两样都齐了这一项自动打勾；缺哪样旁边会写「Consensus 还没填密钥」「Undermind 未登录」等。
- 不配也能跑，AI 会用 OpenAlex 等免密钥来源。

**【待补充：Consensus / Undermind 的注册地址、是否收费、国内网络能否直连】**

**登录学校账号**（有付费墙文献时）：见下文 ④。

#### ② AI 做什么

1. 按综述角度拆概念块、写检索式，在各数据源检索，逐条记检索日志。
2. 去重，按拟定的纳入 / 排除标准初筛。
3. 把初始命中数和建议标准写进求助条问你（收件箱「人工请求」）。
4. 标准档按需做引文扩展；严格检索档强制做，并分题摘、全文两轮筛。
5. 下载开放获取 PDF 到 `papers/`，付费墙的列进 `to-fetch.md`。

`screening.md` 的固定结构：深度与假设 → 纳入 / 排除标准 → 概念块与检索词 → 检索日志表 → 逐篇决定 → 引文扩展轮次 → 覆盖缺口声明（严格档再加检索披露）。

#### ③ 你拍板：核对待确认篇目

人工事项 **核对待确认篇目** 展开是一份三段清单：

- **待确认**：每行标题、年份、作者、期刊，贴 **IF**、中科院 **N区**、**TOP** 标签（1 区和 TOP 用强调色，2 区绿，3 区黄）。有 PDF 的标题可点，在文件页预览。
  - 单篇 **纳入** / **排除**；批量先勾选，再 **纳入所选** / **排除所选**。**全选** 只选当前看得到的行。
  - **排序**：清单原序 / 影响因子从高到低 / 从低到高。
- **已纳入**：单篇 **移出**，或 **全选** 后 **移出所选**。移出 = 改成排除，从纳入清单、待获取、两份 RIS 里拿掉；PDF、笔记、`references.bib` 不动（已有笔记时行上会提示去精读步清理）。
- **已排除**（默认折叠）：**恢复为待确认**。恢复不会自动写回待获取，再次纳入才补上。

全部篇目都处理完，这一项自动打勾。

**影响因子标签**需要先下载期刊指标表（约 7MB，有版权不随安装包）：清单顶上点 **下载期刊指标表**。之后打开清单会对一次上游，写「指标表已是最新」或「指标表有新版」+ **更新**。没装表时没有标签，也不会编数字。

**【待补充：纳入 / 排除标准怎么写比较好，给一个你们领域的示例】**

#### ④ 付费墙全文：下载付费墙文献全文

纳入但没有 PDF 的篇目进人工事项 **下载付费墙文献全文**，展开 **待获取（还缺 N 篇）**，一行一篇。**一篇一篇来，不要批量下载**，出版商会封学校 IP。

**先登录一次学校账号**：点 **登录学校账号** → 打开 **设置 → 网络**，默认走 CARSI，选学校、完成账号和二次验证。登录在你的浏览器里完成，Mesa 不存密码。校外打不开全文时，展开 **校外打不开全文时**，贴图书馆「校外访问」链接（形如 `https://proxy.学校.edu.cn/login?url=`），之后点「官网」会先走代理。

**每一篇三个动作：**

1. **官网**：默认浏览器打开出版商页面，你用网站自己的下载按钮下 PDF。按钮变成 **等待收货…**（旁边有 **取消**），约 90 秒内落下的 PDF 会收进 `papers/`，行上变 **✓ 已存**。
   - Mesa 会看系统「下载」文件夹，以及 Chrome、Edge、Firefox 设成默认的下载文件夹。
   - 装了 Mesa 文献收货扩展（Chrome / Edge）时，下到别的文件夹也能收到。
2. **关联**：已经下到别处的 PDF，点它选文件，复制进 `papers/`，原件不动。
3. **核对**：变成 ✓ 已存后，点标题跳到文件页看 PDF，确认是这一篇。切回「科研任务」，清单停在原处。

文件名对不上时右下角会弹横幅，可以一键收进刚打开的那篇。实在下不到的可以不补，这篇之后按摘要处理。

**【待补充：Mesa 文献收货扩展的安装方式（商店链接或本地加载步骤）】**
**【待补充：你们学校的 CARSI / 校外访问链接示例，或说明「问图书馆要哪个链接」】**

> **【配视频】** 登录学校 → 点官网 → 下载 → 变已存 → 点标题核对。

#### ⑤ 产出与完成标准

| 文件 | 内容 |
|---|---|
| `papers/screening.md` | 检索全过程（可复现） |
| `papers/included.md` / `included.json` | 纳入清单（json 里也留着被移出的记录和理由） |

**怎样算做完：** 待确认为 0；你看过检索过程，覆盖缺口可以接受；能补的全文都补了；**保存进项目**。

### 7.4 第 2 步：精读笔记

**目标：** 每篇读完的文献都有一份结构化笔记，`references.bib` 齐全。

#### AI 做什么

确认精读篇目后，AI 逐篇读 PDF，**只给读完的篇写笔记**，没读完的在索引里记 pending，不算「已读」。把英文摘要整段贴进来不算精读。叙述用中文，术语可留英文。每篇八段：

1. 一句话总结
2. 研究问题
3. 方法
4. 主要结果
5. 局限（分「作者自述的局限」和「本笔记识别的局限」）
6. 可引用点（末尾标可引用图：可拼 / 仅引用）
7. 与本课题的关系
8. 疑问与待跟进

同时往 `references.bib` 追加规范 BibTeX 条目。

**【待补充：篇数多时（例如 >50 篇）建议怎么分批，每批多少篇比较稳】**

#### 你做什么：三栏沉浸阅读

在 **文件** 页悬停 PDF 或 `notes/` 里的笔记，点 **⛶ 沉浸阅读**（示例课题的精读步可直接点 **开读这一篇**）。屏幕分三栏：

- 左：**笔记**（已有笔记会自动配对）
- 中：**PDF**，可滚动、缩放、选字
- 右：**Agent 终端**，随时问

在 PDF 里选一段，浮动条有 **译**、**◈ 问 AI**、**＋ 生词**（选段较短时）和 **⋯ → 直接发送**。工具栏 **圈选** 可以框一块区域，再 **◈ 发给 agent** 或 **＋ 插入笔记**。

按 **Esc** 退出（在圈选模式里先退出圈选）。退出后回到进入前的页面，这次自动开的阅读标签一起关闭。

#### 可选事项（保存进项目后才能点）

- **继续精读笔记 → 去笔记夹**：打开文件页的 `notes/`，继续挑一篇三栏阅读。
- **同步到文献库**：**同步到 Zotero**、**同步到 EndNote**、**打开 papers**。按 `references.bib` 重写 RIS 后交给对应软件；再把 PDF 从 `papers/` 拖到库里对应条目上。不要把文件拖进 EndNote 窗口。

精读后又手改了笔记：开大纲时确认层写「开始时会先记下 N 个这一步要读的文件，再开工」，按钮是 **记下并开始**，点它即可，大纲步就看得到。

**怎样算做完：** 纳入篇目都有笔记或明确的 pending 理由；文件页「已读」对得上；**保存进项目**。

> **【配图】** 三栏阅读，标出选段浮动条和圈选。

### 7.5 第 3 步：大纲（你来）

**目标：** 一份有论点、有研究空白支撑的章节框架，而不是把文献按主题堆起来。

#### AI 做什么

1. **判定综述形态**（叙述性、主题式、方法比较等）。
2. **提炼研究空白清单**：从笔记的「局限」「可引用点」和文献前言里抽，每条标类型（证据 / 知识 / 实践 / 方法 / 经验 / 理论）。只有一篇来源支撑的标 **孤证**。
3. **拆解 2–3 篇权威综述**，每篇写成一张五要素范式卡片。
4. **融合构造框架**：范式做骨架，空白做导向。
5. `outline.md` 末尾写 **## 框架推演**（空白清单 / 范式卡片 / 融合理由），加覆盖声明和完成自评。

#### 你做什么

这一步角色是「你来」，大纲决定了后面全部写作。评审时重点看：

- 核心论点是不是你想回答的那个问题（对照「综述角度」）。
- 研究空白是否真实，孤证是否被当成了定论。
- 章节顺序是否讲得通，有没有漏掉你知道的重要方向。
- 选的范式综述是否是领域公认的。

不满意就写意见 **退回修改**；方向完全不对就 **按意见重写**。

**【待补充：你期望的大纲颗粒度（写到二级标题还是三级、每节是否要列出计划引用的 bib 键）】**

**怎样算做完：** 你认可框架推演里的融合理由；**保存进项目**。

### 7.6 第 4 步：初稿

**目标：** 一份完整英文初稿，能渲染成 PDF 和 Word。

#### 开工后你要回答：正文字体

初稿开工后、第一次渲染前，AI 会问一次正文字体。默认英文 **Times New Roman**、中文 **宋体**，可以改成别的名字。字体必须在本机装好，没装会直接报错，不会偷偷换字体。定稿沿用这一套。

这个问题在 AI 开工后的对话里问，不在「跟 AI 商量一下」里（那边只改任务书）。回答会写进 `manuscript/typeface.md` 和 `manuscript/reference.docx`，第一次渲染就用这套字。

#### AI 做什么

- 按大纲、笔记、`references.bib` 写正文。遵守 review-writing 规范：
  - 观点先行，引用为证，不堆砌文献。
  - 引用只用 `[@bib键]`，**严禁编造文献**。
  - 没有依据的论断标 **[待核实]**。
  - 需要作图但没有数据的地方写占位「待绘制」，不虚构数据。
- 引用样式固定为方括号编号 `[1]`，这一步不问。
- 需要文献图时，从论文 PDF 裁源图、拼 panel（review-figures）；不能拼的改成「引用 Fig. n」。源图放 `figures/`。
- 用 Quarto 渲染 PDF 和 Word。

#### 你做什么：评审稿件

**稿件** 页签里 Word 在 PDF 前面；PDF 页签先看有没有乱码。顶上黄字列出 [待核实]、空白编号（G1…）、「待绘制」的数量。

- 逐段看论证和引用是否对得上。怀疑某个引用，打开对应笔记或 PDF 核对。
- 划一段 → **加进意见** → 写怎么改；全部写完 **退回修改**。

**【待补充：学科惯例上初稿阶段哪些问题该在这里改、哪些留到润色（例如语言问题是否留到第 5 步）】**

**怎样算做完：** 结构和论点你认可；[待核实] 的数量你心里有数（定稿会逐条处理）；**保存进项目**。

---

### 7.7 第 5 步：润色定稿（你来）

**目标：** 可投稿的终稿，引用闭环，四种格式齐全。

#### ① 开工时：引用样式

AI 会先问：初稿是编号制，**沿用**编号，还是**改成目标期刊**的样式。你也可以随时在流程线上点 **更换引用样式**：

| 类型 | 选项 |
|---|---|
| 编号 | 方括号 `[1]`、上标 `¹` |
| 作者-年 | `(Author, Year)`、`(Author Year)` |
| 按期刊 | 从文献里出现最多的期刊中选，或自己填刊名 |

选「按期刊」时，AI 先读该刊作者须知，再拿 `references.bib` 里该刊最近 2–3 篇综述核对实际排法；两边不一致会停下来问你。确认了期刊才会写 `submission/target-journal.md`；沿用编号时不写。

选定后 AI 回到这一步原对话，重新渲染 PDF 和 Word，并重新生成两份带引用域的 Word。

还没换样式时，AI 沿用初稿的编号照常渲染，不会停下来等你。

#### ② AI 做什么

- 按审查规范写一份**审查报告**：语言、逻辑、引用、统计口径（stats-check）、引用闭环（bib-check：正文引用与 bib 是否一一对应、疑似编造、未引用条目）。
- 润色只改表达，不改观点。改动了数字、因果、样本或结论范围的，单列在修改记录的「科学改动」里。

#### ③ 你做什么：逐条裁决

报告写出后，步骤上出现裁决列表：

- 每条选 **接受** / **拒绝** / **修改**（选修改必须写一句要改成什么样）。
- 或点 **全部接受**。
- 全部点完后点 **让 Agent 按决定继续**，AI 回原对话改稿。拒绝的不改。

**逐条裁决** 只在定稿还有 [待核实] 或引用存疑时才有条目（每条「裁决：」都填完、没有「待裁决」才算完成）；没有条目时写「勾上跳过」。

**【待补充：[待核实] 的裁决原则建议（找到文献支撑 / 删掉论断 / 降级措辞），给用户一个判断准则】**

#### ④ 产出

| 文件 | 用途 |
|---|---|
| `output/*.pdf` | 阅读、投稿 |
| `output/*.docx`（Quarto 渲染） | 只供阅读，换不了文献软件的样式 |
| `output/endnote.docx` | Word 打开 → **Update Citations and Bibliography** 一次，之后可在 EndNote 里换样式 |
| `output/zotero.docx` | Word 打开 → Zotero 工具栏 **Refresh** 一次，之后可换样式 |
| `submission/target-journal.md` | 仅确认了目标期刊时 |

拼图会嵌进两份域稿。LaTeX 稿不交这两份。Mesa 不会替你点 Word 里的按钮。

**【待补充：投稿时 EndNote 版和 Zotero 版该选哪份交给期刊的建议】**

**怎样算做完：** 裁决全部处理；引用闭环；PDF 和 Word 打开无乱码；**保存进项目**。

### 7.8 完结文件

五步都保存进项目后，项目卡上出现 **完结文件**，一处看全所有交付物：

- 最终稿 / 可以接着改的稿
- 图
- 文献从哪来（检索记录、纳入清单）
- 核对与修改（审查报告、修改记录、待核实裁决；目标期刊只在写过那份文件时才列）
- 精读笔记（每行是论文题名，右边是对应 PDF，没有全文写「无全文」）

后来又追加了步骤、还没做完时，这一块先不出现。

### 7.9 常见问题（综述流程）

| 现象 | 处理 |
|---|---|
| AI 做了一半停下来问「要不要继续」 | 不要点「开始」。**继续工作** 回原终端，说「不必拍板，做到完成标准」 |
| 下一步看不到我手改的笔记 | 从确认层的 **记下并开始** 开工；已经开了的话，回主文件夹把改动存进历史，再 **退回修改** 让 AI 重读 |
| 待获取点了官网一直不变已存 | 看是否超过约 90 秒、是否下到了没被监视的文件夹；用 **关联** 补 |
| 渲染失败、PDF 出不来 | **设置 → 诊断** 看 Quarto、TeX 是否 ✓；字体是否装在本机 |
| 拼图失败 | 诊断页 PyMuPDF、Pillow 是否 ✓ |
| 想中途换目标期刊 | 流程线 **更换引用样式 → 按期刊** |
| 正在做的课题想换新版模板 | 不要整套替换。已有课题保持原步骤，新课题才带新要求 |

## 8. 其他科研模板与不使用流程

### 8.1 其他模板

| 模板 | 步数 | 路径 |
|---|---|---|
| **科研论文** | 8 步 | 文献检索与筛选 → 精读与研究空白 → 实验设计 → 执行 → 分析 → 论文大纲 → IMRaD 初稿 → 投稿准备。湿实验或问卷要自己改实验步 |
| **数据处理** | 4 步 | 数据登记与质量检查 → 清洗整理 → 探索性分析 → 结论与建议报告 |
| **毕业论文** | 8 步 | 文献检索与筛选 → 精读笔记 → 开题报告与综述 → 研究方法 → 实验执行 → 结果分析与章节 → 全文初稿 → 格式与定稿 |
| **投稿与返修** | 卡片上 2 步 | 首投是期刊格式适配 → 投稿材料。点进去先选 **首投** 或 **返修**；返修按轮次，每一轮是「审稿意见回复（第 N 轮）」 |
| **LaTeX 论文** | 4 步 | 搭建骨架 → 章节写作 → 编译与排错 → 定稿导出。有成稿就转排版，也可以从笔记从零写 |

步骤卡的操作和第 7.2 节完全相同。润色、定稿、期刊格式、返修步都会先写审查报告，再逐条裁决。

**投稿与返修** 先选分支。

- **首投**：期刊格式适配 → 投稿材料。材料包括 cover letter、投稿前自查、投稿清单。
- **返修**：填返修轮次。这一步叫「审稿意见回复（第 N 轮）」。你先把编辑来信存成 `reviews/round-N.md`，AI 再写回复信、修订稿和修改对照。科学改动要你逐条决定之后才进修订稿。

科研论文、数据处理、毕业论文、LaTeX 论文的逐步说明还没有单独写。点进去之后，每一步的卡片和英文综述同一套操作。

### 8.2 不使用研究流程

适合只读文献、写笔记，或还不想定步骤。

科研任务页变成 **目标** 列表：**新建目标**，写一句话，可以先「记下」再「开始」。默认在隔离副本里做。跑完按钮是 **验收产物**，勾选要留下的再点 **接受 N 项**。不满意写意见，点 **带着意见再出一版**，还是同一个目标接着改。

有研究流程时技能已挂在步骤上；没流程时在 **项目设置** 的规则里勾技能和「写回时跳过」路径。

## 9. 文献雷达：自动盯新文献

项目的 **定时任务** 页，上半是 **文献雷达**。

### 9.1 订阅

雷达卡头点 **订阅**，一行一条：关键词、来源（arxiv / openalex / crossref，可多选）、备注（可选）。**＋ 加一行** 加一条，行尾 × 删掉。也可以点 **编辑源文件**，在同一个弹窗里直接改 `papers/watchlist.md`（先保存已在盘上的订阅，没存的改动不带过去）。还没有订阅时卡头写「文献雷达 · 还没订阅读」。

### 9.2 定时跑

**＋ 定时巡检** → 选 **文献雷达** → **每天** 或 **每周** 几点。**运行配置（可选）** 的提示是：「文献雷达选 Codex。没有后缀的只在课题目录里写。写着「会批准全部操作」的不要用于定时巡检。」

到点后在**隔离目录**里跑，不直接改课题文件夹。雷达卡上写「隔离树有 N 条新命中，尚未采纳进主仓」；「待处理」出现「有 N 条新命中待评审」+ **去评审**。评审里点 **采纳进主仓**（会先确认、查冲突、备份原文件），按钮变 **已采纳**，新文章才进 `notes/inbox.md`。

- 应用没开就不跑；下次打开补跑一次。
- 单次最多约 10 分钟。

### 9.3 读雷达

两行一条：标题 + 中文一句话，点标题展开英文摘要。开放获取有 **↓ 全文**；只有 DOI 的试 **获取全文**（只找合法开放副本）。想精读的点书签。

**【待补充：综述写完后，雷达如何配合「补新文献进综述」（例如投稿前再跑一轮）】**

> **【配视频】** 订阅 → 建每日雷达 → 立即跑 → 采纳一条。

## 10. 运行页与历史对话

### 10.1 运行页

一个标签一次运行。右上两个小图标切 **聊天 / 终端**，是同一次会话：

- 聊天：Enter 发送，Shift+Enter 换行。技能 / MCP 菜单只插入提示，不替你发送。
- 终端：各家 AI 原生界面，登录、权限确认、`/model` 在这里。

启动前中间有「将在某某文件夹启动」和 **运行**；上方三截是 Agent / 配置 / 模型。跑起来后点 **修改** 查看本次身份（要换需先停止）。右侧是 **文件** 和 **改动**。

- 转圈虚线圆 = 正在写回答；黄点 = 等你确认权限。
- 关掉标签不等于扔掉运行，工作台 **继续工作** 能找回。
- 图或文件可以拖进终端、⌘V 粘贴。选中文字有 **复制 / 复制文本 / 查看**。

### 10.2 历史对话

侧栏 **对话** 是全局总账；项目里的 **对话** 页签只列本课题。点一条回放，**恢复** 在 Mesa 里接着聊，**⇗ 外部恢复** 用系统终端接着聊。换电脑用 **导入 / 导出会话包**（原文可能带路径，发出去前先看一眼）。雷达、巡检这类后台 AI 在「内部 AI」里。

## 12. 技能与 MCP

**技能** 是给 AI 的短说明书。有研究流程时开步自动带上，不必手选。综述流程用到的内置技能：

| 技能 | 哪一步 | 管什么 |
|---|---|---|
| lit-search | 检索 | 分档检索、筛选、留痕 |
| lit-notes | 精读 | 八段笔记、BibTeX |
| zotero-sync / endnote-bridge | 检索、精读、定稿 | 文献软件桥接 |
| review-framework | 大纲 | 空白清单、范式卡片、框架推演 |
| review-writing | 初稿、定稿 | 综述写作约束 |
| review-figures | 初稿 | 从 PDF 裁图拼板 |
| quarto-render | 初稿、定稿 | 渲染 PDF / Word |
| bib-check、stats-check | 定稿 | 引用闭环、统计口径审查 |

技能页可以创建、从 GitHub / ZIP 导入，用右侧开关分发给各家 Agent。内置技能只补没有的，不覆盖你改过的。页顶出现「内置技能有新版」时点 **查看差异**，确认后 **备份并采用新版**。

**MCP** 接外部服务。学术检索用 Consensus（预设 + 密钥）和 Undermind（预设 + 去终端登录），见 7.3。Grok 的 MCP 只能在 Grok 里用 `grok mcp add` 添加。Blender、Origin 是可选，用得上时再配（Origin 仅 Windows）。

## 13. 用量、外观与设置

- **用量**：今天 / 7 天 / 30 天花费；官方订阅显示「订阅」。配了智谱 Coding Plan、Kimi For Coding、MiniMax Coding Plan 时有 **订阅余量**；配了 New API 类预付钱包网关时有 **网关余额**（需在网关库填系统访问令牌）。
- **设置 → 外观**：七深七浅主题，可自定义三色；侧栏 / 顶栏透明度可调。
- **设置 → 外观**：终端的字号、字体、渲染方式也在这里（设置里没有单独的「终端」分区；改渲染方式需重开标签）。
- **设置 → 集成 → AI 专用配置**：提交信息、摘要、翻译用哪条配置。
- **设置 → 网络**：出网代理、学校图书馆。
- **设置 → 更新**：下载安装后自动重启，先保存进行中的对话。
- **设置 → 诊断**：环境检查、**导出诊断包**（不含密钥）、生效配置快照。

## 14. 卡住了怎么办

| 现象 | 处理 |
|---|---|
| Mac 说应用已损坏 | `xattr -cr /Applications/Mesa.app` |
| 按钮没反应 | 找页面中间有没有内联输入框或确认层；仍不行导出诊断包 |
| AI 只说话不建文件、不检索 | 模型不支持工具调用，换一个支持 tools 的 |
| 保存了配置，一运行就 404 | Claude 类地址不带 `/v1`，Codex / Kimi / Qwen 类通常要带 |
| 官方账号 token revoked | 订阅过期，到连接页重新登录；国内配出网代理 |
| 改了模型 `/model` 还是旧的 | 只对新开标签生效 |
| 想一次下几十篇付费墙 | 不要，会封学校 IP |
| 工作区里的对话找不到 | 在所属课题的「对话」里，带步骤名 |
| 改动面板报找不到 git | 诊断页一键安装；Mac 先处理 Xcode 许可弹窗 |

问题与想法提到 [GitHub Issues](https://github.com/hongtongzhou-design/ccode/issues)。附上 **设置 → 诊断** 导出的日志。不要贴 API 密钥或 token。
