### 1.2 正面确认（约定落实良好）

1. **版本纪律**：package.json / Cargo.toml / tauri.conf.json 均 0.1.0，与 tag v0.1.0 一致；CHANGELOG「未发布」段在持续维护（含 ba77112 等近期条目）。
2. **进程创建纪律**：全仓仅约 20 处裸 `Command::new`，逐个核对——全部位于 `#[cfg(test)]` 测试辅助、`#[cfg(target_os="macos")]`（open/osascript/pgrep）或 `#[cfg(all(unix, not(target_os="macos")))]`（Linux 终端）门控内；生产 git 调用走 `process::background_command`（coding.rs:1433 等），包装使用面广（git_info 10 处、workspaces 8 处、portwatch 6 处）。
3. **前端不碰文件系统**：全前端无 showOpenDialog/fs API 直用；一切经 Tauri command ✅。
4. **主题亮暗单一出处**：无绕过 `themes.ts` 的自制 `data-theme` 判定 ✅。
5. **密钥文件权限**：keys.json 主文件 0600（agents.rs:1716）、密钥备份 0600（agents.rs:2852/2891）、目录 0700（agents.rs:1626）✅。
6. **脱敏调用面广**：redact_sensitive_text/redact_and_cap 覆盖 18 个后端文件（handoff 10、sessions 9、runs 8、ai 7…）；具体出站缺口留第 3 批逐条核对。
7. **UI 文案中文**：抽查英文命中均为术语/枚举值 placeholder（effort 档位、URL 示例、aria-label）✅。
8. **调色板双端同步**：KNOWN_PALETTES 与 terminal-palettes.ts 均为 8 套且 id 一一对应 ✅。
9. **allow(dead_code) 基本合规**：绝大多数为约定要求的 `cfg_attr(not(any(unix, test)), allow(dead_code))` 形式；FN_TRANSLATE 有注释说明 JS 侧引用。
