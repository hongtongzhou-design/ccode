# 科研流程优化与小项目试跑

日期：2026-09-08。范围：模板减重、决策摘要、验收入口、可执行复现、两类小项目试跑；没有改写用户已有科研项目或本机技能副本。

## 结论与边界

这轮优化让任务书减少重复要求，并提供报告中的单一验收入口。两类试跑均生成了实际可检查产物、从独立输出目录重建结果，并拒绝8类预先注入的错误。

**不能据此声称**新手效率提升、Agent 不会幻觉、自动语义核验成立、独立人类研究复现成功，或项目可以投稿。文献支持范围由执行助手阅读后注释；脚本只检查键、版本、覆盖和显式审查状态。计算使用合成数据，不是新科学结论。没有启动多 Agent 或替用户签字。

## 1. 已落实的五项优化

| 优化 | 落地 | 证据 |
|---|---|---|
| 模板减重 | 共用质量/变更约束单处生成，项目规则不再复制；清理固定要点/批判配额 | `src/pipeline-presets.ts`、相关技能、字符比较 |
| 人工决策减负 | 先给问题/方案/证据/代价/等待边界，人选择或要求补证据；旧问题键不改 | `src/task-md.ts`、G1/G2 简报、持久化回归 |
| 验收入口 | 原报告开头五项摘要，细节链接原记录；格式适配不重复 G5 | 试跑报告头、模板 tests |
| 可执行复现 | 计算项目专用脚本/明确输入输出/版本检查/参考容差/实际执行 | 两次独立命令执行与 `verification.json` |
| 真实材料小试跑 | 两篇公开论文的有限综合 + 36项合成实验 + 失败控制 | 仓库外完整项目与故障记录 |

## 3. 文献型试跑

问题：为什么在同一个有限样本评价结果上选择模型并报告性能可能乐观？

- 范围：两篇方法论文的定向检索与有限叙述性综合，不是系统综述。网页搜索工具没有返回有效结果，故采用已知标题访问原始出版来源；没有虚构数据库命中数。
- Cawley & Talbot (2010), *On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation*, JMLR 11:2079–2107。读取官方29页 PDF；论点定位 Abstract p.2079、§4、§5。
- Varma & Simon (2006), *Bias in error estimation when using cross-validation for model selection*, BMC Bioinformatics 7:91，DOI `10.1186/1471-2105-7-91`。PMC 返回验证页，未当作全文；读取出版方 HTML 的 Abstract、Results/Implementation 与 nested CV 方法。
- 实际交付：检索/筛选记录、稳定ID清单、两份八段笔记、引文库、证据注释、大纲、短稿、引用核对、来源哈希。
- 支持性结论：可以有限地说明选择准则的过拟合和选择/评价分离；不支持“嵌套CV在任意条件下严格无偏”。后者作为错误主张由助手回原文判定超界，再由复现入口拒绝未解决状态。
- 没有独立人类终审；所有草稿保留待审状态。

来源地址存于 `tests/fixtures/research-pilot/literature.json`。不提交第三方全文；实际获取路径、日期、哈希与跳转保存在产物 `source-fetch-log.json`。

## 4. 计算型试跑

固定种子20260908；12个独立合成数据集，每个包含 train=24、selection=24、heldout=128，特征与标签均为独立±1变量。候选特征数1/8/32，共36项。训练集决定方向，selection选特征，heldout不参与选择。停止规则、主描述指标和一个故障控制在执行前写入方案。

数据画像覆盖全部生成字段的取值/计数，缺失数0；分析单元为独立合成数据集，候选数间配对。只报告描述性均值，不生成 p 值或伪造CI；无需为了“全面”画无关字段相关矩阵。

| 候选特征数 | 运行数 | Selection准确率 | Held-out准确率 | 差值 |
|---:|---:|---:|---:|---:|
| 1 | 12 | 0.517361 | 0.513021 | 0.004340 |
| 8 | 12 | 0.642361 | 0.505208 | 0.137153 |
| 32 | 12 | 0.697917 | 0.480469 | 0.217448 |

这是固定合成试跑的探索性模式，不证明任意模型/数据上的效果；也不是两篇论文原算法实验的复现。主实现按匹配计数，复核用±1编码平方误差独立算术还原准确率；36项全部一致，容差 `1e-12`。生成SVG已渲染查看，标签/数据可读；不是投稿级图表验收。

交付冻结数据、计划/结果矩阵、原始预测、失败日志、manifest、实现检查、统计报告、图、简短稿、独立复现入口。唯一失败是预先声明的空输入故障控制，保留日志且按设计不计入成功均值；不是事后挑掉不利结果。

## 5. 故障注入结果

| 注入 | 检查结果 | 限定 |
|---|---|---|
| 关键全文降为摘要 | 阻塞：critical full text missing | 依赖明确全文状态 |
| 引用键指向另一篇 | 阻塞：citation key/source mismatch | 检查映射，不理解论断 |
| 任意条件严格无偏 | 阻塞：claim support unresolved | 支持性由助手阅读判定，非脚本自动发现 |
| 来源文字版本变化 | 阻塞：source version changed | 哈希检测，不判断变更内容 |
| 结果矩阵漏一项 | 阻塞：plan/result ID mismatch | 检查集合覆盖 |
| 冻结数据变化 | 阻塞：data version changed | 不偷偷重算覆盖参考 |
| 汇总指标增加0.2 | 阻塞：reference mismatch | 参考值也需可信版本 |
| 失败日志丢失 | 阻塞：failed run log missing | 不把失败当不存在 |

故障输出校验发生在最终文件写入前；失败不产生伪“通过”结果。另有离线回归检查拒绝复用已有输出目录、拒绝把输出写进输入项目。源素材在CI中是明确标注的合成占位，只测试机制，不冒充真实文献试跑。

## 6. 可复现执行

仓库脚手架只依赖 Python 3.10+ 标准库；不调用任何CLI Agent、外部账户或用户科研目录。创建输出必须是新目录。

```bash
python3 scripts/research-pilot.py create \
  --sources /path/to/frozen-extracted-fulltexts \
  --literature tests/fixtures/research-pilot/literature.json \
  --output /path/to/new-pilots

# 在生成的 computational 项目中执行交付脚本
python3 experiments/reproduce.py reproduce --input . --output ../new-computational-check

# literature 项目同样执行，输出为综合稿与检查记录
python3 experiments/reproduce.py reproduce --input . --output ../new-literature-check

node --experimental-strip-types --test tests/research-usability.test.ts
```

源目录需提供 `cawley2010-fulltext.txt`（官方PDF抽取）与 `varma2006-fulltext.txt`（出版方HTML抽取）；原始获取和抽取记录保留在产物里。若改脚本、计划、输入或参考，不应伪装为原版本的成功复现。
