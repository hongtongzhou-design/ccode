# Mesa Codex 风格界面设计规格

> 2026-09-25：完全隐藏侧栏后，顶部导航从「幽灵胶囊」改为常驻灵动岛。旧结构是一条 12px 隐形热区 + 悬停唤出、2.5 秒后自己跑掉的胶囊，全收起后窗口顶部是空的，用户不主动去摸就以为导航没了。现在岛常驻两态：休眠态＝只有「恢复侧栏」一个元素；展开态＝完整导航（分组 / 快速开聊 / 恢复侧栏），悬停或聚焦展开。休眠态的「恢复侧栏」**恒带文字**，不跟 `navCapsuleDisplayMode` 走——那个设置管的是展开态里那排导航项（那里是"一排"，才有符号/文字之分），而休眠面只有一个控件、不是一排；仅符号模式下若它也只剩图标，休眠面就退回「一个孤零零的光图标」，看不出是入口、也看不出悬停会展开整排导航。展开面仍按模式走，两副面孔的字因此可能不同，但它们淡入淡出、不会同时在场。休眠态**不**放当前页高亮块——先前「恢复侧栏 + 当前页」两颗圆图标并排塞在小胶囊里读起来像开关，且那个块点回当前页等于把页面设成它自己，当前页信息页头本来就有。几何：岛不再是视口浮层，而是 `.ccode-titlebar` 内的绝对定位子元素（`position: absolute; top/left 50%; translate(-50%,-50%)`）——标题栏横贯整窗、宽度不随侧栏状态变化，岛因此嵌在栏里原位不动，不再骑在栏下沿悬到内容上。岛是 `box-sizing: content-box`，总高 = 22px 行 + 上下各 2px padding + 各 1px 边框 = 28px；macOS 栏高 2.25rem×14 = 31.5px、Windows ×16 = 36px，两边都装得下，所以内容区**不再**需要顶部让位（`--ccode-island-clearance` 与 `pt` 已删）。栏要 `position: relative; z-index: 39` 才构成层叠上下文：缺了 z-index 时岛的 `z-1` 会掉进页面内容的 z-10/20/30 里被压住；39 与岛当年独立待在根层级时同读数，收件箱下拉的 z-40 仍在岛之上。宽度直接取 `ResizeObserver` 量值，不在 JS 里复刻盒模型（旧版写 `dormantWidth + 2` 少 8px，内容被 `overflow: hidden` 从右边切掉，即用户看到的「怎么变成这样了」）。状态机在 `nav-capsule.ts` 的 `reconcileIsland`：聚焦与悬停共用一条判据，两者都退出才允许收起，`delay-expired` 当场看标志决定收不收，避免「悬停中定时器到点」误收。换页**不**收起（早先有条「换页即回休眠」的效应，理由是岛浮在内容上「不再占着顶部」；岛嵌进栏后那个理由不成立了，而连切几页是常规操作）——点完入口岛留在展开态，指针或焦点离开后才按 delay 收。`onFocus` 只认 `:focus-visible`：Chromium 点按钮也会给它焦点，照收会让 `focused` 常真、指针移开也不再收（WKWebView 不给按钮焦点，所以这个差异只在 Windows 现形）；指针路径不需要它，鼠标还在岛上时 `pointerInside` 本来就托着岛。岛收回休眠时再把「指针点出来的焦点」blur 掉——展开面收起后是 `aria-hidden`，焦点留在里面等于留了个看不见却还能被 Enter 触发的按钮；`:focus-visible` 的键盘焦点不在此列，它有 `onBlur` 自行交接。首启提示换成 `ccode.navIslandHintSeen`（旧 key 的文案语义已反）。低频入口不进休眠态：全收起时唯一退路是「恢复侧栏」，它必须常驻可见。

## 1. 设计目标

Mesa 的第一屏必须让用户在 3 秒内回答四个问题：

1. 我现在在哪个项目？
2. 当前研究步骤是什么？
3. Agent 正在做什么？
4. 我下一步应该点哪里？

产品从「多页面控制台」收敛为「项目驱动的科研工作台」：

- 工作台、项目、运行、对话是主路径。
- 连接、技能、MCP 是资源管理，不抢主路径。
- 用量、设置是低频管理能力。
- 低频操作按需出现，不在每一行平铺。
- 任何页面只保留一个最主要答案和一个主操作。

## 3. 应用外壳

### 3.1 窗口与顶栏

- macOS 使用现有 Overlay 标题栏，高度 `h-9` = `2.25rem`（根字号 14px → 31.5px，2026-10-31 起 Windows 同为 14px；`--ccode-titlebar-h` 只给首启提示挂栏下沿用，岛靠栏内 50% 居中，不读它）；窗口态保留红绿灯让位区，全屏收起按钮后取消让位。
- Windows（2026-10-19 起）与 macOS 同构：Rust setup 里 `set_decorations(false)` 去掉原生标题栏，标题栏 `data-tauri-drag-region` 自绘拖拽，最小化/最大化/关闭（`WindowControls`）紧贴命令面板/待处理右侧、标题栏右内边距为 0；覆盖层 ReaderOverlay 盖住标题栏，自己的顶栏必须再挂一份窗口按钮。新增能盖住标题栏的全屏不透明层同理。Linux 仍用原生标题栏；内容顶栏仍显示项目上下文和运行状态。macOS 路径不受影响（去标题栏只在 `cfg(windows)`）。
- 顶栏不放假输入框，不重复放一个搜索框。
- 左侧显示当前项目和步骤，可点击回项目详情。
- 中间只显示运行状态：`2 个运行中`、`1 个等待确认`；没有状态时保持留白。
- 右侧显示收件箱胶囊、命令面板入口和必要的窗口级操作。

顶栏按钮：

| 按钮 | 类型 | 默认行为 |
|---|---|---|
| 当前项目·步骤 | 上下文按钮 | 回到项目详情的当前步骤 |
| `N 个运行中` | 状态按钮 | 跳转运行页并聚焦运行标签 |
| `待处理 N` | 状态胶囊 | 展开收件箱分类浮层 |
| `⌘K` | Ghost 按钮 | 打开命令面板；不放置输入框 |

### 3.2 侧栏

- 展开宽度 192–224px，收起宽度 56–64px；当前实现为 192px / 56px。
- 不放品牌行（2026-10-27 用户拍板去掉 Mesa 字标）：收起/展开是标题栏红绿灯右边的侧栏钮（Windows 在标题栏最左），状态持久化；
  旁边是「搜索对话和项目」放大镜。两枚只在侧栏未完全隐藏时出现（完全隐藏时恢复侧栏归灵动岛）。
- 侧栏最上面是两个「新建」，分量一样：新对话、新项目（三项菜单：新建 / 已有文件夹 / 示例课题，菜单项单一出处 `project-add.ts`）；
  再是工作台、对话管理。项目树里不再放搜索行，「项目 N」标签行只报计数、不带 ＋。
- 当前项只使用浅色选中底 + 强调色图标 + 强文字，不再叠加左侧色条；这样收起态和展开态都保持同一套轻量层级。
- 侧栏不显示页面级统计数字；只显示需要立即处理的运行数或待处理数。
- 收起态所有图标入口必须保留应用内 tooltip，tooltip 不能替代 `aria-label`。
- 低频入口在底部，主导航区保持连续留白。
- 禁止把所有入口做成同等视觉权重。

### 3.3 三态侧栏与顶部导航胶囊

- 全局侧栏只有三态：展开、图标、完全隐藏；品牌按钮只在「展开 ↔ 图标」之间切换，完全隐藏由 ⌘\\、命令面板或顶部胶囊的恢复入口控制。
- `navCollapsed` 持久化普通侧栏状态；`chromeHidden` 只保留当前窗口会话，退出时恢复进入隐藏前状态。
- 完全隐藏时保留 40px 上下文栏的系统拖拽/红绿灯让位；项目与运行上下文**照常显示**（左组），命令面板和收件箱继续可用。收起侧栏后这两条反而是最该留在眼前的（我在哪个项目、几个 agent 在跑），早先连同上下文栏目一起隐藏是岛还浮在内容上时的遗留。
- 顶部导航岛嵌在 `.ccode-titlebar` 内部居中（`position: absolute; top/left 50%; translate(-50%,-50%)`），不改变页面布局，也不越出栏高；只在完全隐藏状态（`chromeHidden`）出现，按「快速开聊 → 工作 → 资源 → 管理 → 显示侧栏」排列。
- 岛常驻两态：休眠态只有「恢复侧栏」与收件箱；展开态是完整导航。悬停或聚焦展开，两者都退出才按 delay 收起（默认 1 秒，0 = 立即）；窗口失焦立即收起，焦点在岛内时不自动收起，`prefers-reduced-motion` 关闭入场动效。换页**不**收起。
- 胶囊复用侧栏 Lucide 图标、页面标签、`aria-current` 与动态运行/待处理徽标；分组用细分隔线，不显示组标题。
- 胶囊以顶部热区唤出，离开后按设置的 0/0.5/1/2/5 秒延迟隐藏（默认 1 秒，0 = 立即）；窗口失焦立即隐藏，焦点在胶囊内时不自动隐藏，`prefers-reduced-motion` 关闭入场动效。0 档走普通延时分支：`setTimeout(fn, 0)` 排的是下一个宏任务，指针从岛边掠过时会被 `mouseenter` 的 `clearHideTimer` 取消，比同步收起少一次闪烁。
- 胶囊必须支持 Tab 聚焦、完整 aria 名称和窄窗口横向滚动；Esc 只收起胶囊，不改变完全隐藏状态。
- 胶囊显示偏好支持「符号+文字 / 仅符号 / 仅文字」三档；入口可按显示/隐藏配置，顺序和分组不变。恢复侧栏始终保留，当前页面即使被隐藏也临时保留入口。

### 3.4 主内容区

标准管理页统一结构：

```text
页面标题 / 当前上下文 / 唯一主操作
筛选、搜索、分段切换
主体内容
```

- 普通列表最大宽度 1000–1120px；项目详情这类连续工作区可使用流式宽度，占满主区剩余空间，但保持控件尺寸与信息密度不变。
- 终端、阅读、评审允许全宽。
- 设置页外壳宽度约 1040–1120px，给左侧分区导航与右侧设置内容留出稳定空间；说明文本和表单控件仍按各自阅读上限收敛。
- 页面标题 16–18px；正文 13–14px；元信息 11–12px。
- **管理页视觉统一（2026-10-29 用户拍板，设计稿 `docs/design-quiet-pages-mockup.html`）**：只统一观感，不改功能、顺序与操作位置。
  **页头与宽度各页维持原样**：工作台无可见标题（只给读屏）、其余管理页 `PageHeader`（页名 + 灰字 + 原主次按钮），全部 `PageFrame width="wide"`；
  **页名字号统一到工作台「项目」那一档**（`text-lg font-semibold`，同日用户「页头好像不一样大」→「用工作台那个项目页头大小就行了」）：`PageHeader`、对话管理列表栏头「对话」
  （h-12 与 PageHeader 同高）都用它，工作台顶距 pt-2 让「项目」与各页页名同一高度；页内节标题不得大过页名（连接页单家视图的 Agent 节标题由 text-xl 收回 text-lg）；
  同日试过「各页同款对话头式小页头 + 对话栏宽度单列」，用户否掉（「这些页面不需要同样的小页头，根据每个页面设计合适的；宽度用之前的宽度」），
  那两个件已从 `PageFrame.tsx` 删掉。共用的是：节标题 text-lg 粗体、不带图标；分段控件 `SegTabs variant="boxed"`
  （外框 + 选中格浮起，`.ccode-seg-boxed`，aria-pressed 按钮组也可套）；细边搜索 `PaneSearch`；页内左栏 `PaneSplit` + `PaneNav inline`（设置、连接：吸顶、可拖宽、按页记宽度；
  **内容区窄于 48rem 时上下排**——设置页分区栏整宽放上面、分组与分区横排折行，连接页左栏藏起、内容上方换成「选择 Agent」下拉）；
  **宽屏行不留大空**：MCP 与连接列表宽于 60rem 时，「类型 · 命令」「端点 · 模型」从名字下面挪成名字右边的一列，窄了折回第二行；
  列表不套卡、不画表头；展开用左侧细线缩进（同对话「已思考 ›」）；只有选中 / 展开 / 等你处理的铺 `chat-bubble` 色。用量页例外：一律卡片（§12）。

### 3.5 表面与边界

- 继续使用 `rail → canvas → strip → inset → raised` 五层表面令牌。
- 内联内容优先靠留白和底色分层，不使用连续横线。
- 同屏横向带最多两条。
- 浮层统一使用 `.ccode-float-surface`，零阴影、顶部高光或浅色内暗边。
- 普通块使用卡片和卡间留白，不使用 `divide-y` 画满屏细线。

## 4. 交互语法

### 4.1 按钮层级

一个视图最多一个主 CTA。

| 层级 | 视觉 | 使用场景 |
|---|---|---|
| 主按钮 | `primaryActionClass`，32px | 继续工作、运行、新建项目、保存 |
| 次按钮 | `secondaryActionClass`，32px | 打开目录、查看任务书、刷新 |
| 行内按钮 | `rowActionClass`，28px | 编辑、检查、预览 |
| Ghost | 无边框，28px | 复制、展开、低频辅助 |
| 图标按钮 | 28×28px | 关闭、分屏、刷新、更多 |
| 危险按钮 | 只在确认/更多菜单中出现 | 删除、清除、终止 |

### 4.2 按钮文案

- 直接使用动词：`继续工作`、`开始运行`、`打开目录`、`添加连接`。
- 一个操作最多配一句说明，约 20 字以内。
- 机制解释放到 tooltip 或帮助文档，不写在主界面上。
- 内部术语不出现在用户文案中：`注册项目`显示为`添加项目`，`worktree`仅在高级详情中出现。

### 4.3 状态

| 状态 | 颜色 | 文案 |
|---|---|---|
| 运行中 | 绿色点 | 运行中 |
| 等待确认 | 黄色点 | 等你确认 |
| 已完成 | 低饱和绿色 | 已完成 |
| 失败 | 红色点 | 失败 |
| 已归档 | 灰色点 | 已归档 |
| 未配置 | 空心灰点 | 未配置 |

颜色不能作为唯一状态提示，必须同时提供文字或 tooltip。

### 4.4 加载、空、错误

- 加载：使用与最终布局相同宽度的骨架行，不显示整块旋转动画。
- 空状态：一句结论 + 一个主动作 + 可选次动作；不使用无意义的大图标。
- 错误：说明「发生了什么 / 影响什么 / 下一步怎么做」，提供`重试`或`选择路径`。
- 成功：优先使用页面内短提示或状态变化；不弹阻断式成功对话框。

### 4.5 弹窗、抽屉、菜单

- 简单对话框：26rem。
- 富表单：36rem。
- 命令面板：30rem；全局快捷键在输入框、下拉框、可编辑元素和 IME 组合输入期间不拦截，避免编辑内容时意外弹出。
- 页面模态 z-40；菜单/命令面板 z-50；评审内弹层 z-60；确认框 z-70。
- 所有输入使用内联输入或 `ConfirmDialog`，禁止原生 `prompt/confirm/alert`。
- 项目低频设置使用右侧抽屉，不新增页面路由。

### 5.1 页面目的

回答「现在最值得做什么」，而不是展示所有系统数据。默认打开工作台，不再默认打开连接页。

- 2026-10-27「除了用量都做」批：项目头为零的数不写；没在跑的任务行，时长列写「最后一次动它」（步骤 / 分支：工作副本里的对话与最近提交取晚的；目标：updatedAt），在跑才写这一轮时长，花费移入详情；流程当前步强调色点 + 「工作副本开着，还没保存进项目」，排在它后面提前开的写「提前开了，还没保存」；项目先后跟侧栏（`orderLikeSidebar`：置顶段按 pins 先后 > 拖动顺序表 > 其余按最近活动，读同一份 `ccode.projectTreePins` / `ccode.projectTreeOrder`）。

- 离开期间摘要（`awaySummary`）：`localStorage ccode.workbenchLastSeen` 记最后一次看着工作台的时刻（进来、每分钟、离开 / 关窗各记一次），离开不足 30 分钟或期间没事不出；只数结束的非内部运行与定时任务跑次（跳过不算），不估花费——用量按天入库，凑不出准数。「知道了」只收起本次。

拍板队列口径（`src/workbench-queue.ts`）：
- 使用普通 ul / li 与原生按钮，不用含多个操作按钮的 listbox / option。通知默认单独收起，展开后才进入 J/K 导航；需要决定的事仍默认 6 条，选到折起部分会展开。Tab 访问的当前行与快捷键目标一致，J/K 移动同时移动焦点，关闭详情恢复焦点。
- 行内只做两种事：旁路能经 CLI 官方通道回复的待确认（Codex / Qwen / OpenCode，`approvalChoices` 有允许和拒绝）给 **允许 / 拒绝**，只送这两项，「这次会话都允许」这类细选项回对话里选；信息类（`BULK_READABLE`）给 **收起**。其余照旧跳去处理。
- 行内处理一律先藏行、出带「撤销」的常驻提示，5 秒后才真的送出；审批等待期间写「将在 5 秒后允许一次 / 拒绝，仍可撤销」，成功才写「已发送」；撤销窗口挂模块（`createDeferred`），离开工作台照常送出；送失败报错并把行放回来。隐藏键绑定请求 id，同一 Run 的下一问不跟着隐藏。审批详情完整展示通道已提供的命令 / 路径 / diff / 请求文本，对话目录只取标签已知值；不补猜请求 cwd 或安全结论，缺失项如实写未知。
- 键盘只在工作台可见、没有弹层、焦点在页面空白处（body）或队列里（`data-workbench-queue`）时接管——侧栏 ⌘0 后的 ↑↓、输入框、顶栏都不抢；当前行做不了的键不吞；焦点在队列里的按钮上时回车留给那个按钮。
- 按钮全用行内按钮样式，不用主 CTA（一屏一个主 CTA 的规矩，队列每行都有按钮）。

旧版（2026-10-26 及以前）：大卡（项目名 · 方式 · 状态 + 继续工作）+ 紧凑行 → 待你处理 → 待你验收 → 定时任务 → 最近对话。第一批（2026-10-27 上午）曾是「等你拍板 + 逐行列项目」，同日第二批换成项目卡片网格，看过真实数据后改成项目分组列表。

## 7. 运行 / 终端页

### 7.0 主工作区显示层（v3.126）

模式切换不再单独占用标签栏下方一整行，而是收进终端标签栏同一个单击切换按钮（图标显示当前层，再点切到另一层）；默认进入终端（2026-09-02 起，此前默认聊天）。聊天是同一 PTY 的结构化显示层，不是第二个会话：TerminalView、xterm、PTY 与滚动缓冲始终挂载，切换只改变可见层。聊天层使用居中限宽的 Codex 风格消息列表和浮起 composer（Enter 发送、Shift+Enter 换行），发送统一走当前标签的 PTY / resume / 自动启动链路。AI 正文 Markdown 比笔记阅读更瘦：行内代码无描边、引用只留左线（`.md-chat`）。

进入聊天会自动退出分屏，切回终端不自动恢复分屏。聊天模式不渲染终端底部状态栏，Agent、模型、目录、同步状态和资源数量显示在聊天上下文栏/composer；终端模式继续保留完整状态栏。该规则是运行时显示策略，不新增持久化开关。右侧工作台只保留「文件 / 改动」，实时对话不再在右栏重复渲染。会话文件更新由专用 watcher 触发最近 50 条消息的整段替换，签名轮询只作兜底；界面状态如实显示识别中、已监听、等待文件或兜底轮询。

聊天 composer 与终端启动栏复用同一份当前 Agent 技能/MCP 清单；点击技能或 MCP 只把对应提示插入聊天输入框，不自动发送，用户补充上下文后再按 Enter 发出（与终端入口写入输入框、不自动回车的语义一致），MCP 菜单可直接跳转资源管理页。聊天区不复制九家 CLI 的终端菜单解析器。登录、权限确认或模型选择器默认在聊天下方开出同一会话的终端底栏（按该高度 fit）；只有启动注入失败等必须在 TUI 输入框粘贴的才整层切到终端。交接表见 `src/chat-handoff.ts`。

聊天头部的「新建聊天」是摘要分叉：只在当前会话已关联时启用，复用接力简报与 handoff 标记，不宣称复制完整上下文。分叉标签默认只读；「允许修改」必须二次确认潜在覆盖风险，再以同一摘要重启可写 PTY。无原生只读能力的 CLI 只显示提示约束，不伪装成沙箱。

## 14. 全局模块

### 14.1 命令面板

30rem 浮层，支持：页面跳转、创建项目、新对话、切主题、打开设置、聚焦运行标签、打开最近文件。

每行显示图标、命令名、快捷键；搜索结果分组；Esc 关闭；不重复执行页面已有确认逻辑。

### 14.2 新对话（原名快速开聊）

界面名 2026-10-18 由「快速开聊」改为「新对话」（用户拍板：按钮做的就是开一段新对话，和「对话」页成对；「开聊」偏口语）。
与项目里的「＋新对话」、`/new` 同名同义，只是落点不同（侧栏的落随手聊，项目里的落该项目）。⌘K 保留「快速开聊」「kslt」等旧搜索词；
内部标识（`quick-chat`、`quickchat:` 复用键、`ccode.quickChat`）不改。

2026-10-18 用户拍板：快速开聊＝新对话，**不弹窗**。侧栏、⌘K、工作台页头、顶部导航岛四个入口同一条路（`quick-chat-launch.ts openQuickChat`）：
直接开一个空白聊天标签，文件夹默认 `~/ccode/scratch`、收起右栏；Agent · 连接 · 模型 · 思考、权限、文件夹都在输入框里选，
默认取上次快速开聊发第一句时的选择（不记文件夹和权限），失效依次退到同家另一条可用连接 → 运行页上次启动的 → 装了的第一家（`pickQuickChatDefault`）。
仍是发第一句才启动。再点一次只复用还没说过话的随手聊标签（每个标签自带 `quickchat:<uuid>` 复用键，后端按它认 Run，不能共用），聊过的不复用。
标签标题 `随手聊 · Agent` 跟着输入框里当前选的 Agent 走。不创建项目。

随手聊历史只用本机已加载的会话列表现算，且**只列 `~/ccode/scratch`**；正在跑的随手聊不列出。两处出现：聊天空态（文件夹是随手聊时，最多 5 条，
点一条接着聊并收掉这个空白标签）与侧栏右键菜单，都同步出现、不得先空着再插入。

运行页「＋」＝在当前项目里再开一个 Agent：目录跟当前标签走（`newTabCwd`），当前标签没有目录或在 Mesa 隔离目录（工作副本 / 工作树 / 定时隔离树）时开在随手聊。

**新标签默认目录 = 随手聊（2026-10-20）**：没给目录的新标签挂载时补成 `ensure_scratch_dir`（恢复标签、接回会话不动），不再默认主目录；主目录只能人在目录菜单里选。Windows + Codex + 主目录 + 非「完全访问」启动前弹确认（`codexSandboxCoversHome`）：Codex 的 Windows 沙箱跑命令前给工作目录下每一项改访问权限，主目录 = 整个用户文件夹；开发版里改到 Mesa 源码会让 tauri dev 重编译并重启 Mesa。取消时聊天层发送报具体原因（`launchCancelRef`），不报笼统的「启动失败」。

## 15. 响应式与跨平台

- 宽度不足时先隐藏文字标签，再收起辅助栏，最后才压缩主内容。
- 终端页优先保证输出区宽度；文件树和成果面板可折叠。
- Windows/Linux 不依赖 macOS 红绿灯布局。
- 所有可点击元素最小热区 28px；**导航岛内例外为 22px**（`--ccode-island-row`）——岛嵌在 `h-9` 标题栏里，22px 行 + 上下各 2px padding + 各 1px 边框 = 总高 28px，正好占满栏高；按钮按 28px 会把岛撑出栏外。岛内元素靠间距而非高度保可点。
- 键盘 Tab 必须能到达主要操作；tooltip 不能是唯一可访问名称。
- `prefers-reduced-motion` 下关闭入场动画。
