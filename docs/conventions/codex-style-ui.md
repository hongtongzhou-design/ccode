## 1. 设计目标

Ccode 的第一屏必须让用户在 3 秒内回答四个问题：

1. 我现在在哪个项目？
2. 当前研究步骤是什么？
3. Agent 正在做什么？
4. 我下一步应该点哪里？

产品从「多页面控制台」收敛为「项目驱动的科研工作台」：

- 工作台、项目、运行、对话是主路径。
- 连接、技能、MCP 是资源管理，不抢主路径。
- 用量、设置是低频管理能力。
- 低频操作按需出现，不在每一行平铺。
- 任何页面只保留一个最主要答案和一个主操作。

## 3. 应用外壳

### 3.1 窗口与顶栏

- macOS 使用现有 Overlay 标题栏，高度 40px，保留红绿灯让位区。
- Windows/Linux 使用原生标题栏；内容顶栏仍显示项目上下文和运行状态。
- 顶栏不放假输入框，不重复放一个搜索框。
- 左侧显示当前项目和步骤，可点击回项目详情。
- 中间只显示运行状态：`2 个运行中`、`1 个等待确认`；没有状态时保持留白。
- 右侧显示收件箱胶囊、命令面板入口和必要的窗口级操作。

顶栏按钮：

| 按钮 | 类型 | 默认行为 |
|---|---|---|
| 当前项目·步骤 | 上下文按钮 | 回到项目详情的当前步骤 |
| `N 个运行中` | 状态按钮 | 跳转运行页并聚焦运行标签 |
| `待处理 N` | 状态胶囊 | 展开收件箱分类浮层 |
| `⌘K` | Ghost 按钮 | 打开命令面板；不放置输入框 |

### 3.2 侧栏

- 展开宽度 192–224px，收起宽度 56–64px；当前实现为 192px / 56px。
- 品牌区点击收起/展开，状态持久化。
- 当前项只使用浅色选中底 + 强调色图标 + 强文字，不再叠加左侧色条；这样收起态和展开态都保持同一套轻量层级。
- 侧栏不显示页面级统计数字；只显示需要立即处理的运行数或待处理数。
- 收起态所有图标入口必须保留应用内 tooltip，tooltip 不能替代 `aria-label`。
- 低频入口在底部，主导航区保持连续留白。
- 禁止把所有入口做成同等视觉权重。

### 3.3 三态侧栏与顶部导航胶囊

- 全局侧栏只有三态：展开、图标、完全隐藏；品牌按钮只在「展开 ↔ 图标」之间切换，完全隐藏由 ⌘\\、命令面板或顶部胶囊的恢复入口控制。
- `navCollapsed` 持久化普通侧栏状态；`chromeHidden` 只保留当前窗口会话，退出时恢复进入隐藏前状态。
- 完全隐藏时保留 40px 上下文栏的系统拖拽/红绿灯让位；项目与运行上下文隐藏，命令面板和收件箱继续可用。
- 顶部导航胶囊固定在上下文栏下方，不改变页面布局；只在完全隐藏状态出现，按「快速开聊 → 工作 → 资源 → 管理 → 显示侧栏」排列。
- 胶囊复用侧栏 Lucide 图标、页面标签、`aria-current` 与动态运行/待处理徽标；分组用细分隔线，不显示组标题。
- 胶囊以顶部热区唤出，离开后按设置的 0.5/1/2/5 秒延迟隐藏；窗口失焦立即隐藏，焦点在胶囊内时不自动隐藏，`prefers-reduced-motion` 关闭入场动效。
- 胶囊必须支持 Tab 聚焦、完整 aria 名称和窄窗口横向滚动；Esc 只收起胶囊，不改变完全隐藏状态。
- 胶囊显示偏好支持「符号+文字 / 仅符号 / 仅文字」三档；入口可按显示/隐藏配置，顺序和分组不变。恢复侧栏始终保留，当前页面即使被隐藏也临时保留入口。

### 3.4 主内容区

标准管理页统一结构：

```text
页面标题 / 当前上下文 / 唯一主操作
筛选、搜索、分段切换
主体内容
```

- 普通列表最大宽度 1000–1120px；项目详情这类连续工作区可使用流式宽度，占满主区剩余空间，但保持控件尺寸与信息密度不变。
- 终端、阅读、评审允许全宽。
- 设置页外壳宽度约 1040–1120px，给左侧分区导航与右侧设置内容留出稳定空间；说明文本和表单控件仍按各自阅读上限收敛。
- 页面标题 16–18px；正文 13–14px；元信息 11–12px。

### 3.5 表面与边界

- 继续使用 `rail → canvas → strip → inset → raised` 五层表面令牌。
- 内联内容优先靠留白和底色分层，不使用连续横线。
- 同屏横向带最多两条。
- 浮层统一使用 `.ccode-float-surface`，零阴影、顶部高光或浅色内暗边。
- 普通块使用卡片和卡间留白，不使用 `divide-y` 画满屏细线。

## 4. 交互语法

### 4.1 按钮层级

一个视图最多一个主 CTA。

| 层级 | 视觉 | 使用场景 |
|---|---|---|
| 主按钮 | `primaryActionClass`，32px | 继续工作、运行、新建项目、保存 |
| 次按钮 | `secondaryActionClass`，32px | 打开目录、查看任务书、刷新 |
| 行内按钮 | `rowActionClass`，28px | 编辑、检查、预览 |
| Ghost | 无边框，28px | 复制、展开、低频辅助 |
| 图标按钮 | 28×28px | 关闭、分屏、刷新、更多 |
| 危险按钮 | 只在确认/更多菜单中出现 | 删除、清除、终止 |

### 4.2 按钮文案

- 直接使用动词：`继续工作`、`开始运行`、`打开目录`、`添加连接`。
- 一个操作最多配一句说明，约 20 字以内。
- 机制解释放到 tooltip 或帮助文档，不写在主界面上。
- 内部术语不出现在用户文案中：`注册项目`显示为`添加项目`，`worktree`仅在高级详情中出现。

### 4.3 状态

| 状态 | 颜色 | 文案 |
|---|---|---|
| 运行中 | 绿色点 | 运行中 |
| 等待确认 | 黄色点 | 等你确认 |
| 已完成 | 低饱和绿色 | 已完成 |
| 失败 | 红色点 | 失败 |
| 已归档 | 灰色点 | 已归档 |
| 未配置 | 空心灰点 | 未配置 |

颜色不能作为唯一状态提示，必须同时提供文字或 tooltip。

### 4.4 加载、空、错误

- 加载：使用与最终布局相同宽度的骨架行，不显示整块旋转动画。
- 空状态：一句结论 + 一个主动作 + 可选次动作；不使用无意义的大图标。
- 错误：说明「发生了什么 / 影响什么 / 下一步怎么做」，提供`重试`或`选择路径`。
- 成功：优先使用页面内短提示或状态变化；不弹阻断式成功对话框。

### 4.5 弹窗、抽屉、菜单

- 简单对话框：26rem。
- 富表单：36rem。
- 命令面板：30rem；全局快捷键在输入框、下拉框、可编辑元素和 IME 组合输入期间不拦截，避免编辑内容时意外弹出。
- 页面模态 z-40；菜单/命令面板 z-50；评审内弹层 z-60；确认框 z-70。
- 所有输入使用内联输入或 `ConfirmDialog`，禁止原生 `prompt/confirm/alert`。
- 项目低频设置使用右侧抽屉，不新增页面路由。

## 5. 工作台

### 5.1 页面目的

回答「现在最值得做什么」，而不是展示所有系统数据。默认打开工作台，不再默认打开连接页。

### 5.2 布局

```text
工作台                                      [新建项目] [快速开聊]

当前工作
  项目名 · 步骤名 · Agent · 状态             [继续工作]

待你处理
  等待确认 / 人工事项 / 文献新命中 / 失败    [去处理]

最近产出                         最近对话
  文件、图表、PDF、任务书           最近 5–8 条对话
```

### 5.3 按钮与行为

- `继续工作`：回到当前项目步骤；若有运行中的标签则聚焦标签。
- `新建项目`：打开添加项目弹窗。
- `快速开聊`：打开快速开聊弹层；遵守现有 scratch 语义。
- `去处理`：按条目类型跳到终端、项目、文献或对话详情。
- 产出行点击：打开相应预览层；右侧 `⋯` 放复制路径、定位文件。
- 对话行点击：进入对话页并选中会话。

### 5.4 空状态

```text
从一个项目开始
[添加项目] [查看示例项目]
```

没有项目时不显示统计卡片、不堆快捷入口。

工作台卡片空态使用紧凑版留白；工作台只保留「添加项目」和「快速开聊」两个入口，最近产出/对话无数据时只显示一句结论。

工作台、项目详情以及连接、技能、MCP、用量页都属于横向信息工作区：最大化窗口时使用主区流式宽度，列表、表格和分栏占用可用横向空间；
字号、按钮尺寸和内容密度保持不变，不用放大卡片来填充空白。技能详情栏、设置分区和对话回放等局部阅读区继续保留自身宽度上限。

## 6. 项目页

### 6.1 项目列表

每个项目使用卡片，不使用满屏横线：

```text
项目名
课题主题 / 项目路径
当前步骤 · 最近活动 · 运行状态
                                          [继续] [⋯]
```

工作区卡片常驻「继续」；普通评审、脚本、复制路径和归档等低频操作进入 `⋯`。只有正在发生的合并冲突保留行内「解决冲突」入口。

常驻动作只有`继续`；评审、合并、创建 PR、归档、移除等进入`⋯`。

项目页左侧项目列表是页内导航 rail，可单独收起，不与全局侧栏绑定，也不随窗口尺寸自动切换。默认展开；收起后 rail 变为零宽，不保留空白竖条，页头「项目」旁保留恢复按钮，当前项目选择与右侧详情上下文保持不变。收起状态按用户选择记忆。

### 6.2 添加项目弹窗

字段顺序：

1. 项目文件夹
2. 项目名称（默认取目录名）
3. 课题主题（可选）
4. 研究流程模板

按钮：`取消`、`添加项目`。选择模板单独使用现有模板选择层，不在弹窗内塞入完整流程编辑器。

### 6.3 项目详情固定三段

#### 身份段

- 项目名 16px semibold。
- 课题主题直接显示；为空时显示可点击的`＋写一句课题主题`。
- 路径显示为 `~/…`，完整路径放 tooltip。
- 右侧按钮：`继续工作`、`打开目录`、`⋯`。

#### 流程段

- 保留现有大圆步进器及步骤顺序。
- 当前步骤使用唯一高亮。
- 步进器下方紧接当前步骤卡，不再拆成多个细带。

当前步骤卡：

```text
步骤名 · 白话状态
StepFlow 流程线
                                             [开始] / [继续]
```

#### 工作段

顺序固定：任务卡 → 工作区卡 → 产物 → Git → 人工事项 → 文献雷达 → 定时任务。

### 6.4 项目详情按钮

| 按钮 | 位置 | 行为 |
|---|---|---|
| 继续工作 | 身份段 | 找回或创建对应终端标签 |
| 打开目录 | 身份段 | 在系统文件管理器打开项目根 |
| 开始/继续 | 当前步骤卡 | 走一键开步单一链路 |
| 预览/编辑 TASK.md | 流程线 | 打开任务书预览/编辑层，保存才落盘 |
| 跟 AI 商量一下 | 决策区 | 打开对话并按现有播种规则处理 |
| 查看产物 | 工作区卡 | 打开成果工作台或文件预览 |
| 评审 | 工作区卡 | 打开全宽评审覆盖层 |
| `⋯` | 身份段/卡片 | 编辑研究流程、项目设置、历史、移除项目注册 |

项目设置抽屉分组：基本、研究流程、文献与数据、定时巡检。

## 7. 运行 / 终端页

### 7.0 主工作区显示层（v3.126）

模式切换不再单独占用标签栏下方一整行，而是收进终端标签栏的轻量「聊天 · 终端」inline action；默认进入聊天。聊天是同一 PTY 的结构化显示层，不是第二个会话：TerminalView、xterm、PTY 与滚动缓冲始终挂载，切换只改变可见层。聊天层使用居中限宽的 Codex 风格消息列表和浮起 composer（Enter 发送、Shift+Enter 换行），发送统一走当前标签的 PTY / resume / 自动启动链路。

进入聊天会自动退出分屏，切回终端不自动恢复分屏。聊天模式不渲染终端底部状态栏，Agent、模型、目录、同步状态和资源数量显示在聊天上下文栏/composer；终端模式继续保留完整状态栏。该规则是运行时显示策略，不新增持久化开关。右侧工作台只保留「文件 / 改动」，实时对话不再在右栏重复渲染。会话文件更新由专用 watcher 触发最近 50 条消息的整段替换，签名轮询只作兜底；界面状态如实显示识别中、已监听、等待文件或兜底轮询。

聊天 composer 与终端启动栏复用同一份当前 Agent 技能/MCP 清单；点击技能或 MCP 只把对应提示插入聊天输入框，不自动发送，用户补充上下文后再按 Enter 发出（与终端入口写入输入框、不自动回车的语义一致），MCP 菜单可直接跳转资源管理页。聊天区不复制九家 CLI 的终端菜单解析器，遇到登录、权限确认或模型选择器仍提示切到终端。

聊天头部的「新建聊天」是摘要分叉：只在当前会话已关联时启用，复用接力简报与 handoff 标记，不宣称复制完整上下文。分叉标签默认只读；「允许修改」必须二次确认潜在覆盖风险，再以同一摘要重启可写 PTY。无原生只读能力的 CLI 只显示提示约束，不伪装成沙箱。

### 7.2 启动上下文栏

默认显示：

- Agent 选择器
- 连接选择器
- 模型选择器
- 工作目录
- `运行`

以下内容放到`⋯`的高级启动选项：首条指令；技能和 MCP 作为运行时快捷入口常驻在启动栏与收缩状态行。环境变量与权限模式继续沿用启动配置详情，不抢默认启动栏空间。

按钮：

- `运行`：启动 Agent；没有可用连接时给出就地提示。
- `打开 Shell`：只打开 shell，不注入 Agent 配置。
- `会话`：当前标签有会话时可进入结构化视图，否则置灰并带原因。
- `查找`：在终端输出中查找。
- `专注`：隐藏侧栏和非必要面板，但保留标题栏让位与必要状态。
- `⋯`：停止、恢复、接力、继续、复制命令、修改启动配置。

启动栏默认收起高级选项；需要首条指令时，从 `⋯` 打开「高级启动选项」；技能和 MCP 可直接从常驻入口使用，能力和注入语义不变。

### 7.3 终端标签

标签标题优先显示：`项目 · Agent · 模型`；快速开聊显示 `随手聊 · Agent`。

标签操作：新建、关闭、拖拽排序、分屏、交换 pane、复制标签、恢复会话。

### 7.4 终端错误

不直接展示底层异常作为唯一信息。例：

```text
无法读取工作目录
~/测试文件
[选择目录] [重试]
```

### 7.5 底部状态栏

只显示：模型、思考档、Git 状态、保存/推送、状态点、运行时长、本会话 token。完整操作进入`⋯`。

## 14. 全局模块

### 14.1 命令面板

30rem 浮层，支持：页面跳转、创建项目、快速开聊、切主题、打开设置、聚焦运行标签、打开最近文件。

每行显示图标、命令名、快捷键；搜索结果分组；Esc 关闭；不重复执行页面已有确认逻辑。

### 14.2 快速开聊

弹层只询问 Agent、连接、目录。确认后创建终端标签并自动启动；无连接时降级为预填，不创建项目。

### 14.3 收件箱

顶栏胶囊按类别显示数量；点击展开分类浮层。每行只有：状态点、内容、一个动作、忽略按钮。

忽略只隐藏当前签名，状态变化后重新出现。

### 14.4 项目设置抽屉

从项目详情右侧打开，分为基本、研究流程、文献与数据、定时巡检。保存后保持项目详情上下文，不跳到新页面。

### 14.5 成果工作台与阅读区

- 文件、对话、改动使用标签或分段，不新增常驻第三栏。
- 阅读区保留「笔记｜PDF｜Agent 终端」三栏沉浸模式。
- Esc 优先退出阅读覆盖层；底下终端保持挂载。

### 14.6 评审覆盖层

全宽覆盖层优先显示变更摘要、逐 hunk、产物和人工事项。主操作只有`批准并合并`或`返回修改`；危险动作收进更多菜单。

## 15. 响应式与跨平台

- 宽度不足时先隐藏文字标签，再收起辅助栏，最后才压缩主内容。
- 终端页优先保证输出区宽度；文件树和成果面板可折叠。
- Windows/Linux 不依赖 macOS 红绿灯布局。
- 所有可点击元素最小热区 28px。
- 键盘 Tab 必须能到达主要操作；tooltip 不能是唯一可访问名称。
- `prefers-reduced-motion` 下关闭入场动画。
