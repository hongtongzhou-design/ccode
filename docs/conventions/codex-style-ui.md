# Ccode Codex 风格界面设计规格

> 状态：设计基线，供后续逐项实现与核验。
>
> 本规格只以当前 `tauri dev` 热更新窗口为视觉基线，不参考旧打包版本；不改变已有 Agent 适配、项目隔离、任务书、评审合并、只读保护和密钥安全语义。

## 1. 设计目标

Ccode 的第一屏必须让用户在 3 秒内回答四个问题：

1. 我现在在哪个项目？
2. 当前研究步骤是什么？
3. Agent 正在做什么？
4. 我下一步应该点哪里？

产品从「多页面控制台」收敛为「项目驱动的科研工作台」：

- 工作台、项目、运行、对话是主路径。
- 连接、技能、MCP 是资源管理，不抢主路径。
- 用量、设置是低频管理能力。
- 低频操作按需出现，不在每一行平铺。
- 任何页面只保留一个最主要答案和一个主操作。

## 2. 术语和导航迁移

| 当前热更新界面 | 目标用户术语 | 说明 |
|---|---|---|
| 配置 | 连接 | 连接 Agent、供应商、模型与密钥 |
| 工作区 | 项目 | 用户认知中的研究项目；内部 worktree 仍叫工作区 |
| 终端 | 运行 | 进入 Agent 执行与终端工作台 |
| 会话 | 对话 | 历史会话与结构化回放 |
| 技能 | 技能 | 保留 |
| MCP | MCP | 保留 |
| 统计 | 用量 | token、费用与项目归因 |
| 设置 | 设置 | 保留 |

目标侧栏顺序：

```text
Ccode

工作
  工作台
  项目
  运行
  对话

资源
  连接
  技能
  MCP

底部
  用量
  设置
  ⌘K 命令面板
```

「快速开聊」是动作，不是页面：放在“工作”组最上方，旁边显示快捷键；不创建项目、不创建工作区、不写任务书。

## 3. 应用外壳

### 3.1 窗口与顶栏

- macOS 使用现有 Overlay 标题栏，高度 40px，保留红绿灯让位区。
- Windows/Linux 使用原生标题栏；内容顶栏仍显示项目上下文和运行状态。
- 顶栏不放假输入框，不重复放一个搜索框。
- 左侧显示当前项目和步骤，可点击回项目详情。
- 中间只显示运行状态：`2 个运行中`、`1 个等待确认`；没有状态时保持留白。
- 右侧显示收件箱胶囊、命令面板入口和必要的窗口级操作。

顶栏按钮：

| 按钮 | 类型 | 默认行为 |
|---|---|---|
| 当前项目·步骤 | 上下文按钮 | 回到项目详情的当前步骤 |
| `N 个运行中` | 状态按钮 | 跳转运行页并聚焦运行标签 |
| `待处理 N` | 状态胶囊 | 展开收件箱分类浮层 |
| `⌘K` | Ghost 按钮 | 打开命令面板；不放置输入框 |

### 3.2 侧栏

- 展开宽度 192–224px，收起宽度 56–64px；当前实现为 192px / 56px。
- 品牌区点击收起/展开，状态持久化。
- 当前项使用底色 + 3px 左侧强调条 + 强文字，不使用大面积渐变。
- 侧栏不显示页面级统计数字；只显示需要立即处理的运行数或待处理数。
- 收起态所有图标入口必须保留应用内 tooltip，tooltip 不能替代 `aria-label`。
- 低频入口在底部，主导航区保持连续留白。
- 禁止把所有入口做成同等视觉权重。

### 3.3 主内容区

标准管理页统一结构：

```text
页面标题 / 当前上下文 / 唯一主操作
筛选、搜索、分段切换
主体内容
```

- 普通列表最大宽度 1000–1120px。
- 终端、阅读、评审允许全宽。
- 设置页最大宽度 760–820px。
- 页面标题 16–18px；正文 13–14px；元信息 11–12px。

### 3.4 表面与边界

- 继续使用 `rail → canvas → strip → inset → raised` 五层表面令牌。
- 内联内容优先靠留白和底色分层，不使用连续横线。
- 同屏横向带最多两条。
- 浮层统一使用 `.ccode-float-surface`，零阴影、顶部高光或浅色内暗边。
- 普通块使用卡片和卡间留白，不使用 `divide-y` 画满屏细线。

## 4. 交互语法

### 4.1 按钮层级

一个视图最多一个主 CTA。

| 层级 | 视觉 | 使用场景 |
|---|---|---|
| 主按钮 | `primaryActionClass`，32px | 继续工作、运行、新建项目、保存 |
| 次按钮 | `secondaryActionClass`，32px | 打开目录、查看任务书、刷新 |
| 行内按钮 | `rowActionClass`，28px | 编辑、检查、预览 |
| Ghost | 无边框，28px | 复制、展开、低频辅助 |
| 图标按钮 | 28×28px | 关闭、分屏、刷新、更多 |
| 危险按钮 | 只在确认/更多菜单中出现 | 删除、清除、终止 |

### 4.2 按钮文案

- 直接使用动词：`继续工作`、`开始运行`、`打开目录`、`添加连接`。
- 一个操作最多配一句说明，约 20 字以内。
- 机制解释放到 tooltip 或帮助文档，不写在主界面上。
- 内部术语不出现在用户文案中：`注册项目`显示为`添加项目`，`worktree`仅在高级详情中出现。

### 4.3 状态

| 状态 | 颜色 | 文案 |
|---|---|---|
| 运行中 | 绿色点 | 运行中 |
| 等待确认 | 黄色点 | 等你确认 |
| 已完成 | 低饱和绿色 | 已完成 |
| 失败 | 红色点 | 失败 |
| 已归档 | 灰色点 | 已归档 |
| 未配置 | 空心灰点 | 未配置 |

颜色不能作为唯一状态提示，必须同时提供文字或 tooltip。

### 4.4 加载、空、错误

- 加载：使用与最终布局相同宽度的骨架行，不显示整块旋转动画。
- 空状态：一句结论 + 一个主动作 + 可选次动作；不使用无意义的大图标。
- 错误：说明「发生了什么 / 影响什么 / 下一步怎么做」，提供`重试`或`选择路径`。
- 成功：优先使用页面内短提示或状态变化；不弹阻断式成功对话框。

### 4.5 弹窗、抽屉、菜单

- 简单对话框：26rem。
- 富表单：36rem。
- 命令面板：30rem。
- 页面模态 z-40；菜单/命令面板 z-50；评审内弹层 z-60；确认框 z-70。
- 所有输入使用内联输入或 `ConfirmDialog`，禁止原生 `prompt/confirm/alert`。
- 项目低频设置使用右侧抽屉，不新增页面路由。

## 5. 工作台

### 5.1 页面目的

回答「现在最值得做什么」，而不是展示所有系统数据。默认打开工作台，不再默认打开连接页。

### 5.2 布局

```text
工作台                                      [新建项目] [快速开聊]

当前工作
  项目名 · 步骤名 · Agent · 状态             [继续工作]

待你处理
  等待确认 / 人工事项 / 文献新命中 / 失败    [去处理]

最近产出                         最近对话
  文件、图表、PDF、任务书           最近 5–8 条对话
```

### 5.3 按钮与行为

- `继续工作`：回到当前项目步骤；若有运行中的标签则聚焦标签。
- `新建项目`：打开添加项目弹窗。
- `快速开聊`：打开快速开聊弹层；遵守现有 scratch 语义。
- `去处理`：按条目类型跳到终端、项目、文献或对话详情。
- 产出行点击：打开相应预览层；右侧 `⋯` 放复制路径、定位文件。
- 对话行点击：进入对话页并选中会话。

### 5.4 空状态

```text
从一个项目开始
[添加项目] [查看示例项目]
```

没有项目时不显示统计卡片、不堆快捷入口。

工作台卡片空态使用紧凑版留白；工作台只保留「添加项目」和「快速开聊」两个入口，最近产出/对话无数据时只显示一句结论。

## 6. 项目页

### 6.1 项目列表

每个项目使用卡片，不使用满屏横线：

```text
项目名
课题主题 / 项目路径
当前步骤 · 最近活动 · 运行状态
                                          [继续] [⋯]
```

工作区卡片常驻「继续」；普通评审、脚本、复制路径和归档等低频操作进入 `⋯`。只有正在发生的合并冲突保留行内「解决冲突」入口。

常驻动作只有`继续`；评审、合并、创建 PR、归档、移除等进入`⋯`。

### 6.2 添加项目弹窗

字段顺序：

1. 项目文件夹
2. 项目名称（默认取目录名）
3. 课题主题（可选）
4. 研究流程模板

按钮：`取消`、`添加项目`。选择模板单独使用现有模板选择层，不在弹窗内塞入完整流程编辑器。

### 6.3 项目详情固定三段

#### 身份段

- 项目名 16px semibold。
- 课题主题直接显示；为空时显示可点击的`＋写一句课题主题`。
- 路径显示为 `~/…`，完整路径放 tooltip。
- 右侧按钮：`继续工作`、`打开目录`、`⋯`。

#### 流程段

- 保留现有大圆步进器及步骤顺序。
- 当前步骤使用唯一高亮。
- 步进器下方紧接当前步骤卡，不再拆成多个细带。

当前步骤卡：

```text
步骤名 · 白话状态
StepFlow 流程线
                                             [开始] / [继续]
```

#### 工作段

顺序固定：任务卡 → 工作区卡 → 产物 → Git → 人工事项 → 文献雷达 → 定时任务。

### 6.4 项目详情按钮

| 按钮 | 位置 | 行为 |
|---|---|---|
| 继续工作 | 身份段 | 找回或创建对应终端标签 |
| 打开目录 | 身份段 | 在系统文件管理器打开项目根 |
| 开始/继续 | 当前步骤卡 | 走一键开步单一链路 |
| 预览/编辑 TASK.md | 流程线 | 打开任务书预览/编辑层，保存才落盘 |
| 跟 AI 商量一下 | 决策区 | 打开对话并按现有播种规则处理 |
| 查看产物 | 工作区卡 | 打开成果工作台或文件预览 |
| 评审 | 工作区卡 | 打开全宽评审覆盖层 |
| `⋯` | 身份段/卡片 | 编辑研究流程、项目设置、历史、移除项目注册 |

项目设置抽屉分组：基本、研究流程、文献与数据、定时巡检。

## 7. 运行 / 终端页

### 7.1 页面结构

```text
工作树                         运行上下文栏
                               Agent · 连接 · 模型 · 目录 [运行]
终端标签栏                     终端 / 结构化对话 / 成果工作台
                               输出区
                               底部状态栏
```

### 7.2 启动上下文栏

默认显示：

- Agent 选择器
- 连接选择器
- 模型选择器
- 工作目录
- `运行`

以下内容放到`⋯`的高级启动选项：首条指令、技能、MCP；环境变量与权限模式继续沿用启动配置详情，不抢默认启动栏空间。

按钮：

- `运行`：启动 Agent；没有可用连接时给出就地提示。
- `打开 Shell`：只打开 shell，不注入 Agent 配置。
- `会话`：当前标签有会话时可进入结构化视图，否则置灰并带原因。
- `查找`：在终端输出中查找。
- `专注`：隐藏侧栏和非必要面板，但保留标题栏让位与必要状态。
- `⋯`：停止、恢复、接力、继续、复制命令、修改启动配置。

启动栏默认收起高级选项；需要首条指令、技能或 MCP 时，从 `⋯` 打开「高级启动选项」，能力和注入语义不变。

### 7.3 终端标签

标签标题优先显示：`项目 · Agent · 模型`；快速开聊显示 `随手聊 · Agent`。

标签操作：新建、关闭、拖拽排序、分屏、交换 pane、复制标签、恢复会话。

### 7.4 终端错误

不直接展示底层异常作为唯一信息。例：

```text
无法读取工作目录
~/测试文件
[选择目录] [重试]
```

### 7.5 底部状态栏

只显示：模型、思考档、Git 状态、保存/推送、状态点、运行时长、本会话 token。完整操作进入`⋯`。

## 8. 对话页

### 8.1 布局

保留当前双栏结构：

```text
左：搜索与会话列表
右：对话回放与结构化结果
```

不再增加第三个常驻栏。文件、产物和 Git 结果使用右侧抽屉或页内分段。

### 8.2 左栏

- 搜索框
- 一行可叠加筛选 chip：进行中、保留、今天、近 7 天、内部、已归档
- 按项目和 Agent 分组
- 每行显示标题、项目·Agent·时间、状态点

token 数、内部会话、handoff 信息降为辅助信息或 tooltip。

### 8.3 右栏

顶部按钮：`继续`、`提炼简报`、`导出`、`⋯`。

主体展示消息、文件引用、产物、任务卡关联和接力信息。

底部操作：`继续这个对话`、`融合进任务书`、`归入项目`、`在外部终端继续`。

## 9. 连接页

### 9.1 页面名称

用户面显示「连接」，页面副标题可显示「Agent、供应商与模型」。内部仍使用 profile 数据模型。

### 9.2 列表卡

按 Agent 分组，每组是轻卡片：

```text
Codex                                      [添加连接]
● Zeta-1       模型名       2 天前使用
               已保存密钥 ···TKsD          [使用] [编辑] [⋯]
```

未安装 Agent 组降权，不用 opacity 影响浮层定位。

### 9.3 新建连接流程

分四步：选择 Agent → 选择供应商/端点 → 模型与密钥 → 测试并保存。

高级环境变量、全局写入、官方账号登录等不放第一屏。

按钮：`添加连接`、`测试连接`、`保存连接`、`在终端使用`、`设为默认`、`编辑`、`⋯`。

密钥只显示尾号提示，不进入界面文本、shell 或日志。

## 10. 技能页

### 10.1 列表

```text
技能名
一句话说明
已应用到：Codex、Claude · 来源 · 更新时间
                                      [预览] [应用] [⋯]
```

搜索按名称、描述、分类、来源匹配。

### 10.2 预览抽屉

显示：说明、SKILL.md、输出文件、已应用 Agent、使用中的项目、来源、漂移状态、更新状态。

按钮：`导入`、`创建技能`、`应用到 Agent`、`同步副本`、`更新`、`卸载`。

### 10.3 空状态

```text
建立你的第一个研究技能
[导入技能] [创建技能] [查看示例]
```

## 11. MCP 页

### 11.1 列表

```text
● filesystem
stdio · 已连接 · 已应用到 4 个 Agent
                                     [检查] [启用] [⋯]
```

状态分为：已连接、未检查、连接失败、已停用。

### 11.2 添加流程

选择协议 → 命令或 URL → 参数和环境变量引用 → 测试连通性 → 选择分发范围 → 保存。

相对命令路径、密钥引用、各 Agent 分发状态在详情抽屉中说明。

### 11.3 按钮

`添加 MCP`、`从预置添加`、`导入`、`检查连通性`、`启用/停用`、`应用到 Agent`、`⋯`。

不支持写入的 Agent 必须置灰并显示能力原因，不允许静默失败。

## 12. 用量页

### 12.1 页面结构

```text
用量                         货币  今日  近 7 天  近 30 天  全部  刷新

总消耗 / 输入 / 输出 / 会话数 / 估算费用
趋势
按项目
按 Agent
任务成本
按模型
```

统计卡只突出一组核心数字；其余用轻量文字和列表表达，不做五张同等权重的大卡。

### 12.2 交互

- 时间范围使用 `SegTabs`。
- 货币切换为图标按钮并带 tooltip。
- 项目行点击进入项目详情。
- Agent 或模型行点击进入对应筛选后的对话/运行视图。
- 官方账号显示「订阅」，不按官方价计费；仍显示 token 统计。

## 13. 设置页

设置改为左侧子导航 + 右侧内容，不再是一条难定位的长页面：

```text
外观
启动行为
快捷键
统计
集成
更新
诊断
数据与存储
关于
```

每一行统一为：设置名 / 当前值或开关 / 一句说明。

### 13.1 外观

- 深色、浅色、跟随系统为第一层。
- 具体主题收在高级主题。
- 终端字号、字体、调色板、滚动缓冲按现有语义保留。

### 13.2 快捷键

- 显示命令面板、隐藏侧栏、页面切换、终端查找等快捷键。
- 录制冲突时就地提示并拒绝保存。
- 空值代表禁用，但界面必须给出恢复默认按钮。

### 13.3 集成、更新、诊断

- 分组默认收起，保留状态摘要。
- 诊断日志、导出、有效配置快照、诊断包动作放在同一组。
- 诊断导出前显示脱敏说明，不展示密钥。

## 14. 全局模块

### 14.1 命令面板

30rem 浮层，支持：页面跳转、创建项目、快速开聊、切主题、打开设置、聚焦运行标签、打开最近文件。

每行显示图标、命令名、快捷键；搜索结果分组；Esc 关闭；不重复执行页面已有确认逻辑。

### 14.2 快速开聊

弹层只询问 Agent、连接、目录。确认后创建终端标签并自动启动；无连接时降级为预填，不创建项目。

### 14.3 收件箱

顶栏胶囊按类别显示数量；点击展开分类浮层。每行只有：状态点、内容、一个动作、忽略按钮。

忽略只隐藏当前签名，状态变化后重新出现。

### 14.4 项目设置抽屉

从项目详情右侧打开，分为基本、研究流程、文献与数据、定时巡检。保存后保持项目详情上下文，不跳到新页面。

### 14.5 成果工作台与阅读区

- 文件、对话、改动使用标签或分段，不新增常驻第三栏。
- 阅读区保留「笔记｜PDF｜Agent 终端」三栏沉浸模式。
- Esc 优先退出阅读覆盖层；底下终端保持挂载。

### 14.6 评审覆盖层

全宽覆盖层优先显示变更摘要、逐 hunk、产物和人工事项。主操作只有`批准并合并`或`返回修改`；危险动作收进更多菜单。

## 15. 响应式与跨平台

- 宽度不足时先隐藏文字标签，再收起辅助栏，最后才压缩主内容。
- 终端页优先保证输出区宽度；文件树和成果面板可折叠。
- Windows/Linux 不依赖 macOS 红绿灯布局。
- 所有可点击元素最小热区 28px。
- 键盘 Tab 必须能到达主要操作；tooltip 不能是唯一可访问名称。
- `prefers-reduced-motion` 下关闭入场动画。

## 16. 逐项核验清单

### 外壳

- [ ] 默认打开工作台，不是连接页。
- [ ] 侧栏只保留主路径和低频管理区。
- [ ] 顶栏显示当前项目、步骤、运行状态和待处理数。
- [ ] 命令面板只保留一个入口。
- [ ] 收起侧栏后所有图标仍有 tooltip。

### 页面

- [ ] 每页只有一个主 CTA。
- [ ] 页面标题、筛选、主体层级一致。
- [ ] 列表不再平铺全部低频按钮。
- [ ] 空、加载、错误、成功状态均可独立核验。
- [ ] 项目详情的身份段、流程段、工作段顺序不变。

### 终端

- [ ] 启动栏默认只显示 Agent、连接、模型、目录、运行。
- [ ] 高级选项进入更多菜单。
- [ ] 运行、会话、查找、专注的行为清晰可见。
- [ ] 目录失败提供选择目录和重试。
- [ ] 终端标签可拖拽、关闭、分屏和恢复。

### 安全与语义

- [ ] 密钥永不回显或进入 shell/日志。
- [ ] 只读保护、评审合并和项目隔离语义不变。
- [ ] 删除与移除注册清楚区分。
- [ ] 不支持的 Agent 能力显示原因，不静默失败。

## 17. 推荐实施顺序

1. 应用外壳、导航、顶栏、按钮和状态基础组件。
2. 工作台与项目列表。
3. 项目详情三段结构、项目设置抽屉。
4. 运行/终端上下文栏、标签栏和状态栏。
5. 对话双栏与详情操作。
6. 连接、技能、MCP 管理页。
7. 用量和设置。
8. 命令面板、快速开聊、收件箱、阅读区、评审覆盖层统一验收。

每完成一项，必须在当前热更新窗口完成：默认状态、空状态、加载状态、错误状态、主要操作、键盘操作和窗口尺寸核验。
