## Mesa 能帮你干什么

Mesa 是装在电脑上的 **AI 科研工作台**。

你可以把它想成三件事叠在一起：

- 一个**书桌**：课题文件夹、文献 PDF、笔记、草稿都在这里，不会散落到九个不同的聊天窗口里。  
- 一个**管家**：替你记住用哪家 AI、哪套密钥、这个课题现在进行到哪一步。  
- 一扇**验收门**：AI 改完的东西，默认先放在旁边的工作副本里，你看过、点过「收下」，才进你的课题文件夹。

它能接这九家终端里的 AI（你不必九家都装，有一家能干活就行）：

Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Kimi Code、CodeBuddy Code、Cursor CLI、Grok Build。

日常最常见的用法是：

- 围绕一个课题检索、筛选、精读、写综述或论文  
- 让 AI 在隔离的副本里改稿、改代码、改数据，你验收后再写回  
- 把以前在各家 CLI 里聊过的记录，按课题回放  
- 每天/每周自动扫一轮新文献，你决定要不要收进课题

> **【配图】** 一张总览：书桌（项目）+ 管家（连接/步骤）+ 验收门（评审）。  
> **【配视频】** 30 秒：从工作台点进一个课题，能看见步骤、一篇 PDF、一次对话。

### 三个人怎么分工

打开 Mesa 之后，请按这个分工想，不容易走偏：

| 谁 | 干什么 | 不干什么 |
|---|---|---|
| **你** | 定课题、选文献、登录学校、决定哪一版算数 | 不用手填一堆环境变量，也不用盯着黑窗里的每一行日志 |
| **Mesa** | 准备环境、隔离工作副本、记住步骤、把 PDF 收进 `papers/`、拦住未验收的写回 | 不替你登录学校、不存机构密码、不把「文件写完了」当成「研究成立」 |
| **AI** | 检索、写笔记、改文件、出草稿 | 不能自己点「合并进项目」，也不能批量去出版商网站扒 PDF |

### Mesa 明确不做的事

- 不是 ChatGPT 那样的网页聊天框。真正干活的是你电脑上的那些 Agent 程序，Mesa 负责把它们管起来。  
- 不会自动把一个大课题拆成很多子任务、也不会替你选该用哪家 AI。  
- 不会保存学校图书馆的账号密码，也不会在你睡觉时批量下载付费全文（那样会连坐全校 IP）。  
- 不会把 Agent 报告里的「通过」「已完成」自动当成你可以投稿。

界面上叫 **Mesa**。你电脑里的数据文件夹仍叫 `ccode`（课题里的 `.ccode/`、家目录下的 `~/ccode/`）。备份或换电脑时，按这些路径找，不要按「Mesa」去搜数据盘。

## 为什么界面是现在这样

终端里的 AI 已经很会写、会搜、会改文件。科研里真正麻烦的往往不是「它会不会写」，而是：

1. **配一次就要配九次。** 每家 CLI 密钥、地址、技能都不一样，换电脑又来一遍。  
2. **现场容易乱。** 两个 AI 同时改同一个文件夹，文献 PDF 和实验草稿混在一起，最后不知道哪一版是真的。  
3. **没有验收。** 模型越强，越容易把「我写完了」说成「你可以交了」。你需要一个地方看清改了哪些文件，再亲手收下。

所以 Mesa 做了几条你以后会反复碰到的规矩（先有个印象即可）：

- **课题是家。** 对话、步骤、文件、定时任务都挂在这个文件夹上，不挂在某一次聊天上。  
- **成稿走副本。** 要落进课题的正式成果，默认在旁边的工作副本里做，你点过评审才合并。随口问一句，用「＋新对话」，那是直接改课题文件夹。  
- **PDF 是原始资料。** 下载或关联来的文献直接进课题的 `papers/`。AI 做出来的表、图、成稿要评审后才进主文件夹。  
- **密钥不出门。** 界面只显示尾号。默认只把配置注入这一次运行，不改你电脑上 CLI 的全局文件——除非你自己点「设为全局默认」。

## 装上、打开、认路

### 下载哪个包

到 [Releases](https://github.com/hongtongzhou-design/ccode/releases/latest) 按下表选：

| 你的电脑 | 选这个 |
|---|---|
| Mac，芯片是 M1 / M2 / M3 / M4 | `Mesa_x.x.x_aarch64.dmg` |
| Windows | `Mesa_x.x.x_x64-setup.exe`（公司批量装可以用 `.msi`） |
| Ubuntu / Debian | `.deb` |
| Fedora / RHEL | `.rpm` |
| 其他 Linux | `.AppImage`，先 `chmod +x` 再双击 |

名字里带 `.sig`、`latest.json` 的是自动更新用的签名，**不用下载**。

不确定 Mac 是不是苹果芯片：左上角苹果菜单 → 关于本机 → 看「芯片」。Windows：设置 → 系统 → 关于 → 系统类型，一般是 x64。

### 安装时可能碰到的唯一拦路虎（Mac）

第一次打开如果系统说「已损坏，无法打开」：**文件没坏**。因为应用暂时还没做苹果公证，从网上下来会带隔离标记。

打开「终端」应用，粘贴这一行回车：

```bash
xattr -cr /Applications/Mesa.app
```

然后再打开 Mesa。以后每次重新下载安装，都要做一次。

> **【配图】** 三个平台安装包对照；Mac「已损坏」提示和终端里那一行命令。  
> **【配视频】** 从下载 DMG 到第一次看见工作台，中间含「已损坏」的处理。

### 打开之后你在哪

默认停在 **工作台**。页头写着「工作台」，旁边一行小字是「从当前工作开始」，右上角有一个次要按钮 **快速开聊**。

左边是一列图标。上面一组叫「工作」，中间一组叫「资源」，最底下是「用量」和「设置」。九页从上到下是：

**工作台 → 项目 → 运行 → 对话 → 连接 → 技能 → MCP → 用量 → 设置**

可以用键盘切：Mac 是 `⌘1` 到 `⌘9`，Windows / Linux 是 `Ctrl+1` 到 `Ctrl+9`。`⌘K` / `Ctrl+K` 打开命令面板，输入名字就能跳。

**还没有任何课题时，工作台中间是空的。** 你会看见：

- 标题：**从一个项目开始**
- 说明：添加项目后，Mesa 会从上次停下的地方继续。
- 实心按钮：**添加项目**（点了会跳到「项目」页）

这时不要慌。你有三条同样合理的路：

1. 只想先试 AI 会不会说话 → 点右上角 **快速开聊**（不建课题，见下一节）。  
2. 已经有一个课题文件夹 → 点 **添加项目**。  
3. 还没有课题、想先摸科研界面 → 到「项目」页点 **✦ 创建示例课题**。

窗口最顶上（Mac 在标题栏）有时会出现 **待处理** 和数字：那是收件箱，有要你拍板的事才亮。没有数字就是没事。新装好的 Mesa 通常没有待处理。

**怎样算安装成功：** 能看见工作台；空态那张「从一个项目开始」在；左边九个入口都能点进去。Git / Node 缺了也不妨碍先看界面，但开科研步骤或编程前最好到 **设置 → 诊断** 装上。

以后升级：待处理里会出现「更新」，点「去安装」，或打开 **设置 → 更新**。装完会自动重启，进行中的对话请先保存。

> **【配图】** 全新安装的工作台：空态「从一个项目开始」+ 右上「快速开聊」+ 左侧九页。

### 还不想建课题：快速开聊

适合：还没想好文件夹叫什么，只想先问一句、试模型、试密钥。

1. 工作台右上角，或侧栏的快速开聊入口，点 **快速开聊**。  
2. 弹层标题就是「快速开聊」，说明是 **不建项目，直接开个终端聊。**  
3. 选 Agent 和连接，点开始。会进 **运行** 页，目录默认在本机 `~/ccode/scratch`（随手聊，不是某个课题）。  
4. 聊出有用的东西了：运行页这个标签的 **⋯ → 转为项目…**，选一个文件夹登记。之后这些对话会跟到那个课题下面。

勾过「记住选择」之后，再点侧栏快速开聊会直接开聊，不再先问。工作台页头和 `⌘K` 里的「＋ 快速开聊」永远先弹出层。侧栏这项可以右键看「继续上次」的随手聊历史。

**怎样算做成：** 运行页出现一个标签，聊天或终端里 AI 在回；改动面板若写「不是 git 仓库」，对随手聊是正常的。

**不要用快速开聊干的事：** 写综述、下文献、要进课题的成稿。那些需要一个项目当家。

> **【配视频】** 快速开聊一句 → ⋯ 转为项目。

## 第一次用：从零到能聊

下面是**要在一个课题里干活**时最顺的顺序。只想先试一句，走上一节「快速开聊」即可，不必先建项目。

每一步都有「怎样算做成」。整段大约 15–25 分钟。

### 第 1 步　看一眼本机缺什么

打开 **设置 → 诊断**。

看 **Git** 和 **Node.js** 是不是打勾。科研和编程都要用 Git；很多 Agent 靠 Node 安装。

缺了就点行内的 **一键安装**（Mac 走 Homebrew，Windows 走 winget）。装完点「重新检测」。

Linux 没有一键时，页面上会写 apt / dnf 命令，到系统终端执行。

**怎样算做成：** 两行都是 ✓，或你已经按提示装上了。

### 第 2 步　让至少一家 AI 能用

打开左边 **连接**。

如果你还没在电脑上装过任何 Agent：在对应那一家的卡片上点 **安装**，确认后等它跑完。

然后给它一把能用的密钥，或登录官方订阅。详细点法见后面「先让 AI 连得上」。这里先记最短路径：

1. **＋ 添加连接**  
2. **端点预设** 里选你买过的那家（DeepSeek、智谱、月之暗面、百炼、OpenRouter 等）  
3. 把 API Key 贴进去  
4. 点 **验证并获取**（会真的发一次请求，通过才会列出模型）  
5. 保存  

**怎样算做成：** 这家卡片里出现一条连接，密钥显示尾号，不是报错红字。

### 第 3 步　有一个课题文件夹

打开 **项目**。

左边还是空的时候，主区写着 **从一个项目文件夹开始**，两个按钮：**添加项目** 和 **✦ 创建示例课题**。左边列表头部的 **＋** 也是添加项目（菜单里同样有示例课题）。

想先摸界面、没有自己的文件夹：点 **✦ 创建示例课题**。它会在「文档/Mesa 示例课题」生成一套英文综述演示（检索已经筛过、有一篇 PDF）。打开后聚焦「文献精读与笔记」，主按钮是 **开读这一篇**。演示数据不能当科研证据。

有自己的文件夹：

1. 点 **添加项目**。先弹出系统选目录窗口（还没有文件夹就先在访达/资源管理器建一个再选）。  
2. 接着弹出 **添加项目** 表单：上面是刚才选的路径，下面填 **项目名**，再选 **工作方式**（三选一，界面里以后不能改）：
   - **科研** — 按课题推进，可选研究流程、任务卡、文献雷达  
   - **编程** — 按分支和工作树推进，管并行改动和合并  
   - **工作** — 处理工作文档和日常材料（公文、幻灯、表格这类）  
3. 点 **添加**。

选 **科研** 之后不会直接结束。会再弹出 **选择研究流程模板**，第一句是：「某某」已添加。写论文请挑一套流程；只读文献、写笔记，选下面的「不使用研究流程」。上面可以填 **课题主题（可选）**，占位示例是「如 GLP-1 受体激动剂的心血管结局」。

- 写综述：点 **英文综述**（卡片上写着五步）  
- 只读文献：点左下 **不使用研究流程**  
- 现在不定：点右下 **稍后再选**（项目页上还会提醒你选）

选中一套模板后，还会进一屏贯穿全程的设定（综述角度、篇幅等），不确定的可以留空，点 **保存设定并应用模板**。

**怎样算做成：** 左边列表里出现这个名字，右边顶上能看见「对话 / 科研任务 / 定时任务 / 文件 / Agents」；有流程时任务页顶上有一排大圆。

### 第 4 步　告诉这个课题默认用哪家 AI

打开项目顶栏的 **Agents**。

找到你刚配好的那一家，点 **设为默认**。卡片会微微高亮。

卡片上的连接名可以点开。里面是这条连接已经带上的每一个模型，点其中一个，这个课题以后开聊、开工就用它。换模型只影响这个课题，不改连接页上的名单顺序。名单里没有的模型，点右上角 **管理连接** 去加。

**怎样算做成：** 那张卡上写着「项目默认」。点开连接名能看到这条连接的模型，点中的那个显示在卡片上。以后在这个课题里点「开始」或「＋新对话」，就会用它。

### 第 5 步　真的说上一句

两条路，按你现在要干什么选：

- **只问一句、改一个错字：** 项目顶栏或对话页点 **＋新对话**，直接说。这会改课题文件夹本身。  
- **要出一版能收进课题的成果：** 在科研任务里点当前步骤的 **开始**（有流程），或 **新建目标**（无流程）。AI 在旁边的工作副本里做，你验收再写回。

**怎样算做成：** 运行页出现一个标签，聊天里能看到 AI 在回，或终端里 Agent 已经启动。

> **【配视频】** 按上面五步从头走一遍（诊断 → 添加连接 → 添加项目或示例课题 → Agents 设为默认 → 开读或开聊）。另一种拍法：工作台空态点快速开聊。

## 左边九个入口分别是什么

先建立「去哪找什么」的地图，后面各章再展开怎么操作。

> **【配图】** 侧栏九页，用三个括号标出：工作、资源、管理。

### 工作：每天待着的地方

**工作台**  
进来第一眼。

- 还没有课题：就是上一节说的空态「从一个项目开始」。  
- 有课题、AI 正在跑：这一区的标题是 **正在进行**，大卡上课题名 + 实心 **继续工作**；小绿点表示在跑，黄点旁会写 **待确认**。  
- 有课题、但这一刻没人在跑：标题改成 **继续工作**。点进去回到上次停下的地方，不是新开一轮。  

右侧（宽屏）或下方可能有 **待你处理**（收件箱前几条）和 **待你验收**（目标跑完等你勾选的）。再往下是 **最近项目**、**最近对话**。

终端标签关了也不怕：点 **继续工作**，按那一次运行找回，不是只能翻标签。

**项目**  
课题的家。左边是课题列表，按 **科研 / 编程 / 工作** 分组（还没添加的仓库沉在最下），右边是当前课题。添加课题只在左边的 **＋**，不在顶栏。

**运行**  
真正盯着 AI 干活的地方。一个标签就是一次运行。聊天和黑窗是**同一次对话的两种看法**，切来切去不会丢掉进度。

**对话**  
以前聊过的记录。按课题、按 Agent 回放，不是用来新开聊天的主入口（新开在项目里的「＋新对话」或运行页）。

### 资源：让 AI 有手有脚

**连接**  
密钥、地址、模型。没有这里，运行页的「运行」按了也起不来。

**技能**  
给 AI 的短说明书，例如「精读笔记要写成哪八节」。有研究流程时，技能挂在步骤上，不必自己到这里临时勾。

**MCP**  
外部工具接口，例如学术检索库 Consensus、Undermind，或本机 Blender。配了之后，新开的对话才能用。

### 管理：偶尔才来

**用量**  
花了多少 token、估多少钱。官方订阅显示「订阅」，不算钱。

**设置**  
外观、终端、快捷键、学校图书馆登录、代理、更新、诊断。

### 顶上的「待处理」是什么

不是装饰。只有**要你拍板、不拍就卡住**的事才进来，例如：

- Agent 在等你确认一条命令  
- 步骤做完了，改动可以合并  
- 两边改了同一处，有冲突  
- Mesa 自己有新版本  
- Agent 写了一张「请你帮忙」的条子（补检索词、某篇下不到）

点进去是一句话 +「去处理」。全部处理完，图标自己消失。

**不会出现在这里的：** Agent 说完一轮、等你下一句。那是每天都发生的事，不打点、不通知。

> **【配图】** 待处理展开，标出「待确认」「可合并」「更新」三条。

## 先让 AI 连得上

没有连接，后面所有「开始」「问 AI」都是空转。这一节只要求你做成一件事：**至少一家 Agent，有一条能用的连接。**

打开 **连接**。每一家 Agent 一张卡片。还没装的卡片颜色更淡，上面有 **安装**。

### 安装 Agent 程序

点 **安装**，确认框会告诉你将执行的命令。Mac 优先用 Homebrew（自动走国内镜像），Windows 上 Claude / Codex / OpenCode / Kimi / Grok 可以用 winget，其余多数走 npm。

过程是一个小终端：有 `[y/n]` 就在下面回答。下载走国内镜像和你的出网代理，一般几十秒到几分钟；Mac 上个别走 GitHub 直下的包（如 OpenCode）会慢一些，只要进度还在走就是正常的。持续约 10 分钟没有任何动静才算卡住，会自动报错。

有「新版」按钮说明能升级，点一下即可。Kimi 那种要方向键选择的更新，会改到运行页的终端里让你用键盘选，不要在连接页干等。

### 用中转 / API 密钥（最常见）

把「网关」理解成：**一把密钥 + 一组网址**。  
把「绑定」理解成：**某家 Agent 用这把密钥里的哪些模型**。

你日常要做的是「添加连接」，不必先背这两个词。

**推荐做法：**

1. 点右上角 **＋ 添加连接**。  
2. **端点预设** 选供应商。地址、名称、推荐模型会自动填。  
3. 把 API Key 贴进密钥栏。界面保存后只显示尾号，完整密钥不会再给你看。  
4. 点 **验证并获取**。  
   - 成功：能看到延迟和模型列表，推荐模型会自动勾上（目录里没有的不会瞎勾）。  
   - 失败：按红字改地址或密钥，不要先保存。  
5. 同一把密钥还要给另一家 Agent 用：勾 **同时绑到**，保存一次建齐。  
6. 保存。

**怎样算做成：** 列表里出现这条连接；点「验证」能过。之后到运行页能选中它并启动。

几条容易踩的坑：

- 给 Claude / CodeBuddy 填的地址 **不要** 以 `/v1` 结尾（程序会自己拼，多写一层就 404）。  
- 给 Codex、Kimi、Qwen 这类 OpenAI 协议的地址，一般 **要** 带 `/v1`。  
- 智谱如果还要给 Codex 用：普通槽填 `paas/v4`，再把 Responses 槽填 `api/v1`。勾了「同时绑到 Codex」时，预设会帮你补。  
- Cursor 没有通用预设，第三方中转通常接不上，请用 Cursor 自己的密钥和模型。

> **【配图】** 添加连接：预设、密钥、验证并获取、同时绑到，四个位置画圈。  
> **【配视频】** 用智谱预设同时接到 Claude 和 Codex。

### 连接行上那三件事：编辑 / 停用 / 解绑

「这条连接我不要了」有三种意思，别点错：

- **编辑**（行上常驻按钮）：换密钥、加减模型。用它的地方下次启动一起变。改完的模型组合如果和这家 Agent 上另一条连接**一模一样**，保存会被拦下并提示「已经有相同模型选择的绑定」——同一家 Agent 两条同源同名单的连接没有意义，改个模型或换个网关再存。
- **停用此连接**（行尾 ⋯ 菜单）：只是不让它被自动挑中——启动栏预选、恢复会话、AI 功能回落都跳过它；列表里还在，启动栏下拉的「已停用」分组里仍能手选。想恢复就再点一次「取消停用」。
- **解绑**（行尾 ⋯ 菜单）：删掉这条连接在某家 Agent 上的用法。**网关和密钥都留着**，同一把密钥给别家 Agent 的绑定不受影响。

解绑前留意一件事：如果有个课题的定时任务正用着这个配置，弹窗会告诉你有几条、分别叫什么。**解绑后这些任务不会自动改用别的 AI**，会在下一次该跑的时候停下，运行历史里留一条失败记录，写明配置不存在。这是故意的——半夜悄悄换一家出站，比停下更麻烦。要让它继续跑：先到那个课题的「定时任务」里把连接改成别的，再回来解绑。

> **【配图】** 一行连接上：编辑按钮、⋯ 菜单里的「停用此连接」与「解绑」。

### 模型能力报错或查不到：写一条「能力声明」

中转的新模型（改名模型、刚上架的型号）有时公共能力库里也查不到。症状：Claude 把它当 200K 小窗口、长对话提前压缩；Codex 模型目录里窗口写小了；明明能看图的模型贴图被拒。你可以手写一条声明，**写一次，本机所有 Agent 共用**。

打开 **连接 → 网关库 → 编辑**，展开「模型策略」里那行模型，最下面有 **能力声明**：

1. 填你知道的字段：**上下文窗口**（如 `1048576`）、**思考 / 视觉**选「支持」或「不支持」。
2. 不确定的字段留「未声明」——留空的字段继续走公共库和内置表推断，不会瞎猜。
3. 点 **保存声明**。

**怎样算做成：** 面板顶部「当前解析」变成你填的值，行右侧的徽章跟着变（比如出现 `1024K`）。想撤销：把字段全清空，按钮会变成 **清除声明**，点一下即删。

容易卡的点：

- 思考/视觉选「不支持」是**硬声明**——推断链到此为止，就算公共库说支持也不再听它的；拿不准就留「未声明」。
- 每次请求要限制输出长度用的是上面的 **max output**（策略），能力声明里没有输出一项——两者的分工：max output 是「这次让它最多写多少」，能力声明是「这个模型本身是什么规格」。

### 用官方订阅（ChatGPT / Claude 账号等）

Claude Code、Codex、Gemini、CodeBuddy、Cursor、Grok 支持。

添加时「账号类型」选 **官方账号**，不用填密钥。对应卡片组头点 **登录**，按终端里的提示完成。Codex 会给你一串设备码，用浏览器打开它说的地址、输入这串码。

**怎样算做成：** 组头变成绿点「官方已连接」。

国内网络直连官方常常失败。到 **设置 → 网络**，在「出网代理」填你本机代理，例如 Clash 的 `http://127.0.0.1:7890`。不知道地址就点旁边的 **检测**，列出正在跑的代理，点一下即填入。这份代理**给官方登录、官方启动和 Agent 安装/更新下载用**（国内镜像源的下载自动直连、不绕代理）；走中转网关的连接不会被它拐到境外。

### 两种「生效」别混

| 你想要的 | 怎么做 |
|---|---|
| 只在 Mesa 里用，不改电脑上其它终端 | 什么都不用点，启动时自动带上（默认） |
| 系统终端、ChatGPT 桌面客户端也走这套 | 连接行 **⋯ → 设为全局默认** |

设为全局会改 CLI 自己的配置文件，Mesa 会先备份。可「撤销上次写入」，也可以「恢复初始状态」（回到 Mesa 第一次改之前）。

Grok 走中转时，设为全局会给每个绑定模型写上推理强度菜单（Extra High / High / Medium / Low）。中转目录自己不报档位时，不写这段，Grok 里就选不了推理强度。你已经手写过的档位 Mesa 不会覆盖。写完要新开一次 Grok 会话才看得到。

本机如果还装着 cc-switch 一类切换工具，点「设为全局」会先提醒你不要两边同时改。Codex 的「设为全局」**不会**去改 `auth.json`。

某条连接暂时不想被自动选中：⋯ → **停用此连接**。启动栏最底下「已停用」里仍能手选。不是删除。

行上悬停出现的 **⌨ 在终端使用**：用这条连接直接新开一个运行标签，适合「我现在就要试一下」。

## 建一个课题

打开 **项目**。左边是你的课题，右边是当前课题的内容。

### 三种工作方式（添加时选一次）

| 方式 | 适合 | 主画面 |
|---|---|---|
| **科研** | 文献、实验、论文 | 步骤或目标 + 文献 + 文件 |
| **工作** | 公文、幻灯、表格 | 目标 + 文件预览 |
| **编程** | 写代码、开分支、PR | 工作树（一棵树一次改动） |

选完不能在界面里改成另一种（表单上会写「已选定，不可更改」）。真要换，请另建一个项目（文件夹可以是新的）。按钮上写的是 **工作**，不是「办公」。

> **【配图】** 添加项目弹窗：三种工作方式各一行说明。

### 科研项目打开后有五个页签

默认停在 **科研任务**。顶栏还可以切：

| 页签 | 你来这里是为了 |
|---|---|
| **对话** | 看这个课题里 AI 做过的记录，点一条回放 |
| **科研任务** | 看进行到哪一步，点「开始」或管目标 |
| **定时任务** | 文献雷达、每天自动巡检 |
| **文件** | 找 PDF、笔记、表格；左边目录，右边预览 |
| **Agents** | 指定这个课题默认用哪家 AI、哪条连接、这条连接里的哪个模型 |

规则、课题主题、验收记录在顶栏 **⋯ → 项目设置**，不占任务页地方。

每个课题会记住你上次停在哪个页签。

### 有步骤的科研：从模板开始

添加成功后弹出的那一层，标题是 **选择研究流程模板**。先可以填 **课题主题**（以后每次开工都会带给 AI），再点下面某一套（每张卡写着步数和一条路径）：

- **英文综述**（5 步）：文献检索与筛选 → 精读笔记 → 大纲 → 初稿 → 润色定稿  
- **科研论文**（8 步）：计算实验向。分析结果之后先写论文大纲，再写初稿。湿实验或问卷要自己改实验步  
- **数据处理**：登记检查 → 清洗 → 探索 → 报告  
- **毕业论文**：开题到格式定稿  
- **投稿与返修**：首投改格式；返修按轮次回审稿意见  
- **LaTeX 论文**：有成稿就转排版，也可以从笔记从零写  

拿不准就选英文综述，或点左下 **不使用研究流程**（只读文献）。右下 **稍后再选** 只关弹层，项目页上还会提醒你选。

点中一套之后，进入填写屏。英文综述会问综述角度、篇幅、读者、去向、深度。暂时不确定可以点 **暂不填写，稍后补充**。空着的会留在顶栏 **⋯ → 项目设置** 的规则里，一行一个，括号里是可以怎么填。你把括号换成自己的答案；也可以在步骤上点 **跟 AI 商量一下**，它会逐项问你，你确定后它改那一行。还是括号的不会写进「项目规则」，但会出现在每一步任务书的 **待确认的全局设定**。Agent 开工或跟你商量时要先逐项问你，你确定后它才改规则里的那一行，并按你的答案做。做完点 **保存设定并应用模板**。

稿件用 Word 还是 LaTeX、图用不用 Origin、要不要进 Zotero，**不在添加项目时问**。到用得上的那一步再选。文献从哪来，只在检索步问一次。

**怎样算做成：** 科研任务页顶上出现一排大圆（每一步一个），其中一个是当前步。当前步骤卡上如果已经有报告，会显示报告里写的状态，以及还有几处「待核实」「待确认」。这是报告自己写的，不是系统判你通过了。

润色、定稿、期刊格式和返修会先写一份审查报告。你把每条改成接受、拒绝或修改之后，AI 才按这些条改稿。改了数字、因果、样本或结论范围，会单独列在修改记录的「科学改动」里。已经在做的课题保持原来的步骤和任务书。新开的课题才会带上这些要求。不要为了升级去整套替换正在用的流程。

### 不使用研究流程

适合：文件夹里已经有 PDF，只想阅读和写笔记，或先不定步骤。

科研任务页变成 **目标** 列表：点 **新建目标**，写一句话即可，可以先「记下」再「开始」。默认把整个课题复制到隔离副本里做，你验收勾选后再写回。

文献雷达在 **定时任务** 页。PDF 在 **文件** 页。边看边写用沉浸阅读。

## 有步骤时，一天怎么往下走

把大圆理解成「这条路走到哪了」。点某个圆，下面出现**当前步骤卡**。卡片永远按这个顺序，只是每一步具体内容不同：

**先讨论、准备 → 你要做的事 → AI 干活（开始）→ 收尾 → 去评审**

右侧那颗实心按钮才是这一步的主动作：没开过是 **开始**，做完是 **去评审**，有冲突是 **解决冲突**。

> **【配图】** 大圆 + 当前步骤卡，把「开始」圈出来，人工事项用另一色。

### 开步之前要想清楚的

有的步骤会问几件开工前就能定的事（篇幅、读者、实验规模等），在 **先定几件事**：

- **直接选：** 展开选项卡片，点一个。  
- **跟 AI 商量一下：** AI 通读任务书，拿不准的逐个问你，按你的回答改任务书。商量过之后按钮会变成 **继续讨论**，再点接回上次，不是新开一轮。

不是每一步都要答。只有卡片上标明必须批准的，不答就不能点「开始」。要先看到数据才能定的问题（纳入标准严不严、精读读几篇），AI 会在跑起来之后拿着数字再问你，写在收件箱的「人工请求」里。点进去看完整问题，再用 **去终端回答** 回到那次对话告诉它；它还在干活就先打断再答。不回它会按每条后面的兜底继续。

精读确认篇目之后，AI 只给**读完的篇**写笔记（一句话总结、问题、方法、结果、局限）。叙述用中文，材料名、方法缩写这类惯用英文原词可以留着。没读完的不占「已读」。把英文摘要整段贴进笔记里不算精读。

### 它干完一批就停了

每一份任务书的 **决策暂停策略** 会列出这一步**必须停**的事项，例如：核心篇目还没拍板、纳入标准还没定、期刊还没选定、样张要你看排版、投稿前要你点头。写完一批、git 提交、报个进度，不在这个清单里。

它如果在不该停的地方停了：不要点 **开始**。用当前步实心圆或工作台 **继续工作** 回到原来那个终端，说「不必拍板就做到完成标准」。上下文写满时它仍可能自己停一轮，再回一句即可。

**怎样才算能去评审：** 这一步任务书里的完成标准达到了，不是「已经提交过一次」。该你看排版或核对 [待核实] 的，到这一步才轮到你。

大纲和初稿干完后，流程线上还有一件 **审阅后再开下一步**。点 **去评审**：稿件页先看源稿，Word 在 PDF 前面；PDF 标签会提示先看是否乱码。渲染参考文献之前，先看 `manuscript/citation-style.md`。里面按项目里的 PDF 列了编号、作者-年、按期刊。你在「选定：」后面写一种，才会渲出参考文献。没写就不渲。以后要换，改这一行再渲一次。顶栏若扫到摘要里的「待核实」、正文 G1、「待绘制」，会黄字列出来。下面有意见框：写完点 **退回修改**（接回原来那条对话，按意见改现稿）或 **按意见重写**（同一工作区新开会话，按大纲和笔记重写）。都不保存进项目。合意了再点右上角保存进项目。

Zotero 和 EndNote 做同样三件事。

- **导入**：不用 Zotero、也不用 EndNote 时，PDF 留在项目里。检索和精读按 PDF 里的 DOI 写入 `references.bib`，不经过任何文献库软件。用了 Zotero 的人，可以先关掉「自动重命名附件文件」、打开「自动检索 PDF 元数据」，把 PDF 拖进一个分类。Zotero 会读前几页并生成条目，再点「从 Zotero 导入」。拖进去默认是复制一份；要和项目里的 PDF 保持同一份文件，用「链接到文件」，并把链接附件根目录指到项目的 `papers/`。用了 EndNote 的人，在 EndNote 里导出 XML 或 RIS，放进 `papers/imports/`。不要把项目的 `papers/` 设成 EndNote 的自动导入文件夹，它可能把 PDF 搬走。Mesa 不读 `.enl`，也不把 Zotero 库再倒一遍进 EndNote。
- **同步**：待获取清单上有「同步到 Zotero」和「同步到 EndNote」。把项目里的题录送进对应的库。
- **交稿**：项目设置「文献库」选一个。定稿只交一份：Zotero 是 `output/zotero.rtf`（导入 RIS 后做一次 RTF Scan）；EndNote 是 `output/endnote.docx`（点一次 **Update Citations and Bibliography**）。

写作仍用 `[@键]` 和 `references.bib`。普通 `draft.docx` 换不了这两个软件的样式。

文献检索步在 AI 开始之前，还有一问：**确定文献来源**（整个课题只在这里问）：

- 让 AI 去检索  
- 我有 Zotero 库  
- 我已有 PDF / 题录（PDF 留在项目里，由这一步写成题录。已在 Zotero 或 EndNote 里的，走上面两个库）

选 Zotero 会给检索/精读步挂上同步技能。导入动作在项目设置的「文献与数据」里。

### 点「开始」之后发生什么

点步骤卡右侧的 **开始**，不会立刻跑。先弹出确认层。

你会看到：本步要产出什么、上一步传来哪些文件（缺的标「还没有」）、将用哪家 AI。任务书默认收起，可以展开改这一次。权限是写死的一行小字：写步骤工作副本 + 课题的 `papers/`（原始文献）；其它成品要等你评审。

右下角那颗实心按钮，字会变：

| 按钮上写的 | 意思 |
|---|---|
| **先加连接** | 这个课题还没有能用的 AI，先去连接页 |
| **确认开始** | 正常开工 |
| **仍要开工** | 有一件事没做完：上一步的收尾事项没勾完，或你改过本步要读的文件还没存进历史。第一次点「确认开始」只是说你知道，按钮变成这四个字，再点才真开 |
| **仅开始准备** / **先做无依赖工作** | 有些决定还没批准，只能做不依赖那些答案的准备 |
| **开始中…** | 已经在建工作副本 |

改过本步要读的文件（比如精读后又改了笔记）时，确认层里会列出这些文件并给 **存进历史** 按钮：点了再开工，新工作副本才看得到你的修改；不存就跳过的话，这一步只认已保存的旧版。

硬暂停没选「批准指定范围」时，开始是点不了的，层里会写待拍板的问题。

确认之后：

1. Mesa 建好工作副本、写好任务书，有连接就会直接拉起 AI。你到 **运行** 页。  
2. 画面中间可能先是「将在 … 启动」，然后变成聊天或终端。你可以说话，也可以看黑窗里的原始界面。  
3. 告一段落，回到项目点 **去评审**。看改了哪些文件，点 **提交并合并**，成果才进课题主文件夹。

合并成功只表示**文件进项目了**，不表示论文结论你已经接受。科学上的接受是另一回事，不要看见绿灯就投稿。

**怎样算做成：** 大圆这一步变成已推进；文件页或评审里能看到新产出；你点过合并（或明确决定先不合并）。

> **【配视频】** 检索步：定文献来源 → 开始 → 运行页里看它干活 → 回到项目去评审合并。

### 「＋新对话」和「开始」不要用反

| 你想 | 用这个 |
|---|---|
| 问一句、改个别字、看看某段 | 项目里 **＋新对话**（直接改课题文件夹） |
| 出一版要进课题的正式成果 | 步骤 **开始**，或无流程时 **新建目标** |

＋新对话不会把「还没完成的目标」「验收后才进项目」塞给 AI。它只知道：这是哪个课题、里面有什么、规则是什么、你这次说了什么。

## 付费墙文献怎么进项目

检索之后，开放获取的 AI 会自己下到 `papers/`。剩下过不了付费墙的，会进人工事项 **下载付费墙文献全文**。

展开 **待获取**，每一行是一篇。不要对整份清单点「全部下载」。

### 日常就做这三件事

**1. 用学校权限打开这篇**

点行上的 **浏览器**。系统默认浏览器会打开这篇的页面（能走图书馆代理的会自动带上）。你在网页上用站点自己的下载。PDF 落到电脑「下载」文件夹后，Mesa 会在大约 90 秒内试图收进这个课题的 `papers/`。

按钮在等待时会写成 **等待收货…**。行上会出现强调框，方便你从浏览器切回来还找得到。

**2. 已经下到别处**

点 **关联**，选那个 PDF。Mesa 复制进 `papers/`，你的原件不动。

**3. 确认是不是这篇**

行上变成 **✓ 已存** 之后，**点这篇的标题**。会跳到项目的 **文件** 页并打开对应 PDF。看完切回「科研任务」，清单应还停在刚才那一行，已存状态还在。

不想补的可以不做，下一篇按摘要记。

> **【配图】** 待获取一行：浏览器、关联、已存后标题可点。  
> **【配视频】** 登录学校 → 点浏览器 → 站点下载 → 清单变已存 → 点标题核对 PDF → 切回清单还在原处。

### 先登录一次学校账号

在 **设置 → 网络 → 学校图书馆**。

主按钮只有一个：**登录学校账号**。默认打开 CARSI，选你的学校，完成账号和二次验证。Mesa **不保存账号密码**。登录发生在你的浏览器里，一次可长期有效。

校园网里直连数据库的，往往不用再填任何地址。

校外打开文献仍是出版商登录页时，展开 **校外打不开全文时**，把图书馆「校外访问」链接贴进去（形如 `https://proxy.学校.edu.cn/login?url=`）。之后点「浏览器」会先走学校代理。

**内嵌窗、保存会话、浏览器桥** 在 **其他方式** 里，日常可以当没看见。

**怎样算做成：** 浏览器里已经能看到学校资源或已登录状态；回到 Mesa，待获取里点「浏览器」打开的是能下 PDF 的页面。

### 收货对不上号时

右下角可能弹出横幅：文件名和清单对不上。可以一键收进你刚才打开的那篇；原件会留在下载文件夹，避免误收合同扫描件。

一篇都没收到：看是不是下到了非系统「下载」目录、是不是超过大约 90 秒、浏览器是不是拦了下载。用 **关联** 总能补上。

同一篇不要连点很多次「浏览器」刷屏。强调框在，点下一篇才会换到下一行。

### 和 Zotero 一起用

待获取会附带一份 `papers/to-fetch.ris`。点 **同步到 Zotero** 会用 Zotero 打开它（Zotero 自己识 RIS，不需要 Better BibTeX）。

**不能**指望按钮自动把 PDF 挂到条目上（Zotero 9 的本机接口是只读的）。把 `papers/` 里的 PDF 拖到对应条目上即可。

## 精读：三栏阅读

文献进了 `papers/` 之后，打开 **文件** 页，点这个 PDF。悬停行上的 **⛶ 沉浸阅读**（示例课题精读步也可以点 **开读这一篇**）。点 `notes/` 里的笔记行也一样能进——Mesa 会自动找到这篇笔记对应的 PDF。

屏幕变成三栏：

- 左：**笔记**（按精读结构准备好的 Markdown，已有笔记会配对，不另建一份）  
- 中：**PDF**，可以滚动、缩放、选字  
- 右：**Agent 终端**，还想问就在这里问  

按 **Esc** 退出。这次阅读自动开的「阅读」标签会一起关掉（AI 正在生成的回答也会被打断）；从文件页（或项目页其它入口）进来的，退出后直接回到进入前那一页。你自己开着的其它终端不受影响。

在 PDF 里选一段，浮动条可以：翻译、问 AI、收入生词本。圈选可以截图进笔记。

**怎样算做成：** 三栏都在；左边是这篇的笔记，能存；退出后文件页里还找得到这篇 PDF。文件页「已读」表示真有笔记，不是空模板。

> **【配图】** 三栏阅读，把选段浮动条画出来。  
> **【配视频】** 划一段问 AI，看笔记「我的想法」里出现内容。

文件页本身：左边是目录（滚动预览时目录不会跟着跑掉），右边是预览。顶上用图标筛 PDF / 文档 / 表格。点文件名就是预览，悬停有「问 AI」「在文件夹中显示」；PDF 和 `.md` 笔记行还多一个 **⛶ 沉浸阅读**（搜索、筛选出来的列表里也有）。

右边预览按类型分流：Markdown（含 `.qmd` / `.mdx`）默认阅读版式，标题多了会出 **目录**，代码块可以复制，`mermaid` 图能点开放大；HTML 默认在沙箱里渲染，可切回源码；表格（xlsx / csv）是格子；图片可以用 ⌘/Ctrl+滚轮缩放。打不开的二进制文件会给你 **用系统应用打开**。

英文综述的精读步保存进项目之后，可选区只有 **继续精读笔记**：点 **去笔记夹** 打开文件页的 `notes/`，再点一篇进三栏阅读。这里不再导入 EndNote，也不出现 Zotero。文献来源选了 Zotero 的课题，才在检索步按那个库同步。选了 EndNote 交差的，只在润色定稿交一份 `output/endnote.docx`，打开后点一次 Update。改完开大纲时，开工确认层会列出还没存进历史的笔记，点 **存进历史** 下一步才能看见。

## 让 Mesa 帮你盯新文献

打开项目的 **定时任务** 页。上半是 **文献雷达**，下半是定时列表。

### 订什么

雷达卡头点 **订阅**。一行一条：

- 关键词（你真正关心的那几个词）  
- 来源：arXiv / OpenAlex / Crossref / 网页，可多选  
- 备注：可写时间范围；写 `+bib` 时，推荐的条目会尝试写进 `references.bib`

保存即生效。还没有任何订阅时，卡片上会写「还没订阅读」，点添加即可。

也可以 **编辑源文件** 直接改 `papers/watchlist.md`（注释行会保留）。

### 何时自动跑

点 **＋ 定时巡检**，种类选 **文献雷达**，选每天或每周的几点。

到点后 Mesa 在**隔离目录**里跑，**不会直接改你的课题文件夹**。跑完「待处理」里出现「去评审 N 条新命中」：你看过，点 **采纳进主仓**，新文章才进 `notes/inbox.md`。

**应用没开就不会跑。** 下次打开会补跑一次漏掉的（漏多次也只补一次）。

单次最多大约 10 分钟。超时和失败在历史里分开显示。

### 雷达上怎么读

默认两行一条：标题 + 中文一句话。英文摘要要点标题才展开。

开放获取有 **↓ 全文**。只有 DOI、没有免费 PDF 的，可以试 **获取全文**（先查合法的开放副本；不是去撞付费墙）。想精读的点书签，PDF 和笔记到 **文件** 页看。

期刊的 IF、分区、TOP 小标，要先在卡头 **↓ 期刊指标表** 下载到本机（约 7MB）。数据版权归原数据方，Mesa 不内置转发，下载由你点。没装表时没有徽章，不会编造数字。

**怎样算做成：** 订阅里有关键词；定时列表里有一条启用中的雷达；跑过之后，待处理或雷达上能看见新命中，采纳后文件页/笔记里找得到。

> **【配图】** 雷达：订阅、两行一条、书签。  
> **【配视频】** 建每日雷达 → 立即跑 → 评审采纳一条。

## 闲聊和成稿不要走同一条路

这是用 Mesa 最容易用反的地方。

**随口问、改一个错字、让它解释一段**  
项目里 **＋新对话**。AI 直接在课题文件夹里改。适合「这个符号什么意思」「把这句话改通顺」。

**要留下一版正式成果（一章、一图、一次清洗）**  
有步骤就点 **开始**；没步骤就 **新建目标**，写一句话。AI 在隔离副本里做。做完你在验收里勾选要写回的文件。不满意就在意见里写，点「带着意见再出一版」——还是同一个目标，接着改，不另起炉灶。

文件页里，待你验收的文件会标 **待验收**。

有研究流程时，技能已经写在步骤上，任务页不会再摆一份「技能池」。没有流程的科研和「工作」项目，才在项目设置的规则里勾技能、勾「写回时跳过」（验收时不要覆盖的路径）。

## 看 AI 改了什么、决定收不收

步骤做完或目标跑完，不要只看聊天里的「我已经完成」。

1. 到项目点 **去评审**（或目标上的 **验收**）。  
2. 顶上可以切 **清单 / 笔记或稿件 / 过程 / 文件**。检索先看纳入表，精读先看笔记，大纲和写作先看稿件。要看增删切 **文件**。实验执行、分析和清洗才会出现验收摘要和接受/退回。图片会左右两张一起看。  
3. 主按钮 **提交并保存进项目**（步骤）或勾选后接受（目标）。提交信息可以留空，Mesa 会写一句很短的默认说明。  
4. 合并进的是**文件**。论文里的结论是否成立，仍要你自己看报告和数据。保存进项目不等于接受科学结论。

两边改了同一处：按钮会变成 **解决冲突**。按文件选「用任务这一版」或「用主文件夹这一版」，全部选完再合并。需要一行一行掺，去预览编辑器手改。

主文件夹自己还有没保存进历史的改动时，合并会被拦住。评审里可以就地把主文件夹的改动先存进历史，再继续。

**怎样算做成：** 主文件夹里出现你勾过的文件；验收记录里能翻到「谁在哪天收下了哪一版」（项目设置或目标页下方）。这不等于你已经同意投稿。

## 运行页：聊天和黑窗

左边点 **运行**。顶上一排标签，一个标签是一次干活。

旁边两个小图标是 **聊天 / 终端**：

- **聊天：** 像常见对话。Enter 发送，Shift+Enter 换行。技能和 MCP 菜单只是帮你插入一句提示，**不会替你按发送**。  
- **终端：** 各家 AI 自己的界面，登录、权限确认、`/model` 都在这里。  

两者是同一会话。切来切去，字不会丢。

还没点运行时，画面中间有一张卡：「将在某某文件夹启动」+ 实心的 **运行**。上面启动栏是三截：当前 Agent、配置、模型，写的是名字本身。点开向下列清单，顶上标明在选哪一项。选过会记住。

右侧是 **文件** 和 **改动**。改动里可以勾选后提交。

标签上转圈的虚线圆表示「正在写回答」。它停了不代表 Agent 退出了，只代表这一轮话说完了。等你确认权限时是黄点，不是这个圆。

关掉标签 ≠ 扔掉这次运行。回工作台点 **继续工作**，或待处理里点那一条。

只想讨论、不许改文件：开聊时选只讨论。有的 Agent 做不到只读，Mesa 会直接拒绝，请换一家或明确允许写。

> **【配图】** 同一标签：左聊天右终端，标「这是同一次」。  
> **【配视频】** 从步骤「开始」落到运行页，发一句，再切到终端。

把图或文件拖进输入框即可。终端里的 http 链接可以点，用系统浏览器打开。

## 以前的对话去哪找

**侧栏「对话」** 是全应用的总账。  
**项目里的「对话」页签** 只列出这个课题的。

点一条才打开回放。你的话在右边，AI 在左边。一长串工具调用会收成「过程」，点开再看细节。方向键换上一条 / 下一条。

标题会尽量写成 `月日|类型|主题`，让你能分辨「对什么做了哪一件事」。你手改过的标题不会被覆盖。

行上 **恢复**：在 Mesa 里接着聊。  
**⇗ 外部恢复**：用系统终端接着聊（密钥不会进你复制的那行命令）。

换电脑：列表上的 **导入 / 导出会话包**。导出是对话原文，可能带路径，发出去之前自己看一眼。OpenCode 的对话进不了这种包。

雷达解读、定时巡检这类 Mesa 自己在后台喊的 AI，在「内部 AI」里，不会冒充成本课题的讨论。

## 「工作」项目和写代码

添加项目时第三种方式按钮上写的是 **工作**（处理工作文档和日常材料）。

**工作项目**  
页签是 **工作任务**。主卡标题是「目标」：写一句话，记下或开始。文件页和科研同一套（左目录右预览）。Word / 表格 / PDF 都能预览；旧的 `.doc` 请先在 Word 另存为 `.docx`。

**编程项目**  
主区是一棵棵 **工作树**：从基准分支（常见是 main）拉出一份独立目录给 AI 改，避免直接在主文件夹里搅。

点 **从 … 开工**，起一个分支名。成功后打开运行页。改完在树上查看改动，再 **合进基准** 或开 Pull Request。

用 GitHub Desktop 时，打开的应是**这一棵工作树**，不要打开主仓库文件夹去找 AI 的改动。

> **【配图】** 工作树一行：进入、改动、比基准多/少。  
> **【配视频】** 从 main 开工 → AI 改完 → 合进基准。

## 技能和外部工具（可后看）

**技能** 是一篇短说明书，告诉 AI「精读要写成哪几节」「图要怎么交」。有研究流程时，开步会自动带上这一步挂的技能，你不必每次手选。

技能页可以创建、从 GitHub / ZIP 导入，再打开右侧开关分发给各家 Agent。Cursor 和 Grok 是复制一份过去，不是快捷方式。

内置技能第一次启动会放进技能库：**只补没有的，不覆盖你改过的，你删掉的不会复活。** 新加的内置技能要**重启 Mesa Dev** 才会出现在列表里。

页顶若写「内置技能有新版」，点 **查看差异**，确认后 **备份并采用新版**（会覆盖库里那份，先备份）。点开某个技能若看到 **副本需同步**，那是 Cursor / Grok 的复制件旧了，点旁边 **同步副本** 把库里的最新版再拷过去——不是 GitHub 更新。

**MCP** 是接外部服务。学术检索常用：

- **Consensus**：在 MCP 页用预设添加，把 API 密钥填到密钥栏（不要把密钥写进命令本身）  
- **Undermind**：同样用预设，然后「去终端登录」做一次浏览器授权  

不配这两家，检索步仍然可以用 OpenAlex 等免密钥来源。配了只是多一个库，不是替代筛选标准。

Grok 的 MCP 在 Mesa 里只能看，不能从这里代为写入；要用 Grok 自己的 `grok mcp add`。

Blender、Origin 都是可选：到用得上的步骤再选。Origin 只在 Windows 且本机装着 Origin 时才有意义。

> **【配图】** 技能右侧开关；MCP 预设里的 Consensus。  
> **【配视频】** 添加 Consensus 后新开检索，能搜到论文。

## 用量、外观、更新

**用量**  
看今天 / 7 天 / 30 天花了多少。官方订阅不计费，只显示「订阅」和 token。Mesa 自己写摘要、起标题、解读雷达，也不计入课题费用。汇率在设置里改。

**用量 → 订阅余量**  
配了订阅套餐网关的话，费用卡下面多一块「订阅余量」。目前支持**智谱 Coding Plan**（地址含 bigmodel.cn 或 z.ai）、**Kimi For Coding**（api.kimi.com）、**MiniMax Coding Plan**（minimaxi.com / minimax.io）三家；有多家时卡片顶部出现切换标签，点一下换一家，单家时不占位置。

5 小时窗和本周窗**同一套排法**，谁用得多谁排上面：指标名、百分比、旁边的绝对用量、粗进度条，右边一句「还有 28 小时 51 分」。70% 起转黄、90% 转红，进度条和数字同色；到 100% 就是已经卡住了。倒计时悬停能看到具体重置时刻。智谱和 Kimi 的绝对用量（积分 / 配额点数）写在百分比旁边，如 `140,000 / 140,000`。站点偶尔会超发一点点，卡面按总量封顶，避免看起来比 100% 还多。MiniMax 只回百分比，那里就空着。

- **重置卡**（仅智谱）：卡底并排两列——`5 小时重置卡 ×1`、`周重置卡 ×1`，有效期写到日（`有效期至 10-18 · 剩 28 天`），几点几分悬停才看。上面两个窗口已经把用量摆出来了，卡上不重复百分比。已经卡住的那一窗，按钮用强调色；另一张是细边框的次级按钮，**不会因为 0% 被禁用**。点了先弹确认——重置卡是有限的，**消费后不可撤销**（Mesa 总是先用最早过期的那张）；确认后立即重置对应窗口并刷新余量。**3 天内到期会标黄**提醒你先用掉，不用就浪费了。

  Mesa 会劝你别白用，但**不会拦你**：确认框里会写明这个窗口**当前已用多少**，若它一点没用（0%）还会直说「重置不会腾出任何额度，这张卡会白费」，确认按钮也跟着变成 **仍要用**——你真要清这个窗口，照样点得下去。一张都没有时只写「重置卡无可用」。
- **去控制台**：卡头右侧，打开这家平台的网页版用量页。
- **自动刷新**：页面开着每 2 分钟自动查一次，不用手动点；卡头上的 ⟳ 是立刻强制重查这一张；页顶的 **刷新**（重建用量索引那个）会顺带把订阅余量和网关余额一起强制重查。查到新数字前会先显示上一次的结果，不会白屏。

查询失败时会保留上一次的成功数据并标注「数据截至 几点几分」；提示密钥失效就到连接页更新这个网关的密钥。智谱团队版不用单独设置：网关自定义 Header 里带过 `bigmodel-organization` / `bigmodel-project` 就自动按团队版查。Kimi 的 5 小时窗按最紧的那个模型窗口显示；MiniMax 无周限额的套餐只显示 5 小时窗。

**用量 → 网关余额**  
配的是预付钱包网关（现在认 **ZetaTechs** 这类 New API 站，地址含 `zetatechs.com`）的话，订阅余量旁边会多一块「网关余额」。要显示钱包页上那个账户余额，到**连接 → 网关库**打开这个网关，填 **系统访问令牌**（不是推理用的 `sk-`）：点卡片上的「去钱包」登录站点，在个人设置里生成访问令牌，粘回来保存。用户 ID 一般不用填，只有老站点才要。

填了令牌后主数字是**当前可用余额**（和网页一致）。旁边写已消耗百分比和已用 / 总额，底下那条粗进度条是消耗进度，不是余额还剩多少——剩得够用时条是中性色，已用到 80% 才转黄、90% 转红。密钥额度在下面单独一块，按名称对齐：限额的有细条和百分比，不限额的写「不限额度」，不画空槽。金额格式统一，不限的只写已用数。同一个站配了多个网关时（比如正式一个、测试一个），Mesa 会把它们**合成一张卡**——因为这几个网关通常共用同一个系统访问令牌，查到的本来就是同一个账户余额；钱包数字只出现一次，真正不同的是各家推理密钥的额度，按网关名列在下面，鼠标悬停能看到站点上的令牌名和密钥尾号。同一个站如果开了两个账户，会分成两张卡，标题是「站点 · 账户名」。只配了一个网关时标题仍是你自己起的网关名，切换标签只在多张卡时才出现。

金额藏起来用卡头的眼睛符号（大字和密钥行的金额一起变成 `¥•••`，百分比还在）。人民币站显示 ¥，美元站显示 $；币种符号比数字小一号。密钥额度用到 100% 会标「已用尽」。密钥快到期（14 天内，含已过期）会在卡里用黄色提醒一行，其余时候悬停密钥行才看到到期时间——到期是这把推理密钥的，不是钱包的。没填令牌时主数字就是这把推理密钥的额度，并有一行提醒你到连接页去填。

刷新节奏和订阅余量一样；同一个站的多个网关一次并发查完，不会一个接一个慢慢等。不是这类网关不会出现这张卡。

**设置 → 外观**  
七套深色、七套浅色，点一下全站换。还可以自定义左栏 / 画布 / 强调三色。终端配色会跟着亮暗走；已经在跑的 Agent 窗口有的不会热更新，重开标签即可。

**设置 → 终端**  
字号、字体、滚动行数在这里调。字体立即生效，没装上的可以一键装；要对齐 Ghostty 就选「JetBrains Mono（内置）」。终端渲染改完要重开标签：在意字形选「清晰」或「自动」，要出字更快选「流畅（WebGL）」。清晰档里，滚轮和触控板回看历史时，还留在屏幕上的行会直接挪位，只重画新滚进来的几行；程序把整屏重绘一遍时仍是整屏重画。底部状态栏是终端和聊天底下那条，关掉后两边一起消失。

**设置 → 集成 → AI 专用配置**  
提交信息、摘要、翻译这些生成用这一项。下拉里同一条配置的每个模型各占一行，选中哪个就调用哪个。下面每一项功能可以单独换；留空就跟着上面这条，包括你选的模型。选「自动」则用最近用过的那条配置，模型取它的第一个。

**设置 → 更新**  
有新版本时待处理也会亮。点下载安装，完成后自动重启。

**设置 → 诊断**  
出问题把「导出诊断包」发给开发者。包里没有密钥。也可以导出一份「生效配置快照」，看当前到底用了哪条连接。

**设置 → 网络**  
出网代理（官方账号与 Agent 安装/更新下载用）+ 学校图书馆（见「付费墙文献」）。

## 卡住了怎么办

**Mac 说应用已损坏**  
不是损坏。终端执行 `xattr -cr /Applications/Mesa.app`。

**点了按钮没反应**  
Mac 上 Mesa 不用系统自带的弹窗。如果某个输入还在等你填，看页面中间有没有内联输入框或确认层。仍然没反应，到设置 → 诊断 导出日志。

**AI 只会说话，不建文件、不检索**  
多半是中转上的模型没有「工具调用」。换官方 Claude，或供应商写明支持 tools 的模型。

**配置保存了，一运行就 404**  
Claude 类地址不要带 `/v1`；Codex / Kimi / Qwen 类通常要带。回到连接里再点一次「验证并获取」。

**官方账号提示 token revoked / 请重新登录**  
是 ChatGPT / Claude 订阅本身过期，不是 Mesa 把官方和 API 搞混了。到连接页重新登录。国内网络请配「出网代理」。

**改了模型，窗口里 `/model` 还是旧的**  
只对**新开的**标签生效。停掉当前这次，再运行一次。

**待获取点了浏览器，一直不是「已存」**  
看按钮是不是「等待收货…」。PDF 要落到系统的「下载」文件夹，尽量在一分半钟内下完。对不上会有右下角横幅。实在不行用「关联」。

**想一次下完几十篇付费墙**  
请不要。出版商会封学校 IP。一篇一篇点「浏览器」。

**切到文件看 PDF，再回来清单跳到最顶、全变成未获取**  
应已修好：回来停在刚才那一行，已存仍在。若仍跳动，先确认 Mesa 已更新到含这项的版本，并把现象发到诊断包里。

**工作区里的对话找不到**  
在所属课题的「对话」里，带步骤名。工作区删了，记录还在，可能显示成单独一项。

**Git / Node 缺失，改动面板报找不到 git**  
设置 → 诊断 一键安装。Mac 若还没同意 Xcode 许可，请先处理系统弹窗，不要反复点。

## 和别的文档怎么分工

| 文档 | 你什么时候才需要打开 |
|---|---|
| **本说明书** | 日常：这是什么、点哪里、怎样算做成 |
| `CHANGELOG.md` | 升级之后：这一版改了哪些行为 |
| `docs/architecture.md` | 你在改 Mesa 本身，要知道为什么这样设计 |
| `docs/conventions/` | 你在改某一块功能，要遵守已拍板的硬约束 |

说明书只写使用者做决定时要用的那一层。更细的渠道差异、冲突怎么逐文件选边、科研质量门怎么分级，写在 conventions 和 architecture 里。
