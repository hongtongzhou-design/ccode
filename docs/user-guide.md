## 1 全局约定

Mesa 是装在电脑上的 **AI 科研工作台**：把本机的终端 AI 管起来，围绕一个课题文件夹干活。

- 可以接九家：Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Kimi Code、CodeBuddy Code、Cursor CLI、Grok Build。装一家就够。
- 界面叫 **Mesa**，数据文件夹仍叫 `ccode`（课题里的 `.ccode/`、家目录下的 `~/ccode/`）。备份、换电脑按这个找。

三条贯穿全部页面的规矩：

| 规矩 | 含义 |
|---|---|
| **课题是家** | 对话、步骤、文件、定时任务都挂在课题文件夹上，不挂在某次聊天上 |
| **成稿走副本** | 要进课题的正式成果在隔离的工作副本里做，你评审后才合并；随口问一句用「＋新对话」，那直接改课题文件夹 |
| **密钥不出门** | 界面只显示尾号；默认只注入到这一次运行，不改电脑上 CLI 的全局配置 |

产品为什么这么设计，见 [docs/architecture.md](architecture.md) §10 决策记录。

### 1.1 界面总览与快捷键

左边一列九个入口，分三组：

**工作**：工作台 → 项目 → 运行 → 对话
**资源**：连接 → 技能 → MCP
**管理**：用量 → 设置

| 操作 | Mac | Windows / Linux |
|---|---|---|
| 切换九页 | `⌘1` – `⌘9` | `Ctrl+1` – `Ctrl+9` |
| 命令面板 | `⌘K` | `Ctrl+K` |

**外观**：Mac 和 Windows 上左侧栏与顶栏是磨砂的（壁纸透出），右侧工作区是不透明圆角面板；Linux 上为实心。系统开「减少透明度」时回到实心。透明度在 **设置 → 外观 → 侧栏 / 顶栏透明度** 调，100% 是主题本来的样子，0% 完全不铺罩色（深色壁纸下选中的那一行不好辨认）。可选档位 0 / 25 / 50 / 75 / 85 / 100%，默认 100%。

### 1.2 三种工作方式

添加项目时选一次，**界面里之后不能改**（表单上写「已选定，不可更改」）。要换就另建项目。

| 方式 | 适合 | 主画面 |
|---|---|---|
| **科研** | 文献、实验、论文 | 步骤（或目标）+ 文献 + 文件 |
| **编程** | 写代码、开分支、PR | 工作树 |
| **工作** | 工作文档、日常材料 | 目标 + 文件预览 |

设计文档里第三种叫「工作」，不是「办公」。

### 1.3 两条路：＋新对话 vs 开始 / 新建目标

这是最容易用反的地方。

| 你想 | 用这个 | 它改哪里 |
|---|---|---|
| 问一句、改个别字、解释一段 | 项目里 **＋新对话** | 直接改课题文件夹 |
| 出一版要收进课题的成果 | 步骤 **开始**，无流程时 **新建目标** | 隔离工作副本，你验收后合并 |

**＋新对话** 不会把「未完成的目标」「验收后才进项目」这些塞给 AI。它只知道：这是哪个课题、里面有什么、规则是什么、你这次说了什么。

### 1.4 待处理（收件箱）

窗口顶上（Mac 在标题栏）出现 **待处理** 和数字。只有**要你拍板、不拍就卡住**的事才进来：

| 类型 | 例子 |
|---|---|
| 等确认 | Agent 在等你确认一条命令 |
| 可合并 | 步骤做完了，改动可以合并 |
| 冲突 | 工作副本和主文件夹改了同一处 |
| 更新 | Mesa 自己有新版本 |
| 人工请求 | Agent 写了求助条（补检索词、某篇下不到） |

点进去是一句话 + **去处理**。全部处理完，图标自己消失。

**不会进这里的**：Agent 说完一轮等你下一句——那是每天都发生的事。

### 1.5 状态与图标对照

| 图标 / 文字 | 位置 | 意思 |
|---|---|---|
| 绿点 | 工作台项目卡、项目列表 | 这个课题此刻有 Agent 在跑 |
| 黄点 / **待确认** | 同上 | 有事等你处理 |
| 虚线转圈圆 | 运行页标签 | 悬停写「生成回答中」。它停了只代表这一轮说完，不代表 Agent 退出 |
| 黄点 ● | 运行页标签 | 悬停写「待确认」。没激活的标签要悬停或聚焦才看得见 |
| 实心强调色小圆 | 步进器名称旁 | 这一步你主要负责。悬停写「这一步主要靠你」 |
| 灰点 | 步进器名称旁 | 你和 AI 一起定。悬停也是这句话 |
| 无点 | 步进器 | 主要是 AI 做 |
| ✓ / 已存 | 待获取行 | 这篇 PDF 已收进 `papers/` |

## 2 工作台

进来第一眼。三块。

**正在进行 / 继续工作**

| 状态 | 显示 |
|---|---|
| 还没有课题 | 空态：**从一个项目开始** + **添加项目**（点了跳到项目页） |
| 有课题、有 AI 在跑 | 标题 **正在进行**，大卡上课题名 + 实心 **继续工作** |
| 有课题、此刻没人在跑 | 标题 **继续工作**，点进去回到上次停下的地方，不是新开一轮 |

终端标签关掉不等于扔掉：点 **继续工作** 按那一次运行找回。

**待你处理 / 待你验收**（有内容才出现）

- **待你处理**：收件箱前几条。宽屏在右侧，窄屏在下方。
- **待你验收**：目标跑完等你勾选的，单独一块排在下面。

**最近项目 / 最近对话**

页头右上角有次要按钮 **快速开聊**。

> **【配图】** 全新安装的工作台空态 + 有课题时的「正在进行」。

## 3 项目页

左边课题列表，右边当前课题。

### 3.1 项目列表

- 按 **科研 / 编程 / 工作** 分组，组头就这四个字。还没添加的仓库单独一组，组头写 **未添加**，沉在最下。
- 名字左边：有待处理是黄点，悬停写「待处理」；这个课题里有 Agent 在跑是绿点，悬停写「运行中」。没事不画点。
- 添加课题只在左边列表头的 **+**，不在顶栏。点开是 **添加项目…** 和 **✦ 创建示例课题（演示）**。一个课题都没有时，空态上的按钮写 **✦ 创建示例课题**，没有「（演示）」。

### 3.2 添加项目

| 步骤 | 界面 |
|---|---|
| 1 | 系统选目录窗口（没有文件夹先在访达 / 资源管理器建一个） |
| 2 | **添加项目** 表单：路径、**项目名**、**工作方式**（三选一） |
| 3 | **添加** / **添加中…** |
| 4 | 科研项目接着弹 **选择研究流程模板** |

**选择研究流程模板**

- 首句：「「项目名」已添加。写论文请挑一套流程；只读文献、写笔记，选下面的「不使用研究流程」。」
- 可先填 **课题主题（可选）**，占位示例「如 GLP-1 受体激动剂的心血管结局」。填了以后每次开工都会带给 AI。
- 每张模板卡写着名字、步数徽标和一条路径：

| 模板 | 步数徽标 | 卡片上的那一行 |
|---|---|---|
| **英文综述** | 5 步 | 文献检索与筛选 → 精读笔记 → 大纲 → 初稿 → 润色定稿 |
| **科研论文** | 8 步 | 计算实验向实证论文：文献检索与筛选 → 精读与研究空白 → 实验设计 → 执行 → 分析 → 论文大纲 → IMRaD 初稿 → 投稿准备（湿实验/问卷需自改实验步） |
| **数据处理** | 4 步 | 数据登记与质量检查 → 清洗整理 → 探索性分析 → 结论与建议报告 |
| **毕业论文** | 8 步 | 文献检索与筛选 → 精读笔记 → 开题报告与综述 → 研究方法 → 实验执行 → 结果分析与章节 → 全文初稿 → 格式与定稿 |
| **投稿与返修** | 2 步 | 首投：期刊格式适配 → 投稿材料；返修：按轮次回复审稿意见 → 修订稿 → 再投稿清单。徽标按首投那两步计。点进去先选 **首投** 或 **返修**；返修再填 **返修轮次**，每一轮是单独一步 |
| **LaTeX 论文** | 4 步 | 把已有成稿转成 LaTeX（也可从笔记从零写）：搭骨架 → 章节写作 → 编译排错 → 定稿导出 |

- **不使用研究流程**（只读文献）/ **稍后再选**（只关弹层，项目页还会提醒）。

**项目全局设定**

选中模板后进填写屏，标题是「「模板名」的项目全局设定」。英文综述问五项：综述角度、目标篇幅、读者与文风、去向、综述深度。都是自由填写。

- 空着的项会以「名称：（提示）」留在项目设置的规则里，也出现在每一步任务书的**待确认的全局设定**；AI 开工或跟你商量时会先逐项问你。
- 按钮：**‹ 换个模板**、**暂不填写，稍后补充**、**保存设定并应用模板**。
- 综述深度分 **标准档** 与 **严格检索档**；界面上注明「严格检索档不是系统综述」。

### 3.3 项目设置（顶栏 ⋯）

科研项目这个抽屉从上到下是：

| 分区标题 | 里面有什么 |
|---|---|
| **基本** | **项目名**（**重命名**）、**课题主题**（**编辑**）、折叠的 **规则**、有记录才出现的 **验收记录 N**、**项目路径**（**复制**） |
| **研究流程** | 「当前 N 个步骤」。按钮是 **选择模板** / **更换模板**、**另存为模板**；已经有步骤时还有 **不使用研究流程** |
| **文献与数据（N）** | 默认折叠。展开后文献来源只读，旁边写「在流程线里改」。进料是 **从 Zotero 导入**、**导入 RIS / BibTeX**、**重新扫描目录** |

没有研究步骤时，**规则** 展开后还有 **写回时跳过** 和 **技能**。有研究步骤的科研项目不显示这两块。工作方式不在这个抽屉里。

**稿件载体** 不在项目设置里。打开 **编辑研究流程**，折叠标题是 **稿件载体与外部工具（按需选择）**（没有稿件那一项时写成 **按需补齐交付**）。选项是文献库、数值图、结构 / 装置示意、稿件载体（Markdown / Quarto、LaTeX（原生源码）、已有 Word（人工插件验收））。

编程项目和工作项目的 **项目设置** 是另一套：第一节标题 **规则与验收**（规则；工作项目在没有研究步骤时同样有 **写回时跳过** 和 **技能**；下面是 **验收记录 N**），接着是 **项目长期知识**。

### 3.4 项目页签

页签钉在课题名下面，划到文件或任务底部也能直接切。每个课题记住你上次停在哪个页签。

三种工作方式都是这五个页签。任务那一页的名字随方式变：

| 工作方式 | 任务页签 | 这一页是什么 |
|---|---|---|
| 科研 | **科研任务** | 有流程是步骤线；点过 **不使用研究流程** 且没有步骤时，是目标列表 |
| 工作 | **工作任务** | 目标列表 |
| 编程 | **编程任务** | 工作树 |

另外四个都叫 **对话 / 定时任务 / 文件 / Agents**。

## 4 科研任务页

有研究流程时是步骤线，没有时是目标列表。

### 4.1 步进器

- 顶上一排大圆，每一步一个，名称用学术习惯叫法（文献检索与筛选、综述大纲…）。
- 名称旁的小圆点见 [1.5](#15-状态与图标对照)。悬停写的是「这一步主要靠你」或「你和 AI 一起定」，不是「你来」。
- 步骤卡头部另有文字徽标 **你来** / **一起**（主要是 AI 做的那一步不标）。悬停分别是「这一步主要靠你，AI 打下手」「这一步你和 AI 一起定」。
- 图例在步进器右上，整条流程里出现过对应角色才画：**角色提示**、**你主要负责**、**你和 AI 一起定**。

### 4.2 当前步骤卡

点某个圆，下面出现当前步骤卡。没有内容的行不出现。有的话，从上到下是：

1. **确定文献来源**（这一步要问文献从哪来才有）
2. **稿件载体**（这一步会换正式稿才有；不挡着点「开始」）
3. **先定几件事**；还有没答的写成 **先定几件事（还有 N 件）**（配置了开工前要定的事才有）
4. 开工前的人工事项，一行一件，标题就是事项名
5. **AI 干活：{这一步的名字}**
6. 进行中和收尾的人工事项，标题仍是事项名。没有单独一行叫「收尾」或「你要做的事」
7. **你核对后，保存进项目**。这一行的按钮才是 **去评审**
8. 一条分隔线，左边只写 **可选**。下面是保存进项目之后才做的事，例如 **同步到文献库**、**继续精读笔记**（按钮 **去笔记夹**），以及不挡开工的工具项

标了可选、但仍排在上面主干里的人工事项，行尾有 **可选**。分隔线下面那一段本身就叫可选，行上不再重复这个字。前提排在 **AI 干活** 之前。

### 4.3 主按钮状态

这些字出现在对应那一行的右侧，不是整张卡只有一颗按钮：

| 按钮上写的 | 在哪一行 | 什么时候 |
|---|---|---|
| **开始** | **AI 干活** | 这一步还没开过工 |
| **开读这一篇**，旁边仍有 **开始** | 同上 | 只在示例课题的精读步，而且已经有 PDF。这时 **开读这一篇** 是主按钮，**开始** 缩成次要 |
| **去终端看看** | 同上 | AI 正在做。会话判定已经跑完时，按钮左边有一行字 **Agent 已跑完**（不是按钮） |
| **恢复工作区** | 同上 | 这一步的工作副本已收起，占掉「开始」的位置 |
| **去评审** | **你核对后，保存进项目** | 有产出可以看。AI 正在写回答或等你确认时先藏起来 |
| **去处理冲突** | 同上 | 工作副本和主文件夹改了同一处，占掉「去评审」的位置 |
| **提交产物** / **提交中…** | 要你交文件的人工事项 | 这一行有落点、还没完成。悬停是「选文件提交到落点 …；也可直接把文件拖到这一行」 |
| **去笔记夹** | **继续精读笔记** | 保存进项目之后才能点 |

**开始** 的悬停提示是「直接开工也行，AI 会在对话里问你缺的信息」：上面的待定项都不拦着开工。

### 4.4 先定几件事

有的步骤在开工前就能定几件事（篇幅、读者、实验规模等），节点写成 **先定几件事** / **先定几件事（还有 N 件）**。

| 方式 | 怎么用 |
|---|---|
| **方式一 · 直接选择** | 展开 **直接选择（N 项待定）**；都答完了，这一行改成 **直接选择（已定）**。点选项，或点 **全部用推荐值**。选项不合适时是 **其他…**（没有预设选项时是 **写一句…**），写完点 **记下**，拿不准点 **开聊** |
| **方式二 · 和 AI 商量** | 展开 **和 AI 商量（可选）**，点 **跟 AI 商量一下**。AI 通读任务书、逐个问你，按回答改任务书 |

商量过之后按钮变成 **继续讨论**，接回上次那条对话，不新开一轮。没有决策项的步骤不标「方式二」，**跟 AI 商量一下** 直接挂在 AI 那一栏。

**哪些问题会在这里问、哪些不会**

| 问题类型 | 出现位置 |
|---|---|
| 决定后面每一步（篇幅、读者、去向、目标期刊） | 项目层的全局设定，每步任务书自动带上 |
| 开工前就能答、答了影响执行 | 步骤的决策项，就是这里 |
| **要先看到数据才定得了**（纳入标准、精读力度、分析粒度） | 不在这里。AI 跑起来后拿数字，写进收件箱「人工请求」问你 |
| 只有人能做（下载付费全文、放入成稿） | 人工事项 |
| 三选一的稿件载体、用哪套软件交差 | 用得上的那一步才问 |

只有卡片上标明必须批准的问题，不答才不能点 **开始**。

### 4.5 想法卡

| 按钮 | 作用 |
|---|---|
| **聊想法** | 回到这张卡上一次的对话；没有对话才新开 |
| **◈ 沉淀进任务书** | 只在这一步还没开工时出现。AI 先写出要追加的结论，你改完再写入任务书 |

### 4.6 人工事项

只有人能做、且做完会在项目里留下痕迹的事。步骤卡上每一行有勾选框，标题就是事项名。做法写在行下；长了才收进 **怎么做**。标 **可选** 的，不做也能往下走。

**怎么做 / 落点** 出现在开工确认层里的人工事项清单：展开后有做法，有落点的再写「落点：…（放到这里系统会自动勾上）」。

综述检索步这三件：**配置学术检索 MCP**、**核对待确认篇目**、**下载付费墙文献全文**。定稿步这三件：**更换引用样式**、**逐条决定审查报告**、**逐条裁决 [待核实] 与存疑条目**。逐项说明见教程对应章节。

### 4.7 开工确认层

点 **开始** 不会立刻跑，先弹确认层，标题是 **开始 {步骤名}**。左下是 **取消**。

| 区域 | 界面上的字 |
|---|---|
| 本步产物 | 这一步要交的文件名 |
| 已有材料 | 上一步传来的文件。缺的必填写成「文件名 · 还没有」 |
| 这次用谁 | 一行身份，旁边 **更换**。还没有能用的连接时写「还没有可用连接。」，链接是 **去添加** |
| 任务书 | 默认收起，可展开改这一次。改过之后可以 **恢复默认拼装** |
| 权限 | 有连接时写死一行：「运行权限：写步骤工作区 + 主仓 papers/（原始文献）；派生产物经评审合并进主仓」 |

右下主按钮的字，按这个顺序取第一个成立的：

| 按钮 | 意思 |
|---|---|
| **开始中…** | 已经在建工作副本，或正在把改过的文件存进历史 |
| **先加连接** | 这个课题还没有能用的 AI |
| **仅开始准备** | 当前决定只允许做准备 |
| **先做无依赖工作** | 有决定还没批准，再确认一次也只能做不依赖那些答案的部分 |
| **仍要开工** | 上一步还有收尾事项没勾。第一次点的仍是「确认开始」，点过之后变成它，再点才真开 |
| **记下并开始** | 你改过本步要读的文件还没存进历史。点了先存进历史再开工 |
| **确认开始** | 上面都没有时的正常开工 |

**上一步收尾提醒**原话：「上一步「…」还有 N 件收尾事项没完成（…）——跳过审阅直接开工，上一步要返工时这一步也得跟着作废。」还没点过时接着写「建议先回去过完再来；确认跳过就点「确认开始」，按钮会再问你一次。」点过之后改成「再点一次「仍要开工」即继续。」

**有待拍板**时层里写「待拍板：…」。硬暂停时按钮点不了，后面写「硬暂停：…。待补或不批准不能开工。」只允许准备时写「当前决定只允许准备，不能当作正式开工授权。」软暂停时写「软暂停：建议先回答；再次确认只允许先做不依赖这些答案的工作。」

### 4.8 决策暂停策略

每一步的任务书里有一段 **决策暂停策略**。编辑研究流程时，这一项的三个选项是：

| 选项 | 意思 |
|---|---|
| **一般问题可按可逆兜底继续** | 默认 |
| **软暂停：未答需二次确认，只推进无依赖工作** | 没答完只能做不依赖答案的部分 |
| **硬暂停：结构化决策全部回答后开工** | 题没答完不能当正式开工 |

写进任务书的正文是这三句之一：

- 「hard_pause：遇到新的待拍板问题，写入 .ccode/help-wanted.md 并暂停本步骤，等待人明确答复后继续；不得自行采用推荐值或「未回复即继续」。」
- 「soft_pause：遇到待拍板问题，写入 .ccode/help-wanted.md 并暂停受影响的操作；只可推进无依赖、可逆的部分，等待人明确答复后恢复受影响的操作。」
- 「auto_continue：一般问题写入 .ccode/help-wanted.md 并附可逆兜底方案，可按兜底继续；涉及目标/对象范围、关键处理规则、结论范围、隐私、伦理、合规、主指标或不可逆操作时必须等待人明确授权，不得默认同意。」

下面接着「本步中途没有必须等人拍板的事项。」或「本步必须停下来等你：」，条目来自这一步的拍板题和人工事项。有交付后才轮到你的事，再写「达到完成标准后交给你（不要自行宣称已通过）：」。最后一句固定是：「一批工作、一次 git 提交或进度汇报不是停工理由；未达完成标准且不必拍板时，用户没说停就继续。」

写完一批、git 提交、报个进度不在停工清单里。

| 情况 | 怎么办 |
|---|---|
| 它在该停的地方停 | 按收件箱或卡上的提示拍板 |
| 它不该停却停了 | **不要点「开始」**。用当前步的圆或工作台 **继续工作** 回到原来那个终端，说「不必拍板就做到完成标准」 |
| 上下文写满后它又停一轮 | 再回一句即可 |
| 它需要你补信息 | 收件箱「人工请求」；点 **去终端回答** 回到那次对话答复。不回，它按每条后面的兜底继续 |

### 4.9 评审页

点 **去评审** 打开。页签按步骤类型不同，**最多三个**：

| 步骤类型 | 页签 |
|---|---|
| 检索 | **清单 / 过程 / 文件** |
| 精读 | **笔记 / 过程 / 文件** |
| 大纲、初稿、定稿 | **稿件 / 过程 / 文件** |
| 实验、分析、清洗（产物含复现入口或质量报告） | **结果 / 过程 / 文件** |

**文件** 页签看增删；**过程** 看 AI 的做事记录。

**稿件** 页签：

- Word 在 PDF 前面；PDF 标签会提示先看是否乱码。
- 顶上黄字扫描提醒：摘要含 [待核实]、正文含空白编号（G1…）、N 处「待绘制」。
- 意见框：直接写，或在稿件里划一段点 **加进意见**（追加到同一个意见框）。
- **退回修改**（接回原来那条对话，按意见改现稿）/ **按意见重写**（同一工作区新开会话，按大纲和笔记重写）。两者都**不保存进项目**。

**保存进项目**

| 按钮 | 什么时候 |
|---|---|
| **提交并保存进项目** | 有未提交的改动 |
| **保存进项目** | 没有待提交的改动 |

提交信息可以留空，Mesa 会写一句很短的默认说明。

**冲突**：两边改了同一处时按钮变成 **去处理冲突**，按文件选「用任务这一版」或「用主文件夹这一版」，全部选完再合并。要逐行掺，去预览编辑器手改。主文件夹自己还有未保存进历史的改动时，合并会被拦住，评审里可以就地先存进历史。

**保存进项目只表示文件进了课题，不等于你接受其中的科学结论。**

### 4.10 裁决与审查报告

润色、定稿、期刊格式适配、返修会先写一份**审查报告**，不改正文。

| 控件 | 说明 |
|---|---|
| **接受** / **拒绝** / **修改** | 逐条点。选 **修改** 必须写一句要改成什么样（「修改时写一句」） |
| **全部接受** | 一次接受全部 |
| **让 Agent 按决定继续** | 全部点完后出现，回到这一步原来的对话改稿 |

拒绝的不改。改了数字、因果、样本或结论范围，会单独列在修改记录的「科学改动」里。

**逐条裁决** 是另一件事：只处理定稿里还标着 [待核实] 的句子，以及引用检查里疑似编造、元数据存疑的条目；没有条目时写「勾上跳过」。每条填完「裁决：」才算完成。

### 4.11 完结文件

每一步都保存进项目之后，项目卡上才出现 **完结文件**。后来追加了步骤、那些步骤还没做完时，这块先不出现。

分组：最终稿 / 可以接着改的稿 / 图 / 文献从哪来 / 核对与修改 / 精读笔记。每份文件左边是文件页同一套类型标，右边是名字；附图和精读笔记先显示篇数。笔记点开后每行是论文题名，右边是对应 PDF，没有全文写「无全文」。上面的框用来收窄。

### 4.12 不使用研究流程：目标

科研任务页的标题是 **目标**。空的时候写「这次想完成什么？」，说明是「写清要交付的成果，再选择资料和 Agent。」

**新建目标** 弹层里，输入框上方写 **要完成什么**。可以先点 **记下**（进行中写成 **记下…**），也可以直接点 **开始**（进行中写成 **正在准备…**）。默认权限是 **写入并验收产物**，旁边还有 **只讨论**。展开 **资料和 Agent** 才能改资料、技能、权限和用哪家 AI。

目标跑起来之后，卡片上是 **继续**。跑完等你看时，按钮写 **验收产物**，分组标题是 **待验收产物**。打开后勾选要留下的，右下是 **带着意见再出一版**（意见框旁注「不满意再出一版」）和 **接受 N 项**；一项都不勾是 **不带回产物，完成**。失败或停掉之后，原来的「开始」变成 **重试**。已经完成的可以 **再来一版**。

文献雷达在 **定时任务** 页，PDF 在 **文件** 页。工作方式选「工作」时，同一套列表的按钮换成 **验收文档**、**待验收文档**、**采纳 N 份**、**不带回文档，完成**。

## 5 定时任务页

上半是 **文献雷达**，下半是定时列表。

### 5.1 文献雷达：订阅

雷达卡头的图标按钮 **订阅** 打开订阅表，一行一条，**＋ 加一行** 加、行尾 **×** 删：

| 字段 | 说明 |
|---|---|
| 关键词 | 占位「关键词，如 mixture-of-experts」 |
| 来源 | **arxiv** / **openalex** / **crossref** 三个小标，可多选 |
| 备注（可选） | 自由填写 |

保存即生效。没有任何订阅时卡头写「文献雷达 · 还没订阅读」。

**编辑源文件**：先保存磁盘上已有的订阅（表里没保存的改动不带过去），再在弹层里直接编辑 `papers/watchlist.md`，不跳页。

### 5.2 定时巡检

**＋ 定时巡检** 打开「定时巡检」弹层，三选一：**文献雷达**、已有的巡检技能、新建巡检技能。雷达的说明是「按周期跑文献雷达，新命中追加到 notes/inbox.md。」频率选 **每天** / **每周**，列表里显示成「每天 09:00」「每周一 09:00」。

| 项 | 说明 |
|---|---|
| 运行配置（可选） | 界面原话：「文献雷达选 Codex。没有后缀的只在课题目录里写。写着「会批准全部操作」的不要用于定时巡检。」 |
| 跑在哪 | 隔离目录，不直接改课题文件夹。雷达卡上会写「隔离树有 N 条新命中，尚未采纳进主仓」 |
| 跑完 | 「待处理」出现「有 N 条新命中待评审」+ **去评审**；在评审里点 **采纳进主仓**（先确认，保存前查冲突和保护路径、备份原文件，冲突不自动覆盖），按钮变 **已采纳** |
| 应用没开 | 不跑。下次打开后第一轮自动补跑（漏多次也只补一次） |
| 超时 | 单次上限 30 分钟；历史里标 **⏱ 超时**，和失败分开 |

### 5.3 雷达上怎么读

雷达只处理**新命中**，精读清单在文件页。

- 默认一条：标题截断一行 + 中文一句话 / 期刊 / 日期；英文摘要点开才见。
- 一条两行。第一行只有标题。第二行是中文一句话或期刊，右边是 **推荐** / IF / 分区，再是日期和 **加入精读**。悬停才出现 **解读**、**打开来源**、**⋯ 更多**。
- 能免费直接下的 PDF（arXiv 直链、链接以 `.pdf` 结尾）在巡检结束时由 Agent 下到 `papers/`。出版商页和付费墙不下，界面上没有 **获取全文**。
- **打开来源** 在系统浏览器打开。你在站方点下载，90 秒内落下的 PDF 自动收进 `papers/`。
- **近 8 周新命中**按巡检日画柱。收件箱没写巡检日期时不画柱，写明缺了几条。旁边有 **按巡检日补记** 时，点一下就按那次巡检的完成日补上，不用论文上的发表日期。
- **待人工下载**是还没拿到全文的题录。展开后每行是 **官网**、**关联**。点 **官网** 后变成 **等待收货…**，旁边可以 **取消**。PDF 进了 `papers/` 就变成 **✓ 已存**，点标题到文件页打开。底下有 **打开 papers/**。
- 卡头 **筛选新命中** 可按期刊指标过滤列表和定时巡检的推送计数；查不到指标的条目照常显示，精读清单不受影响。

### 5.4 期刊指标表

IF、中科院分区、**TOP** 小标需要先把期刊指标表下到本机：两份 CSV（约 4MB + 2.7MB，来自 ShowJCR）。表有版权，安装包里不带，也不会自动下。下载可能要 1–4 分钟，完成后提示「期刊指标表已就绪（N 种期刊）」。

| 位置 | 入口 |
|---|---|
| 文献雷达 | 卡头 **下载期刊指标表**（下载中写「正在下载期刊指标表」） |
| 检索步清单 | 顶上一行状态 |

检索步清单顶上的状态文字：

| 状态文字 | 含义 |
|---|---|
| 正在看指标表… | 正在对上游 |
| **指标表已是最新** | 已装，对过上游 |
| **指标表有新版** + **更新** | 上游有新版本 |
| 「没能连上上游，看不出有没有新版。」+ **重新下载** | 连不上 |
| 指标表更新中… / 已更新… / 更新失败… | 点了之后 |
| 正在按 DOI 补期刊名，影响因子稍后出现。 | 条目缺期刊名，正在补 |

没装表时没有这些标签，也不会编数字；筛选里会提示「期刊指标表还没装：筛选保存后暂不生效…」。下过一次之后，这台电脑上的其他课题直接用。

## 6 文件页与沉浸阅读

### 6.1 文件页

左边文件列表（有搜索框和 **刷新**），右边预览。顶上按类型筛：**全部 / 文档 / 表格 / 幻灯 / PDF / 图片 / 其他**，各带数量。

| 操作 | 说明 |
|---|---|
| 点文件名 | 预览；预览头的 ↑ / ↓ 换上一个 / 下一个文件，× 关闭预览 |
| 悬停 | 文件：**问 AI**；文件夹：**打开终端**。都有 **显示**（在访达 / 资源管理器里定位） |
| **沉浸阅读** 图标 | PDF 和 `.md` 笔记行有。笔记行会自动配对本篇 PDF，配不上就进不去 |
| 文件名右边 | 最近修改时间：「刚刚 / N 分钟前 / N 小时前 / N 天前」，超过 30 天写日期；悬停看具体时刻 |

**Markdown 预览**：预览头可切 **阅读** / **编辑**，有未保存修改时显示 ●。阅读态的 **⛶ 沉浸阅读** 进三栏阅读区（见 6.2）；其它文件是 **⛶ 沉浸阅读 / 沉浸编辑** 全宽单栏，Esc 退出。

【待核对：HTML、表格、图片、二进制文件的预览细节（沙箱渲染 / 源码切换、缩放、「用系统应用打开」）】

### 6.2 沉浸阅读（三栏）

入口：文件页 PDF / 笔记行的 **沉浸阅读** 图标，或 Markdown 阅读态的 **⛶ 沉浸阅读**（提示「笔记｜PDF｜Agent 三栏，自动配对本篇 PDF」）。示例课题的精读步可直接点 **开读这一篇**。

| 栏 | 内容 |
|---|---|
| 左 | **笔记**，可切阅读 / 编辑（⌘E / Ctrl+E） |
| 中 | **PDF**，可滚动、缩放、选字 |
| 右 | **Agent 对话**，每次进入都新开一个会话 |

两栏之间的分隔条可以拖动，宽度会记住。顶栏有 **← 返回**、文献标题、收起 / 展开左侧笔记栏和右侧对话栏，以及 **护眼反色**（按文件记忆）。

**选段浮动条**：**译**、**◈ 问 AI**、**＋ 生词**（选段不超过 60 字时才有）、**⋯ → ↵ 直接发送**。

**圈选**（PDF 工具栏）：框一块区域后可 **◈ 发给 agent** 或 **＋ 插入笔记**。

**Esc**：圈选模式里先退出圈选；再按一次退出阅读。焦点在右侧终端里时 Esc 归终端，要退出就点 **← 返回** 或先点别处再按 Esc。

退出时这次自动开的阅读标签一起关闭（AI 正在生成的回答会被打断），你自己开着的其它终端不受影响。

## 8 运行页

一个标签就是一次运行。顶上一排标签。

### 8.1 聊天 / 终端

右侧两个小图标切换，**两者是同一次会话的两种看法**，切来切去字不会丢。

| 视图 | 用途 |
|---|---|
| **聊天** | 像常见对话。Enter 发送，Shift+Enter 换行。技能和 MCP 菜单只插入提示，**不替你按发送** |
| **终端** | 各家 AI 自己的界面，登录、权限确认、`/model` 都在这里 |

### 8.2 启动栏

还没运行时，画面中间是「将在某某文件夹启动」+ 实心的 **运行**。上方启动栏三截：当前 Agent、配置、模型，点开向下列清单，选过会记住。

跑起来后这三截不再占终端高度，身份在底下那一行；点 **修改** 查看本次身份——这次进程不会改，要换先停止。

### 8.3 右侧面板

**文件** 和 **改动**。改动里可以勾选后提交。

### 8.4 输入与粘贴

| 操作 | 行为 |
|---|---|
| 拖文件 / 图进终端 | 直接插入 |
| ⌘V / 右键 **粘贴** | 剪贴板是图 → 落成一条路径写进输入行，不自动发送；是文字 → 原样贴入 |
| 选中一段 | 出现 **复制**、**复制文本**、**查看** |
| **复制** | 终端里的原样，Markdown 标记还在（⌘C 同） |
| **复制文本** | 去掉标题、加粗、链接地址等标记，只留字 |
| **查看** | 不渲染，字原样铺开，方便读长段 |

## 9 连接页

每家 Agent 一张卡片。没装过的卡片颜色更淡，上面有 **安装**。

### 9.1 安装与更新

点 **安装**，确认框会告诉你将执行的命令。

| 平台 | 渠道 |
|---|---|
| Mac | 优先 Homebrew（自动走国内镜像） |
| Windows | Claude / Codex / OpenCode / Kimi / Grok 可用 winget，其余多数走 npm |
| Linux | 页面会给命令 |

过程是一个小终端，遇到 `[y/n]` 就在下面回答。一般几十秒到几分钟；持续约 10 分钟没有任何动静才算卡住，会自动报错。卡上出现 **新版** 即可升级；Kimi 那种要方向键选择的更新会改到运行页终端里让你用键盘选。

### 9.2 加一条连接（中转 / API 密钥）

把「网关」理解成**一把密钥 + 一组网址**，「绑定」理解成**某家 Agent 用这把密钥里的哪些模型**。日常只做「添加连接」。

1. **＋ 添加连接**
2. **端点预设** 选供应商（DeepSeek、智谱、月之暗面、百炼、OpenRouter 等），地址、名称、推荐模型自动填
3. 贴 API Key（保存后只显示尾号）
4. **验证并获取**：真发一次请求。成功会列出模型并自动勾上推荐项（目录里没有的不瞎勾）；失败按红字改地址或密钥，不要先保存
5. 同一把密钥还要给别家 Agent 用：勾 **同时绑到**
6. 保存

**常见坑**

| 现象 / 场景 | 做法 |
|---|---|
| 一运行就 404 | Claude / CodeBuddy 的地址**不要**以 `/v1` 结尾；Codex / Kimi / Qwen 一般**要**带 `/v1` |
| 智谱还要给 Codex 用 | 普通槽 `paas/v4`，Responses 槽 `api/v1`；勾「同时绑到 Codex」预设会自动补 |
| Cursor | 没有通用预设，第三方中转通常接不上，用 Cursor 自己的密钥和模型 |
| AI 只说话不建文件 | 模型没有工具调用能力，换官方 Claude 或供应商写明支持 tools 的模型 |

### 9.3 官方订阅

支持：Claude Code、Codex、Gemini、CodeBuddy、Cursor、Grok。

「账号类型」选 **官方账号**，不用填密钥；对应卡片组头点 **登录**，按终端提示完成（Codex 会给设备码）。组头变成绿点「官方已连接」即成功。

国内直连官方常失败：**设置 → 网络 → 出网代理** 填本机代理（如 `http://127.0.0.1:7890`），或点 **检测** 列出正在跑的代理。这份代理给官方登录、官方启动、Agent 安装 / 更新下载用（国内镜像源的下载自动直连、不绕代理）；走中转网关的连接不会被它拐到境外。

提示 token revoked / 请重新登录，是订阅本身过期，到连接页重新登录即可。

### 9.4 连接行上的动作

| 动作 | 位置 | 说明 |
|---|---|---|
| **编辑** | 行上常驻 | 换密钥、加减模型。改完的模型组合若与这家 Agent 上另一条连接**一模一样**，保存会被拦下并提示「已经有相同模型选择的绑定」 |
| **停用此连接** | 行尾 ⋯ | 不让它被自动选中（启动栏预选、恢复会话、AI 功能回落都跳过）；列表里还在，启动栏「已停用」分组仍能手选。再点一次「取消停用」恢复 |
| **解绑** | 行尾 ⋯ | 删掉这条连接在某家 Agent 上的用法。**网关和密钥都留着**，同一把密钥给别家 Agent 的绑定不受影响 |
| **⌨ 在终端使用** | 行上悬停 | 用这条连接直接新开一个运行标签 |
| **设为全局默认** | 行尾 ⋯ | 见 [9.6](#96-两种生效别混) |

**解绑前注意**：如果有课题的定时任务正用着这个配置，弹窗会告诉你有几条、分别叫什么。**解绑后这些任务不会自动改用别的 AI**，会在下一次该跑的时候停下并留一条失败记录，写明配置不存在。这是故意的。要让它继续跑：先到那个课题的「定时任务」里改连接，再回来解绑。

### 9.5 能力声明

中转的新模型有时公共能力库也查不到。症状：Claude 把它当 200K 小窗口、长对话提前压缩；Codex 模型目录里窗口写小；能看图的模型贴图被拒。

**连接 → 网关库 → 编辑 → 展开「模型策略」里那行模型 → 最下面 能力声明**：

1. 填 **上下文窗口**（如 `1048576`）、**思考 / 视觉** 选「支持」或「不支持」
2. 不确定的留「未声明」——留空字段继续走公共库和内置表推断
3. **保存声明**

面板顶部「当前解析」变成你填的值、行右侧徽章跟着变（如出现 `1024K`）即成功。字段全清空后按钮变成 **清除声明**。

| 易错点 | 说明 |
|---|---|
| 思考 / 视觉选「不支持」 | 是**硬声明**，推断链到此为止，公共库说支持也不再听。拿不准就留「未声明」 |
| 和 **max output** 的分工 | max output 是「这次让它最多写多少」，能力声明是「这个模型本身什么规格」 |

### 9.6 两种「生效」别混

| 你想要的 | 怎么做 |
|---|---|
| 只在 Mesa 里用，不改电脑上其它终端 | 什么都不用点，启动时自动带上（默认） |
| 系统终端、ChatGPT 桌面客户端也走这套 | 连接行 **⋯ → 设为全局默认** |

设为全局会改 CLI 自己的配置文件，Mesa 会先备份；可 **撤销上次写入**，也可 **恢复初始状态**（回到 Mesa 第一次改之前）。本机若装着 cc-switch 一类工具，点之前会提醒你不要两边同时改。Codex 的「设为全局」**不会**改 `auth.json`。

### 9.7 思考档位

网关库里每个模型的思考档可勾多档，勾上的档是会话里能切的范围，开场只用其中一档。斜杠串和拼写错误存不进去。

| 客户端 | 会话里怎么切 | 中转不报档位时 |
|---|---|---|
| Claude Code、Qwen | 底栏思考滑块，或 `/effort` | 菜单是客户端自带的，不看中转目录 |
| Codex | 在 Codex 自己的模型选择器里改；Mesa 底栏没有滑块 | 启动时写入的模型目录自带 low 到 max |
| Kimi | 底栏只有开 / 关 | 不看中转目录 |
| OpenCode | 在 OpenCode 里改；思考模型会标成可推理 | 不看中转目录 |
| CodeBuddy | 只有开场那一档，会话里没有切换 | 不看中转目录 |
| Gemini、Cursor | 没有思考档入口 | — |
| Grok | `/effort` 或底栏滑块 | 中转不报档位时菜单出不来。设为全局会把勾选档写成菜单，已有菜单不覆盖，写完新开一次会话才看得到 |

## 10 技能页

**技能** 是一篇短说明书，告诉 AI「精读要写成哪几节」「图要怎么交」。有研究流程时开步自动带上，不必手选。

| 操作 | 说明 |
|---|---|

综述流程用到的内置技能见教程 [12 章](tutorial.md#12-技能与-mcp)。

## 11 MCP 页

外部工具接口。配了之后新开的对话才能用。

### 11.1 学术检索

| 服务 | 配置 |
|---|---|
| **Consensus** | 用预设添加，把 API 密钥填到密钥栏（不要写进命令本身） |
| **Undermind** | 同样用预设，然后 **去终端登录** 做一次浏览器授权 |

检索步的人工事项 **配置学术检索 MCP** 自动判定条件：Consensus 已添加且密钥非空，Undermind 已添加并登录。缺哪一步旁边会写一句，例如「Consensus 还没填密钥」「Undermind 未登录」。说明里注明 Consensus「本机已配置时可跳过」——这台机器的 MCP 页已存密钥就不用重做，Undermind 仍要先登录。

不配这两家，检索步仍可用 OpenAlex / Semantic Scholar / arXiv / Crossref 等免密钥来源。配了只是多一个库，不替代筛选标准。

### 11.2 其他

- **Grok 的 MCP** 在 Mesa 里只能看，不能代为写入；要用 Grok 自己的 `grok mcp add`。
- **Blender**、**Origin** 是可选，用得上时再配。Origin 只在 Windows 且本机装着 Origin 时才有意义。

## 12 用量页

看今天 / 7 天 / 30 天花了多少。官方订阅不计费，只显示「订阅」和 token。Mesa 自己写摘要、起标题、解读雷达也不计入课题费用。汇率在设置里改。

### 12.1 订阅余量

配了订阅套餐网关时，费用卡下面多一块「订阅余量」。支持三家：

| 平台 | 地址特征 |
|---|---|
| **智谱 Coding Plan** | 含 bigmodel.cn 或 z.ai |
| **Kimi For Coding** | api.kimi.com |
| **MiniMax Coding Plan** | minimaxi.com / minimax.io |

有多家时卡片顶部出现切换标签，单家不占位置。

- 谁用得多谁排上面，走大数字：百分比、绝对用量、通栏粗进度条、「还有 5 天 20 小时」。另一窗收成一行。
- 70% 起转黄、90% 转红，进度条和数字同色；100% 就是已经卡住。倒计时悬停看具体重置时刻。
- 智谱和 Kimi 的绝对用量写在百分比旁（如 `140,000 / 140,000`）。站点偶尔超发，卡面按总量封顶。MiniMax 只回百分比。
- **重置卡**（仅智谱）：卡底两列 `5 小时重置卡 ×1`、`周重置卡 ×1`，有效期写到日，几点几分悬停才看。已卡住的那一窗按钮用强调色；另一张是次级按钮，不会因为 0% 被禁用。点了先弹确认——**消费后不可撤销**（先用最早过期的那张）。3 天内到期会标黄。
  - Mesa 会劝你别白用但**不拦你**：确认框写明这个窗口当前已用多少；若一点没用（0%）会直说「重置不会腾出任何额度，这张卡会白费」，确认按钮变成 **仍要用**。一张都没有时写「重置卡无可用」。
- **去控制台**：卡头右侧，打开该平台网页版用量页。
- **自动刷新**：页面开着每 2 分钟查一次；卡头 ⟳ 立刻强查这一张；页顶 **刷新** 会顺带把订阅余量和网关余额一起强查。查到新数字前先显示上一次结果，不白屏。
- 查询失败时保留上一次成功数据并标「数据截至 几点几分」；提示密钥失效就到连接页更新这个网关的密钥。
- 智谱团队版不用单独设置：网关自定义 Header 带过 `bigmodel-organization` / `bigmodel-project` 就按团队版查。Kimi 的 5 小时窗按最紧的那个模型窗口显示；MiniMax 无周限额的套餐只显示 5 小时窗。

### 12.2 网关余额

配了预付钱包网关（目前认 **ZetaTechs** 这类 New API 站，地址含 `zetatechs.com`）时，订阅余量旁多一块「网关余额」。

**先填系统访问令牌**（不是推理用的 `sk-`）：**连接 → 网关库** 打开这个网关，点 **去钱包** 登录站点，在个人设置里生成访问令牌，粘回来保存。用户 ID 一般不用填，只有老站点才要。

| 元素 | 含义 |
|---|---|
| 主数字 | 当前可用余额（与网页一致） |
| 通栏粗进度条 | 画的是**还剩多少**（满条 = 钱还多），条下写「已消耗 90%」 |
| 颜色 | 按已消耗分档：80% 起转黄、90% 转红 |
| 密钥额度 | 下面单独一块。不限额的不画百分比，开口条按各密钥已花多少比长短，末端淡出，旁边写「不限」和已用金额 |
| 同一站的多个网关 | 合成一张卡（共用系统访问令牌，余额本是同一个）；钱包数字只出现一次，各密钥额度按网关名列在下面 |
| 同一站的两个账户 | 分成两张卡，标题是「站点 · 账户名」 |

金额藏起来用卡头的眼睛符号（大字和密钥行金额变成 `¥•••`，百分比还在）。人民币站显示 ¥，美元站显示 $。密钥额度用到 100% 标「已用尽」；密钥快到期（14 天内，含已过期）在卡里用黄色提醒一行，其余时候悬停密钥行才看到——到期是这把推理密钥的，不是钱包的。没填令牌时主数字是这把推理密钥的额度，并有一行提醒你去连接页填。

不是这类网关不会出现这张卡。

## 13 设置页

### 13.1 外观

七套深色、七套浅色，点一下全站换。可自定义左栏 / 画布 / 强调三色。终端配色跟着亮暗走；已在跑的 Agent 窗口有的不会热更新，重开标签即可。侧栏 / 顶栏透明度见 [1.1](#11-界面总览与快捷键)。

### 13.2 终端（在「外观」分区里）

设置左侧没有单独的「终端」一项，下面这些在 **外观** 里往下翻。

| 项 | 说明 |
|---|---|
| 字号、字体、滚动行数 | 字体立即生效，没装上的可一键装；要对齐 Ghostty 选「JetBrains Mono（内置，与 Ghostty 默认同款）」 |
| 渲染方式 | 改完要重开标签：在意字形选「清晰」或「自动」，要出字更快选「流畅（WebGL）」 |
| 底部状态栏 | 终端和聊天底下那条，关掉后两边一起消失 |

清晰档里，滚轮回看历史时还留在屏幕上的行会直接挪位，只重画新滚进来的几行；程序整屏重绘时仍整屏重画。

### 13.3 集成 → AI 专用配置

提交信息、摘要、翻译这些生成用这一项。下拉里同一条配置的每个模型各占一行，选中哪个就调用哪个。下面每项功能可单独换；留空跟着上面这条。选「自动」则用最近用过的那条配置，模型取它的第一个。

### 13.4 网络

- **出网代理**：官方账号登录 / 启动、Agent 安装与更新下载用。见 [9.3](#93-官方订阅)。
- **学校图书馆**：见教程「付费墙文献」。

### 13.5 更新

有新版本时待处理也会亮。点下载安装，完成后自动重启——进行中的对话请先保存。

### 13.6 诊断

| 项 | 说明 |
|---|---|
| 依赖体检 | Git、Node.js、Quarto、TeX、PyMuPDF、Pillow 六行；下方写「安装渠道」（Homebrew / winget） |
| **导出诊断包** | 发给开发者排查。包里没有密钥 |
| **生效配置快照** | 点 **导出生效配置快照**，看当前到底用了哪条连接（已脱敏） |

一键安装：PyMuPDF、Pillow 走本机 pip，总能一键；Git 在 Mac 没有 Homebrew 时弹系统安装窗口（Xcode 命令行工具）；其余要有 Homebrew 或 winget，没有就按行内提示去官网下，装完点「重新检测」。Linux 给 `sudo apt install …` 命令（Quarto 需去 quarto.org 下）。TeX 有 xelatex、tectonic、pdflatex 任一个就算 ✓。

### 13.7 快捷键

**设置 → 快捷键**。点绑定钮，按下新组合就保存；按 Esc 取消。和另一条冲突时不保存。录成空组合等于关掉这一条。

**页面切换** 是总开关。关掉后下面九条都不生效。默认按侧栏顺序，Mac 用 ⌘，Windows 用 Ctrl：

| 页面 | 默认 |
|---|---|
| 工作台 | ⌘1 / Ctrl+1 |
| 项目 | ⌘2 / Ctrl+2 |
| 运行 | ⌘3 / Ctrl+3 |
| 对话 | ⌘4 / Ctrl+4 |
| 连接 | ⌘5 / Ctrl+5 |
| 技能 | ⌘6 / Ctrl+6 |
| MCP | ⌘7 / Ctrl+7 |
| 用量 | ⌘8 / Ctrl+8 |
| 设置 | ⌘9 / Ctrl+9 |

**全局快捷键** 两条：命令面板默认 ⌘K / Ctrl+K，隐藏侧栏默认 ⌘\ / Ctrl+\。

### 13.8 数据与存储、卸载

**设置 → 数据与存储** 列出 Mesa 自己占的目录，每行可以 **定位**。

**卸载…** 清的是 Mesa 的本机数据：配置与密钥、技能库、会话索引、工作副本、定时任务记录，以及界面记住的最近项目和偏好，都进系统回收站。课题文件夹、论文、各家 AI 自己的会话不动。先确认一次，再在输入框里打「卸载」，点 **确认卸载**。完成后应用退出。退出前的最后一次写入有可能把界面偏好再写回来。

应用本身还在。Mac 把 Mesa.app 拖进废纸篓。Windows 到「设置 → 应用」卸载。

### 14.2 课题文件夹里有什么

| 路径 | 内容 | 谁写 |
|---|---|---|
| `papers/` | 原始文献 PDF、纳入清单、检索记录、RIS | AI + 你下载的 PDF |
| `papers/imports/` | 你手工放入的题录（RIS / BibTeX / CSV / EndNote 导出） | 你 |
| `papers/watchlist.md` | 文献雷达的订阅 | 界面或你直接编辑 |
| `notes/` | 精读笔记、`index.json`、`handoff.md` | AI |
| `references.bib` | 引文库，正文只用 `[@键]` 引用 | AI 追加 |
| `manuscript/` | 大纲、初稿、定稿、审查报告、`typeface.md` | AI |
| `figures/` | 源图（拼图脚本产出） | AI |
| `output/` | 渲染产物（PDF / Word / 两份域稿），不进 git | AI |
| `submission/` | 目标期刊等投稿材料 | AI |
| `.ccode/` | 项目档案、规则、状态 | Mesa |
| `.ccode/help-wanted.md` | Agent 写给你的求助条（也是「人工请求」的来源） | AI |

项目根 `papers/` 是原始文献专用：AI 下载或关联的 PDF 直接进这里，不经评审。

### 14.3 引用与文献库

| 软件 | 导入 | 同步 | 交稿 |
|---|---|---|---|
| 不用 | PDF 留在项目里，按 DOI 写入 `references.bib` | 无 | Quarto 的 docx |
| **Zotero** | 拖进分类后点「从 Zotero 导入」；要与项目共用同一份 PDF，用「链接到文件」并把链接附件根目录指到 `papers/` | 待获取页或精读步的 **同步到 Zotero**（打开 `papers/to-fetch.ris`） | `output/zotero.docx`，Word 打开后点一次 Zotero 工具栏 **Refresh** |
| **EndNote** | 在 EndNote 导出 XML 或 RIS，放进 `papers/imports/`。不要把 `papers/` 设成 EndNote 的自动导入文件夹 | **同步到 EndNote**（打开 `papers/endnote-import.ris`） | `output/endnote.docx`，Word 打开后点一次 **Update Citations and Bibliography** |

注意事项：

- Mesa 不读 `.enl`，也不把 Zotero 库再倒一遍进 EndNote。
- 不要把文件拖进 EndNote 窗口。
- 步骤说明不会替你点 Word。
- 润色与定稿、学位论文的格式与定稿、期刊格式适配同时写出两份带引用域的 Word；正文里的拼图会嵌进这两份。LaTeX 稿不交这两份。
- 渲染时复制到 `output/figures/` 的图不另交，源图在 `figures/`。

## 15 出问题了

| 现象 | 处理 |
|---|---|
| Mac 说应用已损坏 | 不是损坏。终端执行 `xattr -cr /Applications/Mesa.app` |
| 点了按钮没反应 | Mesa 不用系统自带弹窗。看页面中间有没有内联输入框或确认层；仍不行到 **设置 → 诊断** 导出日志 |
| AI 只会说话，不建文件、不检索 | 中转上的模型没有「工具调用」，换官方 Claude 或写明支持 tools 的模型 |
| 配置保存了，一运行就 404 | Claude 类地址不要带 `/v1`；Codex / Kimi / Qwen 类通常要带。回连接里再点一次 **验证并获取** |
| 官方账号提示 token revoked | 订阅本身过期，不是 Mesa 搞混了官方和 API。到连接页重新登录；国内配出网代理 |
| 改了模型，窗口里 `/model` 还是旧的 | 只对**新开的**标签生效。停掉当前这次再运行 |
| 待获取点了 **官网**，一直不是 **✓ 已存** | 看按钮是不是「等待收货…」。PDF 要落到系统「下载」文件夹或浏览器的默认下载目录，尽量在一分半钟内下完。对不上会有右下角横幅。实在不行用 **关联** |
| 想一次下完几十篇付费墙 | 不要。出版商会封学校 IP，一篇一篇点 |
| 切到文件看 PDF，再回来清单跳顶 | 应已修好：回来停在原行、已存仍在。若仍跳动，确认更新到含这项的版本，并把现象发到诊断包 |
| 工作区里的对话找不到 | 在所属课题的「对话」里，带步骤名。工作区删了记录还在，可能显示成单独一项 |
| Git / Node 缺失，改动面板报找不到 git | **设置 → 诊断** 一键安装。Mac 若还没同意 Xcode 许可，先处理系统弹窗，不要反复点 |
| 渲染 PDF 失败、拼图失败 | 诊断页看 Quarto / TeX / PyMuPDF / Pillow 是否就绪；正文字体是否装在本机 |
| 不确定 Mesa 用了哪条连接 | **设置 → 诊断 → 生效配置快照** |

问题与想法提到 [GitHub Issues](https://github.com/hongtongzhou-design/ccode/issues)。附上 **设置 → 诊断** 导出的日志。不要贴 API 密钥或 token。
